# Economic Principle

Resources such as money, time, material and labour are scarce. The **economic principle** (also *rational principle*) therefore requires the ratio between **input** (the means used) and **output** (the result achieved) to be as favourable as possible.

## Forms

| Form              | Fixed   | Rule                                                                      |
| ----------------- | ------- | ------------------------------------------------------------------------- |
| Maximum principle | Input   | Achieve the greatest possible output with a given input.                  |
| Minimum principle | Output  | Achieve a given output with the least possible input.                     |
| Optimum principle | Neither | Choose input and output so that their ratio is as favourable as possible. |

## Examples

- **Maximum principle:** An IT department has a budget of 20,000 EUR for laptops and buys as many devices of the required specification as possible with it.
- **Minimum principle:** An IT department needs 15 laptops of a given specification, determines the supplier with the lowest total price through an [offer comparison](./offer-comparison.md) and buys them there.
- **Optimum principle:** A company plans a web shop without a fixed budget or a fixed feature set and chooses the combination of budget and features with the best ratio of cost to benefit.
