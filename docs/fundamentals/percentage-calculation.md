# Percentage Calculation

## Terms

| Symbol | Term              | Meaning                            |
| ------ | ----------------- | ---------------------------------- |
| B      | Base value        | The whole, corresponds to 100 %    |
| A      | Percentage amount | The part of the base value         |
| p      | Percentage rate   | The share of the base value in %   |

## Formulas

- **B = A x 100 / p** (Base value)
- **A = B x p / 100** (Percentage amount)
- **p = A x 100 / B** (Percentage rate)

## Examples

**Example 1:** A laptop costs €800. The retailer grants a 15 % discount. How much is the discount (A)?

```text
A = B x p / 100 = €800 x 15 / 100 = €120
```

**Example 2:** An invoice contains €57 VAT at a rate of 19 %. What is the net price (B)?!

```text
B = A x 100 / p = €57 x 100 / 19 = €300
```

**Example 3:** 40 out of 250 apprentices fail an examination. What percentage is that (p)?

```text
p = A x 100 / B = 40 x 100 / 250 = 16 %
```
