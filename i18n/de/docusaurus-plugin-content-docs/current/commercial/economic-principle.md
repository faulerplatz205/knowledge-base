# Ökonomisches Prinzip

Ressourcen wie Geld, Zeit, Material und Arbeitskraft sind knapp. Das **ökonomische Prinzip** (auch *Rationalprinzip* oder *Wirtschaftlichkeitsprinzip*) verlangt deshalb ein möglichst günstiges Verhältnis zwischen **Input** (den eingesetzten Mitteln) und **Output** (dem erzielten Ergebnis).

## Ausprägungen

| Ausprägung     | Vorgegeben | Merksatz                                                               |
| -------------- | ---------- | ---------------------------------------------------------------------- |
| Maximalprinzip | Input      | Mit einem gegebenen Input einen möglichst großen Output erzielen.      |
| Minimalprinzip | Output     | Einen vorgegebenen Output mit möglichst geringem Input erreichen.      |
| Optimalprinzip | Keine      | Input und Output so wählen, dass ihr Verhältnis möglichst günstig ist. |

## Beispiele

- **Maximalprinzip:** Eine IT-Abteilung hat ein Budget von 20.000 EUR für Laptops und kauft davon möglichst viele Geräte der geforderten Ausstattung.
- **Minimalprinzip:** Eine IT-Abteilung benötigt 15 Laptops einer vorgegebenen Ausstattung, ermittelt durch einen [Angebotsvergleich](./offer-comparison.md) den Anbieter mit dem niedrigsten Gesamtpreis und kauft sie dort.
- **Optimalprinzip:** Ein Unternehmen plant einen Webshop ohne festes Budget und ohne festen Funktionsumfang und wählt die Kombination aus Budget und Funktionen mit dem besten Verhältnis von Kosten zu Nutzen.
