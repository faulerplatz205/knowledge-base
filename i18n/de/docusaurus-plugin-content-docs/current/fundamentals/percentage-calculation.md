# Prozentrechnung

## Begriffe

| Symbol | Begriff     | Bedeutung                              |
| ------ | ----------- | -------------------------------------- |
| G      | Grundwert   | Das Ganze, entspricht 100 %            |
| W      | Prozentwert | Der Anteil am Grundwert                |
| p      | Prozentsatz | Der Anteil am Grundwert in %           |

## Formeln

- **G = W x 100 / p** (Grundwert)
- **W = G x p / 100** (Prozentwert)
- **p = W x 100 / G** (Prozentsatz)

## Beispiele

**Beispiel 1:** Ein Laptop kostet 800 €. Der Händler gewährt 15 % Rabatt. Wie hoch ist der Rabatt (W)?

```text
W = G x p / 100 = 800 € x 15 / 100 = 120 €
```

**Beispiel 2:** Eine Rechnung enthält 57 € Umsatzsteuer bei einem Steuersatz von 19 %. Wie hoch ist der Nettopreis (G)?

```text
G = W x 100 / p = 57 € x 100 / 19 = 300 €
```

**Beispiel 3:** 40 von 250 Auszubildenden bestehen eine Prüfung nicht. Wie viel Prozent sind das (p)?

```text
p = W x 100 / G = 40 x 100 / 250 = 16 %
```
