# Pliego de requisitos y pliego de especificaciones funcionales

## Visión general {/*#overview*/}

En la gestión de proyectos, el **pliego de requisitos** y el **pliego de especificaciones funcionales** son dos documentos clave que definen qué debe hacer un sistema y cómo se implementará.

- El **pliego de requisitos** lo redacta el cliente y describe **qué** se necesita
- El **pliego de especificaciones funcionales** lo redacta el contratista y describe **cómo** se cumplirán los requisitos

## Pliego de requisitos {/*#requirement-specification*/}

Contiene los requisitos de un cliente a un contratista y una idea aproximada del sistema deseado.

- Descripción de los objetivos del proyecto
- Descripción de la situación actual
- Requisitos relacionados con la seguridad
- Requisitos funcionales (¿Qué debe hacer el sistema?)
- Requisitos no funcionales (p. ej. rendimiento, seguridad, disponibilidad, usabilidad)
- Plazo
- Presupuesto

## Pliego de especificaciones funcionales {/*#functional-specification*/}

Se deriva del pliego de requisitos. Es la respuesta del contratista que describe cómo se implementarán los requisitos.

- Concepto técnico (arquitectura, tecnologías)
  - Descripción detallada de los componentes del sistema
  - Definiciones de interfaces
  - Modelos de datos
- Criterios de prueba y condiciones de aceptación
- Cronograma y hitos del proyecto
- Estimación de costes
