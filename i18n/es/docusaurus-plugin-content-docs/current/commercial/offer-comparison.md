# Comparación de ofertas

## Resumen {/*#overview*/}

Una comparación de ofertas se utiliza en las compras para evaluar dos o más ofertas de proveedores y determinar la mejor. El proceso incluye una comparación **cuantitativa** (medible, basada en costes) y una **cualitativa** (basada en criterios).

## Comparación cuantitativa {/*#quantitative-comparison*/}

La comparación cuantitativa se centra en factores financieros medibles:

- **Precio de compra / precio por unidad**: El coste base del producto o servicio
- **Costes de envío y manipulación**: Costes adicionales de entrega y manipulación
- **Descuento**: Se aplica al precio de lista, normalmente según el volumen del pedido o la relación comercial
- **Descuento por pronto pago (Skonto)**: Un segundo descuento concedido por el pago anticipado dentro de un plazo determinado
- **Condiciones de pago**: Fechas de vencimiento y condiciones que afectan al coste total

## Comparación cualitativa {/*#qualitative-comparison*/}

La comparación cualitativa evalúa criterios no financieros, más difíciles de cuantificar pero igualmente importantes:

- **Calidad**: Calidad del producto o servicio, certificaciones y cumplimiento de normas
- **Fiabilidad**: Cumplimiento del proveedor e historial de entregas puntuales
- **Soporte**: Servicio posventa, condiciones de garantía y capacidad de respuesta
- **Sostenibilidad**: Normas medioambientales, aprovisionamiento regional y prácticas éticas
- **Relación comercial**: Colaboraciones existentes, confianza y potencial a largo plazo

## Método de puntuación {/*#scoring-method*/}

Cuando los factores cualitativos y cuantitativos deben combinarse en una única decisión, un **modelo de puntuación ponderada** puede ayudar:

1. Definir todos los criterios relevantes y asignar una ponderación a cada uno (las ponderaciones deben sumar 100 %)
2. Puntuar a cada proveedor en cada criterio (p. ej., en una escala de 1 a 10, o un sistema de 3 puntos en el que 3 = bueno, 2 = medio, 1 = malo)
3. Multiplicar cada puntuación por su ponderación para obtener la puntuación ponderada
4. Sumar las puntuaciones ponderadas por proveedor
5. El proveedor con la puntuación total más alta representa la mejor oferta global

Este enfoque hace que los criterios subjetivos sean más transparentes y comparables entre proveedores.

**Nota:** No existe un único método estandarizado para el modelo de puntuación. Hay variaciones tanto en la escala de valoración como en el cálculo:

- **Escala de valoración**: Las escalas habituales incluyen 1-10, 1-5 o un sistema de 3 puntos (3 = bueno, 2 = medio, 1 = malo)
- **Cálculo**: Las ponderaciones pueden aplicarse como números enteros (p. ej., `40 x 8 = 320`) o como decimales (p. ej., `0.40 x 8 = 3.20`). Ambos enfoques producen la misma clasificación; solo difieren los totales

### Ejemplo {/*#example*/}

Supóngase que se desea comprar un lote de portátiles nuevos para algunos empleados nuevos. Se utiliza una escala de 1 a 10 y las ponderaciones se aplican como números enteros (p. ej., `40 x 8 = 320`) para encontrar el mejor proveedor.

- **Proveedor 1**: Económico, pero de calidad mediocre
- **Proveedor 2**: Caro y con entrega lenta, pero de primera calidad
- **Proveedor 3**: Equilibrado, con entrega rápida

| Criterios                                                 | Ponderación | Proveedor 1  | Proveedor 2  | Proveedor 3  |
| --------------------------------------------------------- | ----------- | ------------ | ------------ | ------------ |
| Precio ([cuantitativo](#quantitative-comparison))         | 40 %        | 8 => **320** | 6 => **240** | 7 => **280** |
| Calidad ([cualitativo](#qualitative-comparison))          | 40 %        | 6 => **240** | 9 => **360** | 7 => **280** |
| Plazo de entrega ([cualitativo](#qualitative-comparison)) | 20 %        | 7 => **140** | 5 => **100** | 9 => **180** |
| Suma                                                      | 100 %       | **700**      | **700**      | **740**      |

**Resultado**: En este ejemplo, el Proveedor 3 alcanza la puntuación total más alta y sería, por tanto, la opción recomendada.
