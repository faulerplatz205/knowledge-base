# Tipos de servicios de TI

## Visión general {/*#overview*/}

Los servicios de TI pueden clasificarse según la forma en que se prestan y quién los gestiona. Esto abarca las principales definiciones de "servicio" en los distintos marcos, los tipos habituales de servicios de TI, el ciclo de vida IMAC/R/D y la terminología clave de ITSM.

## Definiciones de servicio {/*#service-definitions*/}

| Fuente | Definición                                                                                                                                                                                  |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BSI    | "Un servicio es la composición de objetos y procesos para cumplir una tarea."                                                                                                               |
| FitSM  | "Un servicio es un medio para entregar valor a los clientes apoyando los objetivos del cliente."                                                                                            |
| ITIL 4 | "Un servicio es un medio para posibilitar la cocreación de valor facilitando los resultados que los clientes desean alcanzar, sin que el cliente tenga que gestionar costes y riesgos específicos." |

**La calidad convence, el servicio decide.**

## Visión general de los tipos de servicios de TI {/*#it-service-types-overview*/}

| Tipo de servicio                                              | Descripción                                                                                                                                                              |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Venta de TI / comercio de TI                                  | Adquisición de sistemas y componentes de TI, incluidas la instalación y la conexión a la red                                                                             |
| Servicio de TI                                                | Cualquier servicio posibilitado por y para la TI                                                                                                                         |
| Soporte Break/Fix / servicio de campo / servicio in situ      | Servicios de TI prestados bajo demanda en las instalaciones del cliente; se facturan la mano de obra y las piezas. Optimizado mediante Field Service Management (FSM)     |
| Gestión in situ                                               | Prestación de servicios de TI en las instalaciones del cliente                                                                                                           |
| Servicio de intercambio (Swap Service)                        | Se proporciona al usuario un dispositivo de reemplazo idéntico                                                                                                           |
| Servicio DIY                                                  | El cliente realiza el servicio por sí mismo (con permiso del fabricante, p. ej., la garantía sigue siendo válida)                                                        |
| Servicio en la nube                                           | Todos los servicios ofrecidos por proveedores de nube                                                                                                                    |
| Live Chat                                                     | Mediante un widget o una aplicación, el cliente se conecta en directo con un miembro del personal del proveedor del servicio web                                         |
| Chatbot                                                       | Sistema basado en IA integrado en sitios web, aplicaciones y redes sociales para comunicarse automáticamente con los usuarios; los chatbots híbridos también ofrecen chat en directo |
| Servicios gestionados (Managed Services)                      | Servicios de TI recurrentes de un proveedor de servicios gestionados (MSP); el alcance y la calidad se acuerdan de antemano en un SLA, p. ej., monitorización proactiva y mantenimiento remoto |
| Servicio de garantía                                          | Servicio gratuito por reclamaciones de garantía                                                                                                                          |
| Goodwill                                                      | Servicio gratuito voluntario por parte del contratista                                                                                                                   |
| Servicio de helpdesk                                          | Servicios prestados a través de un helpdesk en línea                                                                                                                     |
| Servicio de mantenimiento                                     | Servicio dentro de contratos de mantenimiento                                                                                                                            |
| Servicio de reparación                                        | Servicios de reparación                                                                                                                                                  |
| Externalización de TI / sourcing de TI                        | Adquisición externa de servicios de TI; los proveedores especializados de servicios de TI se encargan de forma eficiente de tareas difíciles de resolver                 |
| Introducción a los sistemas de TI                             | Familiarización de clientes y empleados con los sistemas de TI                                                                                                           |
| Formación en TI / instrucción en TI                           | Formación y capacitación de clientes a cambio de una tarifa                                                                                                              |

## Ciclo de vida IMAC/R/D {/*#imacrd-lifecycle*/}

El ciclo de vida **IMAC/R/D** describe las fases de un dispositivo de TI desde su despliegue hasta su eliminación:

| Letra  | Fase                 | Descripción                                                                                                                    |
| ------ | -------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **I**  | Install (instalar)   | Adquisición, preinstalación (staging) y despliegue operativo en la ubicación final                                             |
| **M**  | Move (mover)         | Traslado de dispositivos, p. ej., en mudanzas de oficina o reorganizaciones internas                                           |
| **A**  | Add (añadir)         | Ampliaciones de hardware/software, p. ej., añadir RAM o instalar nuevos programas                                              |
| **C**  | Change (cambiar)     | Cambios de configuración o ajustes de derechos de usuario y políticas                                                          |
| **R**  | Remove / Rollback    | Desinstalación de dispositivos y devolución al inventario de TI                                                                |
| **D**  | Dispose (eliminar)   | Borrado seguro de datos (data erasure), posterior remarketing (reventa) o eliminación respetuosa con el medio ambiente         |

## Términos clave de ITSM {/*#key-itsm-terms*/}

| Término                                                                    | Descripción                                                                                                                                                  |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Service Desk**                                                           | Punto de servicio para usuarios; también denominado Helpdesk                                                                                                 |
| **ITSM**                                                                   | IT Service Management: suma de todas las actividades que realiza un proveedor de servicios de TI para planificar, prestar, operar y controlar los servicios de TI |
| **Portafolio de servicios**                                                | Conjunto de todos los servicios de TI ofrecidos; incluye el catálogo de servicios, las directrices y las responsabilidades                                   |
| **[SLA](./sla.md)**                                                        | Service Level Agreement: acuerdo contractual sobre los niveles de servicio entre proveedor y cliente                                                         |
| **OLA**                                                                    | Operational Level Agreement: acuerdo interno entre equipos/departamentos de TI                                                                               |
| **KPI**                                                                    | Key Performance Indicator: métricas alineadas con objetivos de negocio críticos, p. ej., la disponibilidad del servicio o el número de interrupciones del servicio |
| **SOA**                                                                    | Service-Oriented Architecture: los procesos de negocio y los sistemas se modularizan y se enlazan mediante servicios de TI reutilizables                     |
| **[IaaS](../../cloud/service-models.md#infrastructure-as-a-service-iaas)** | Infrastructure as a Service: plataforma en la nube que proporciona infraestructura como base de una aplicación                                               |
| **Disponibilidad del servicio 24/7**                                       | El servicio está disponible en todo momento                                                                                                                  |
| **Disponibilidad del servicio 12/5**                                       | El servicio está disponible durante el horario laboral habitual                                                                                              |
