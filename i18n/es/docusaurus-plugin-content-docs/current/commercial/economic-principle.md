# Principio económico

Los recursos como el dinero, el tiempo, el material y el trabajo son escasos. Por ello, el **principio económico** (también *principio racional*) exige que la relación entre el **input** (los medios empleados) y el **output** (el resultado alcanzado) sea lo más favorable posible.

## Formas {/*#forms*/}

| Forma                      | Fijo    | Regla                                                                          |
| -------------------------- | ------- | ------------------------------------------------------------------------------ |
| Principio de maximización  | Input   | Lograr el mayor output posible con un input dado.                              |
| Principio de minimización  | Output  | Lograr un output dado con el menor input posible.                              |
| Principio de optimización  | Ninguno | Elegir input y output de modo que su relación sea lo más favorable posible.    |

## Ejemplos {/*#examples*/}

- **Principio de maximización:** Un departamento de TI dispone de un presupuesto de 20.000 EUR para portátiles y compra con él tantos equipos como sea posible con las especificaciones requeridas.
- **Principio de minimización:** Un departamento de TI necesita 15 portátiles con unas especificaciones dadas, determina el proveedor con el precio total más bajo mediante una [comparación de ofertas](./offer-comparison.md) y los compra allí.
- **Principio de optimización:** Una empresa planifica una tienda web sin presupuesto fijo ni conjunto de funciones fijo y elige la combinación de presupuesto y funciones con la mejor relación entre coste y beneficio.
