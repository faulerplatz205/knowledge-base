# Modelo AIDA

El **modelo AIDA** describe las cuatro etapas consecutivas por las que una publicidad exitosa guía a un cliente potencial desde el primer contacto hasta la compra. El modelo se remonta al pionero estadounidense de la publicidad Elmo Lewis (1898) y se utiliza tanto para diseñar como para evaluar la publicidad. La publicidad suele dirigirse a [necesidades latentes](./needs-and-demand.md#types-of-needs) de las que el cliente aún no es consciente.

## Etapas {/*#stages*/}

| Etapa         | Objetivo                                                         | Medios típicos                                                             |
| ------------- | ---------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **Atención**  | El anuncio se percibe entre estímulos competidores.              | Imágenes, colores o música llamativos, titulares inusuales, rostros conocidos |
| **Interés**   | El cliente quiere saber más sobre el producto.                   | Información sobre características y beneficios, un problema que el producto resuelve |
| **Deseo**     | El cliente quiere poseer el producto.                            | Atractivo emocional, comparación con la situación actual, reseñas, escasez |
| **Acción**    | El cliente realiza la acción prevista, normalmente la compra.    | Llamada a la acción, botón "Comprar ahora", descuento por tiempo limitado, pedido sencillo |

La acción prevista no tiene por qué ser una compra. También puede ser el objetivo del anuncio una suscripción a un boletín, una prueba de conducción o una solicitud de oferta.

## Ejemplo {/*#example*/}

Un fabricante de teléfonos inteligentes anuncia un nuevo modelo en redes sociales.

| Etapa     | Implementación                                                                           |
| --------- | ---------------------------------------------------------------------------------------- |
| Atención  | Un vídeo llamativo con música pegadiza destaca al desplazarse por el feed.               |
| Interés   | El vídeo muestra la nueva cámara con impresionantes fotos nocturnas.                     |
| Deseo     | Al compararlo con las fotos de su teléfono anterior, el espectador piensa "lo quiero".   |
| Acción    | Un botón "Comprar ahora" con un descuento válido durante 48 horas lleva directamente al pedido. |

## Extensiones {/*#extensions*/}

- **AIDAS:** Añade *Satisfaction* (satisfacción). Un cliente satisfecho vuelve a comprar y recomienda el producto, por lo que la satisfacción posterior a la compra forma parte del objetivo publicitario.
- **AIDCA:** Añade *Conviction* (convicción) entre Deseo y Acción. Argumentos como resultados de pruebas o garantías convencen al cliente de que la compra es la decisión correcta.

## Limitaciones {/*#limitations*/}

- Las decisiones de compra reales no son lineales. Las compras por impulso se saltan etapas, y las compras costosas implican investigación y comparación que el modelo no contempla.
- El modelo considera al cliente como pasivo. Hoy los clientes suelen buscar información por sí mismos, p. ej. mediante reseñas, portales de comparación y redes sociales.

## Errores comunes {/*#common-mistakes*/}

1. **Confundir Interés y Deseo:** El interés es el deseo de saber más sobre un producto; el deseo es la voluntad de poseerlo. Un cliente que lee los datos técnicos está interesado, pero no necesariamente quiere comprar.
