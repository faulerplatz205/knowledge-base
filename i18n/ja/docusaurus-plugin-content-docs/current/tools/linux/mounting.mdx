# Linuxでのマウント

Linuxでは、ストレージデバイス(ディスク、パーティション、USBメモリ)はドライブレターではなく、ディレクトリツリー内の任意の**マウントポイント**に**マウント**することでアクセスされる。マウント後、その内容はこのディレクトリの下に表示される。

## マウント {/* #mounting */}

```bash
mount /dev/sdb1 /mnt/usb    # Attach the device /dev/sdb1 at /mnt/usb
```

## アンマウント {/* #unmounting */}

```bash
umount /mnt/usb    # Detach the filesystem (note: the command is "umount", without the first "n")
```
