# Linuxのファイルパーミッション

`ls`の2つのオプションで日常的なケースをカバーできる。詳細(パーミッションを含む)の一覧表示と、隠しファイルの表示である。

## ファイルの一覧表示 {/* #listing-files */}

```bash
ls -l    # Long format: permissions, owner, size, date, name
ls -a    # Show all files, including hidden ones
```

名前がドット(`.bashrc`、`.config`)で始まるファイルとディレクトリは**隠しファイル**であり、`ls -a`を付けた場合にのみ表示される。両方のオプションは`ls -la`のようにまとめて指定されることが多い。

## 出力例 {/* #example-output */}

`ls -l`の各行は、複数の列にわたって1つのエントリを記述する。

```bash
-rw-r--r-- 1 user staff 1024 Apr 25 10:00 notes.txt
drwxr-xr-x 2 user staff 4096 Apr 25 09:30 projects
```

| 列           | 例             | 意味                         |
| ------------ | -------------- | ---------------------------- |
| パーミッション | `-rw-r--r--`      | ファイルタイプとパーミッション |
| リンク数     | `1`        | ハードリンクの数             |
| 所有者       | `user`        | ファイルの所有者             |
| グループ     | `staff`        | ファイルが属するグループ     |
| サイズ       | `1024`        | バイト単位のサイズ           |
| 日付と時刻   | `Apr 25 10:00`        | 最終更新日時                 |
| 名前         | `notes.txt`        | ファイル名またはディレクトリ名 |

## パーミッション表記の読み方 {/* #reading-the-permission-notation */}

`ls -l`の行は、`-rwxr-xr-x`のような10文字の文字列で始まる。これは4つの部分に分かれる。

| 位置  | 例      | 意味                                                   |
| ----- | ------- | ------------------------------------------------------ |
| 1     | `-` | ファイルタイプ(`-` = ファイル、`d` = ディレクトリ、`l` = シンボリックリンク) |
| 2-4   | `rwx` | **所有者**のパーミッション                             |
| 5-7   | `r-x` | **グループ**のパーミッション                           |
| 8-10  | `r-x` | **その他**のパーミッション                             |

3つのグループはいずれも同じ3つのフラグを使用する。

| フラグ  | 意味 | ファイルに対する効果 | ディレクトリに対する効果       |
| ------- | ---- | -------------------- | ------------------------------ |
| `r` | 読み取り | 内容を読み取る   | エントリを一覧表示する         |
| `w` | 書き込み | 内容を変更する   | エントリを作成/削除する        |
| `x` | 実行 | プログラムとして実行する | ディレクトリに入る(`cd`) |

文字の代わりに`-`がある場合、そのパーミッションは付与されていないことを意味する。したがって`-rwxr-xr-x`は、通常のファイルで、所有者は読み取り/書き込み/実行ができ、グループとその他は読み取りと実行ができるが書き込みはできないことを意味する。
