# 要求仕様書/機能仕様書

## 概要 {/*#overview*/}

プロジェクトマネジメントにおいて、**要求仕様書**と**機能仕様書**は、システムが何をすべきか、およびどのように実装されるかを定義する2つの主要な文書である。

- **要求仕様書**は発注者が作成し、**何が**必要かを記述する
- **機能仕様書**は請負者が作成し、要件を**どのように**満たすかを記述する

## 要求仕様書 {/*#requirement-specification*/}

発注者から請負者への要件と、望まれるシステムの大まかなイメージを含む。

- プロジェクトの目標の記述
- 現状の記述
- 安全に関する要件
- 機能要件(システムは何をすべきか)
- 非機能要件(例: パフォーマンス、セキュリティ、可用性、ユーザビリティ)
- 期間
- 予算

## 機能仕様書 {/*#functional-specification*/}

要求仕様書から導かれる。要件がどのように実装されるかを記述した、請負者による回答である。

- 技術コンセプト(アーキテクチャ、技術)
  - システムコンポーネントの詳細な記述
  - インターフェース定義
  - データモデル
- テスト基準と受け入れ条件
- プロジェクトスケジュールとマイルストーン
- コスト見積もり
