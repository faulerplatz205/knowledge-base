# 比較演算子

## 等価演算子 {/*#equality-operators*/}

| 演算子    | 名前              | 説明                                                   |
| --------- | ----------------- | ------------------------------------------------------ |
| `===`    | 厳密等価          | 値**と**型が等しい場合に`true`を返す                   |
| `!==`   | 厳密不等価        | 値**または**型が異なる場合に`true`を返す              |
| `==`   | 非厳密等価        | 型変換後に値が等しい場合に`true`を返す                |
| `!=`   | 非厳密不等価      | 型変換後に値が異なる場合に`true`を返す                |

### 例 {/*#examples*/}

```typescript
1 === 1      // true
1 === "1"    // false (different types)

1 == "1"     // true (string is coerced to number)
0 == false   // true
null == undefined // true
```

**重要:** 予期しない型変換を避けるため、`==`および`!=`よりも`===`および`!==`を常に優先する。

## 関係演算子 {/*#relational-operators*/}

| 演算子   | 名前           | 例                  |
| -------- | -------------- | ------------------- |
| `>`  | より大きい     | `5 > 3` => `true`  |
| `<`  | より小さい     | `5 < 3` => `false`  |
| `>=`  | 以上           | `5 >= 5` => `true`  |
| `<=`  | 以下           | `3 <= 5` => `true`  |

## Nullish比較と特殊な比較 {/*#nullish-and-special-comparisons*/}

| 式                   | 結果    | 理由                                   |
| -------------------- | ------- | -------------------------------------- |
| `NaN === NaN`        | `false` | `NaN`はどの値とも等しくない          |
| `null === undefined` | `false` | 型が異なる                             |
| `null == undefined`  | `true`  | 非厳密等価における特別な規則           |
| `null == 0`          | `false` | `null`は`undefined`とのみ非厳密に等しい   |

## 演算子の優先順位 {/*#operator-precedence*/}

**優先順位が高い**演算子が先に評価される。**同じレベル**の演算子は左から右へ評価される。

| 優先順位    | 演算子                   | 説明               |
| ----------- | ------------------------ | ------------------ |
| 1(最高)     | `()`                     | グルーピング       |
| 2           | `!`                      | 論理NOT            |
| 3           | `>`, `<`, `>=`, `<=`     | 関係               |
| 4           | `===`, `!==`, `==`, `!=` | 等価               |
| 5           | `&&`                     | 論理AND            |
| 6           | `\|\|`                   | 論理OR             |
| 7(最低)     | `??`                     | Null合体           |

### 例 {/*#example*/}

```typescript
const result = a > 0 && b === 1 || c !== 2;

// && binds tighter than ||, so this is equivalent to:
const result = (a > 0 && b === 1) || c !== 2;

// NOT:
const result = a > 0 && (b === 1 || c !== 2);

// Solution:
const result = a > 0 && (b === 1 || c !== 2);
```

**ヒント:** 迷う場合は、括弧`()`を使用して意図した評価順序を明示する。
