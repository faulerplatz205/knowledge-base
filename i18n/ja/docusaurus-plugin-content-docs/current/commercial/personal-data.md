# 個人データ

GDPR(General Data Protection Regulation、一般データ保護規則)において、個人データとは、識別された、または識別可能な自然人に関するあらゆる情報を指す(GDPR第4条)。

## 通常の個人データ {/*#regular-personal-data*/}

通常の個人データには、個人を直接的または間接的に識別できる情報が含まれる。

- 氏名(名、姓)
- 住所(番地、市区町村、郵便番号)
- メールアドレス
- 電話番号
- 生年月日
- IPアドレス
- 位置情報
- オンライン識別子(例: Cookie、デバイスID)
- 銀行口座番号またはクレジットカード番号
- 顧客IDまたは従業員ID

## 特別なカテゴリの個人データ {/*#special-categories-of-personal-data*/}

特別なカテゴリの個人データ(GDPR第9条)は特に機微性が高く、より厳格な取扱い要件が適用される。特定の例外が適用されない限り、取扱いは原則として禁止されている。

- 人種的または民族的出自
- 政治的意見
- 宗教的または哲学的信条
- 労働組合への加入
- 遺伝データ
- 個人を一意に識別するために用いられる生体データ(例: 指紋、顔認識)
- 健康に関するデータ
- 性生活または性的指向に関するデータ

## 取扱いの原則 (GDPR第5条) {/*#principles-of-processing-art-5-gdpr*/}

GDPR第5条は、個人データのあらゆる取扱いが満たさなければならない原則を定めている。これらは法的根拠に加えて適用される。GDPR第6条の対象となる取扱いであっても、これらの原則のいずれかに違反すれば違法である。

| 原則 | 意味 |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 適法性、公正性、透明性 | 取扱いには法的根拠が必要であり、データ主体が理解できるものでなければならず、秘密裏に行ってはならない |
| 目的の限定 | データは特定された目的のために収集され、後に両立しない目的で使用してはならない |
| データの最小化 | 目的に照らして適切かつ必要なデータのみを取り扱うことができる |
| 正確性 | データは正確かつ最新でなければならない。不正確なデータは訂正または消去されなければならない |
| 保存の制限 | データは目的に必要な期間のみ保持される。その後は消去または匿名化される |
| 完全性と機密性 | 適切な技術的および組織的措置により、データを損失や不正アクセスから保護する |
| 説明責任 | 管理者は、これらすべての原則への遵守を実証できなければならない |

実務上の帰結は次のとおりである。

- **目的の限定**により、注文処理のために収集したメールアドレスを、そのままニュースレターに使用してはならない。
- **データの最小化**はあらゆる入力フォームに当てはまる。目的に不要な項目を必須としてはならない。
- **保存の制限**には、データカテゴリごとの保存期間を定めた削除コンセプトが必要である。これは、税法などに基づく法定の保存義務と衝突する場合がある。
- **完全性と機密性**は、従来の[セキュリティ目標](../fundamentals/security-goals.md)に対応し、暗号化、アクセス制御、ログ記録、バックアップによって実現される。
- **説明責任**は立証責任を逆転させる。適法性を文書化するのは管理者であり、データ主体が違反を立証するのではない。取扱い活動の記録、活動ごとの法的根拠、同意の証拠はいずれもこの目的に資する。

## データ取扱いの法的根拠 (GDPR第6条) {/*#legal-bases-for-data-processing-art-6-gdpr*/}

個人データは、次の法的根拠の少なくとも1つが適用される場合にのみ取り扱うことができる。

- **同意 (GDPR第6条第1項(a)):** データ主体が、1つまたは複数の特定の目的のために自己のデータを取り扱うことについて、自由意思に基づき、十分な情報を得た上で、明確に同意している。同意はいつでも撤回できる。
- **契約の履行 (GDPR第6条第1項(b)):** データ主体が当事者である契約の履行のため、またはデータ主体の要請に基づく契約締結前の措置のために、取扱いが必要である(例: 売買契約や雇用契約の処理)。
- **法的義務 (GDPR第6条第1項(c)):** 法的義務を遵守するために取扱いが必要である(例: 税務や会計の要件)。
- **生命に関する利益 (GDPR第6条第1項(d)):** データ主体または他の自然人の生命に関する利益を保護するために取扱いが必要である(例: 医療上の緊急事態)。
- **公共の任務 (GDPR第6条第1項(e)):** 公共の利益のために行われる任務の遂行、または公的権限の行使のために取扱いが必要である。
- **正当な利益 (GDPR第6条第1項(f)):** 管理者または第三者が追求する正当な利益の目的のために取扱いが必要である(例: ITセキュリティ)。ただし、そのような利益よりもデータ主体の利益、権利、自由が優先される場合を除く。これには比較衡量が必要であり、公的機関がその任務の遂行にあたって用いることはできない。

## データ主体の権利 {/*#rights-of-data-subjects*/}

- **アクセス権 (GDPR第15条):** 個人データが取り扱われているかどうかの確認を得る権利。取り扱われている場合は、そのデータの写しと、取扱いに関する情報を受け取る権利。
- **訂正権 (GDPR第16条):** 不正確または不完全な個人データを、不当な遅滞なく訂正させる権利。
- **消去権 / 「忘れられる権利」 (GDPR第17条):** 個人データを削除させる権利。例: 当初の目的に不要となった場合、同意が撤回された場合、取扱いが違法であった場合。
- **取扱いの制限権 (GDPR第18条):** 一定の状況において、個人データの取扱いを制限させる権利。例: データの正確性が争われている間。
- **データポータビリティの権利 (GDPR第20条):** 個人データを構造化され、一般的に使用され、機械可読な形式で受け取り、別の管理者に移転する権利(同意または契約に基づく取扱いに適用される)。
- **異議を述べる権利 (GDPR第21条):** 正当な利益または公共の任務に基づく取扱い、およびダイレクトマーケティング目的の取扱いに異議を述べる権利(ダイレクトマーケティングの場合は、比較衡量なしに常に尊重されなければならない)。
- **自動化された決定に服しない権利 (GDPR第22条):** プロファイリングを含む、自動化された取扱いのみに基づく決定で、法的効果または同様に重大な影響をもたらすものに服しない権利。
- **苦情を申し立てる権利 (GDPR第77条):** 取扱いがGDPRに違反するとデータ主体が考える場合に、監督機関に苦情を申し立てる権利。
