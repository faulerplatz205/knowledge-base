# 分割返済ローン

## 分割返済ローンとは {/*#what-is-an-installment-loan*/}

分割返済ローンとは、あらかじめ定められた回数の支払いによって、時間をかけて返済されるローンの一種である。リボルビング払い (例: クレジットカード) とは異なり、期間の終了時にローンは完全に返済される。

この例は**元本均等返済**のモデルを示している。借り手は毎年同額の元本を返済し、利息は時間とともに減少する。

## 計算式 {/*#formula*/}

```text
Annual Interest = Remaining Debt * Interest Rate  

Principal Repayment = Total Debt / Loan Term  

Annuity (Annual Payment) = Interest + Principal Repayment  

Remaining Debt = Previous Debt − Principal Repayment
```

## 例 {/*#example*/}

**€100,000**のローン、利率**5%**、**4年間**にわたる年**€25,000**の元本均等返済を仮定する。

| 年 | 残債務   | 利息 (5%) | 元本返済 | 年間支払額 | 支払後の債務 |
| -- | -------- | --------- | -------- | ---------- | ------------ |
| 1  | €100,000 | €5,000    | €25,000  | €30,000    | €75,000      |
| 2  | €75,000  | €3,750    | €25,000  | €28,750    | €50,000      |
| 3  | €50,000  | €2,500    | €25,000  | €27,500    | €25,000      |
| 4  | €25,000  | €1,250    | €25,000  | €26,250    | €0           |

**支払利息の合計:** €12,500  
**返済額の合計:** €112,500
