# 見積比較

## 概要 {/*#overview*/}

見積比較は、調達において2つ以上の仕入先の見積を評価し、最適な取引を判断するために用いられる。この過程には、**定量的**(測定可能でコストに基づく)な比較と、**定性的**(基準に基づく)な比較の両方が含まれる。

## 定量的比較 {/*#quantitative-comparison*/}

定量的比較は、測定可能な財務的要因に焦点を当てる。

- **仕入価格 / 単価**: 製品またはサービスの基本コスト
- **送料および取扱費用**: 配送と取扱いにかかる追加費用
- **値引き**: 定価に適用される。通常は注文量または取引関係に基づく
- **現金割引 (Skonto)**: 所定の期間内の早期支払いに対して認められる2つ目の割引
- **支払条件**: 総コストに影響する支払期日と条件

## 定性的比較 {/*#qualitative-comparison*/}

定性的比較は、数値化しにくいが同様に重要な、財務以外の基準を評価する。

- **品質**: 製品またはサービスの品質、認証、規格への適合
- **信頼性**: 仕入先の信頼度と納期遵守の実績
- **サポート**: アフターサービス、保証条件、対応の迅速さ
- **持続可能性**: 環境基準、地域調達、倫理的な取り組み
- **取引関係**: 既存のパートナーシップ、信頼、長期的な可能性

## スコアリング方法 {/*#scoring-method*/}

定性的要因と定量的要因を1つの判断にまとめる必要がある場合、**加重スコアリングモデル**が役立つ。

1. 関連するすべての基準を定義し、それぞれに重みを割り当てる(重みの合計は100%とする)
2. 各仕入先をすべての基準で採点する(例: 1~10の尺度、または3 = 良い、2 = 普通、1 = 悪いの3段階)
3. 各点数に重みを掛けて、加重スコアを求める
4. 仕入先ごとに加重スコアを合計する
5. 合計スコアが最も高い仕入先が、総合的に最良の見積を示す

この方法により、主観的な基準がより透明になり、仕入先間で比較しやすくなる。

**注記:** スコアリングモデルには、唯一の標準化された方法はない。評価尺度と計算の両方にバリエーションがある。

- **評価尺度**: 一般的な尺度には、1~10、1~5、または3段階(3 = 良い、2 = 普通、1 = 悪い)がある
- **計算**: 重みは整数(例: `40 x 8 = 320`)でも小数(例: `0.40 x 8 = 3.20`)でも適用できる。どちらの方法でも順位は同じになり、合計値のみが異なる

### 例 {/*#example*/}

新入社員用にノートパソコンを一括購入する場合を想定する。1~10の尺度を用い、重みを整数(例: `40 x 8 = 320`)として適用して、最適な仕入先を求める。

- **仕入先1**: 安価だが、品質は平凡
- **仕入先2**: 高価で納品が遅いが、最高品質
- **仕入先3**: バランスが取れており、納品が速い

| 基準 | 重み | 仕入先1 | 仕入先2 | 仕入先3 |
| ------------------------------------------------------ | --------- | ------------ | ------------ | ------------ |
| 価格([定量的](#quantitative-comparison)) | 40% | 8 => **320** | 6 => **240** | 7 => **280** |
| 品質([定性的](#qualitative-comparison)) | 40% | 6 => **240** | 9 => **360** | 7 => **280** |
| 納期([定性的](#qualitative-comparison)) | 20% | 7 => **140** | 5 => **100** | 9 => **180** |
| 合計 | 100% | **700** | **700** | **740** |

**結果**: この例では、仕入先3の合計スコアが最も高く、したがって推奨される選択肢となる。
