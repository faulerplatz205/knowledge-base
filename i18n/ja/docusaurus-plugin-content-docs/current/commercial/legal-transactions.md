# 法律行為

ドイツ民法典 (BGB) における**法律行為** (ドイツ語: *Rechtsgeschäft*) は、少なくとも1つの意思表示から成り、法律関係の成立、変更、終了などの法的効果を目的とする。ビジネスにおいて最も一般的な法律行為は[売買契約](./purchase-contract.md)である。

## 意思表示 {/*#declaration-of-intent*/}

**意思表示** (*Willenserklärung*) は、法的効果を目指した意思の表明である。さまざまな方法で行うことができる。

- **明示的:** 口頭、書面、または電子的な方法による。例: ウェブショップでの注文。
- **黙示的行為による:** 行為から意思を推知できるもの。例: 商品をレジのベルトコンベアに載せる、タクシーに乗り込む、競売で手を挙げる。

解約告知のように受領が必要な意思表示は、相手方に到達した時点で効力を生じる (BGB第130条)。相手方が内容を読んだかどうかは問われない。郵便受けに入った手紙は、通常の状況で郵便受けが空にされると見込まれる時点で到達したものとされる。

## 法律行為の種類 {/*#types-of-legal-transactions*/}

| 種類 | 意思表示 | 例 |
| --------------------------------- | -------------------------------- | ------------------------------------------------------- |
| 単独行為(受領を要する) | 1つ、他の者に宛てたもの | 解約告知、取消し、契約の撤回 |
| 単独行為(受領を要しない) | 1つ、相手方なしで効力を生じるもの | 遺言、懸賞広告 |
| 片務契約 | 内容が一致する2つの意思表示 | 贈与、保証 |
| 双務契約 | 内容が一致する2つの意思表示 | 売買契約、賃貸借契約、雇用契約 |

**契約**には、常に内容が一致する少なくとも2つの意思表示、すなわち申込みと承諾が必要である。契約が片務か双務かは、意思表示の数ではなく、契約が生じさせる義務を指す。贈与は、受贈者が承諾する必要があるため契約であるが、義務を負うのは贈与者のみである。

## 行為能力 {/*#capacity-to-contract*/}

**権利能力** (*Rechtsfähigkeit*) は、権利と義務を保持する能力であり、出生とともに始まる (BGB第1条)。**行為能力** (*Geschäftsfähigkeit*) は、法的に有効な意思表示を行う能力であり、主に年齢に左右される。自由な意思決定を排除する持続的な精神障害のある者は、年齢にかかわらず行為能力を持たない (BGB第104条第2号)。

| 年齢 | 行為能力 | 結果 |
| ------- | ---------------------- | -------------------------------------------------------------------------------------------- |
| 7歳未満 | なし (BGB第104条第1号) | 意思表示は無効 (BGB第105条)。法定代理人が子に代わって行為する。 |
| 7歳から17歳 | 制限あり (BGB第106条) | 契約には法定代理人、通常は親の同意が必要 (BGB第107条)。 |
| 18歳以上 | 完全 | 意思表示は制限なく有効。 |

未成年者が事前の同意なしに行った契約は、**浮動的無効**である (BGB第108条)。法定代理人が追認すると有効となり、拒絶すると確定的に無効となる。未成年者が単独で行為できる例外は次のとおりである。

- **単なる法的利益:** 義務を伴わない贈与。例: 金銭の贈与 (BGB第107条)。
- **小遣い条項:** 未成年者がその目的のため、または自由な処分のために与えられた手段で全額履行される契約 (BGB第110条)。
- **許可された就労:** 親が許可した雇用関係に関する法律行為 (BGB第113条)。

## 無効な法律行為と取消可能な法律行為 {/*#void-and-voidable-legal-transactions*/}

**無効** (*nichtig*) な法律行為は、最初から効力がない。そのために誰かが行動を起こす必要はない。

| 理由 | 例 |
| ------------------------------------------------ | -------------------------------------------------------------------------- |
| 行為能力の欠如 (BGB第105条) | 6歳の子がゲーム機を購入する。 |
| 通謀虚偽表示 (BGB第117条) | 節税のために、より低い価格が契約書に記載される。 |
| 冗談による行為 (BGB第118条) | 明らかな冗談として「私の車を1ユーロで売る」と言う。 |
| 法定方式の欠如 (BGB第125条) | 土地が公正証書なしで売却される。 |
| 法律上の禁止への違反 (BGB第134条) | 無申告労働の契約。 |
| 公序良俗違反、暴利行為 (BGB第138条) | 窮状につけ込み、市場金利をはるかに上回る金利で貸し付ける。 |

**取消可能** (*anfechtbar*) な法律行為は、当事者の一方が取り消すまで有効である。取消しにより、最初から無効となる (BGB第142条)。

| 理由 | 例 | 期限 |
| ------------------------------------------------------- | ------------------------------------------------------------------- | ----------------------------------- |
| 内容の錯誤 (BGB第119条第1項) | 買主が「グロス」単位でペンを注文し、100本を意味すると思い込む。 | 発見後遅滞なく |
| 表示の錯誤 (BGB第119条第1項) | 申込みの誤記で、10,000ユーロの代わりに1,000ユーロと記載される。 | 発見後遅滞なく |
| 本質的な性質に関する錯誤 (BGB第119条第2項) | 絵画を原画として購入したが、複製だったと判明する。 | 発見後遅滞なく |
| 誤伝達 (BGB第120条) | 使者が誤った数量を伝える。 | 発見後遅滞なく |
| 詐欺 (BGB第123条) | 事故歴を知りながら、中古車が無事故として売られる。 | 発見後1年 |
| 違法な強迫 (BGB第123条) | 暴力の脅しの下で契約に署名する。 | 強迫の終了後1年 |

錯誤を理由に取り消す当事者は、相手方が意思表示を信頼したことによって被った損害を賠償しなければならない (BGB第122条)。

## 一般的な誤り {/*#common-mistakes*/}

1. **書面による契約のみを拘束力があるとみなす:** 契約は、口頭や黙示的行為を含め、原則として特定の方式なしに成立する。特定の方式が必要となるのは、法律または当事者間の合意が定める場合に限られる。例: 土地の売却における公正証書 (BGB第311b条)、雇用関係の解約告知における書面方式 (BGB第623条)。
2. **沈黙を承諾とみなす:** 沈黙によって契約は成立しない。例外は商人間の確認書である。商人間では、これに対する沈黙はその内容への同意とみなされる。注文していない商品を受け取った消費者は、支払いも返送も要しない (BGB第241a条)。
3. **無効と取消可能の同一視:** 無効な行為は決して効力を生じない。取消可能な行為は取り消されるまで有効であり、取消しがなければ有効なままである。
4. **動機の錯誤を理由とする取消し:** 行為の理由に関する錯誤は、取消しの根拠とならない。株価の上昇を見込んで株式を購入した買主は、株価が下落しても購入を取り消せない。相手方が認識できなかった計算上の誤りについても同様である。
5. **小遣い条項の分割払い購入への適用:** BGB第110条は、契約が未成年者の手段で全額履行されることを要求する。分割払いでの購入は、親が事前に同意しているか追認しない限り、最後の分割金が支払われるまで浮動的無効のままである。
