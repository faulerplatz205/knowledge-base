# 作業共同体とコンソーシアム

**作業共同体**または**コンソーシアム**とは、法的にも経済的にも独立した企業が、通常は1社では大きすぎる、あるいはリスクが高すぎる特定のプロジェクトを完遂するために力を合わせる、一時的な連合を指す。

## 定義 {/*#definition*/}

- プロジェクトまたはタスクに関連した協力であり、プロジェクトの完了とともに終わる
- 建設や、大規模なインフラ・サービスプロジェクトで一般的
- 典型的な法的形態: 民法上の組合
- **違い**: コンソーシアムはより緩やかな形態であり、各構成員が自らのサービスを独立して提供する

## 作業共同体とコンソーシアムの比較 {/*#working-group-vs-consortium*/}

両者はしばしば同じ意味で使われるが、内部の統合の度合いが異なる。

| 観点         | 作業共同体 (ARGE)                          | コンソーシアム                                         |
| ------------ | ------------------------------------------ | ------------------------------------------------------ |
| 統合         | 高い: 資源、財務、人員が結集される         | 低い: 各構成員が自らの担当部分を独立して遂行する       |
| 内部組織     | 共同の経営、共通の会計                     | 構成員ごとに別個の経営と会計                           |
| 責任         | 連帯責任                                   | 多くは各構成員自身の担当部分に限定される               |
| 典型的な分野 | 建設とインフラ                             | 銀行 (シンジケートローン、IPO)、大規模なサービスプロジェクト |

要するに、作業共同体は内部で資源を結集して共同で作業し、コンソーシアムは対外的には共同で名乗るが、各構成員は自らの担当部分を独立して処理する。

## 独立性への影響 {/*#effect-on-independence*/}

- 構成員は**法的にも経済的にも独立**したままである
- 各自が独自の法的形態と中核事業を維持する
- 利益と損失はパートナー間で分配される
- 作業共同体は、自らの名で行動する場合、組合として課税され得る

## 動機 {/*#motives*/}

- 1社では扱えないプロジェクトを実施する
- コストとリスクを分担する
- ノウハウ、資源、キャパシティを結集する
- 競争力を強化する

## 利点と欠点 {/*#advantages-and-disadvantages*/}

| 利点                             | 欠点                                 |
| -------------------------------- | ------------------------------------ |
| 作業、コスト、リスクが分担される | 調整上の問題が生じ得る               |
| 大規模なプロジェクトが実現可能になる | パートナーの利害が異なる         |
| パートナーのノウハウの活用       | パートナーのミスに対する責任リスク   |

## 競争への影響 {/*#effects-on-competition*/}

- 強み (ノウハウ、資本、資源) の結集
- 消費者にとっての利益の可能性: 品質の向上、価格の低下、納期の短縮
- **リスク**: 市場支配力が大きくなりすぎると、小規模企業を圧迫し、カルテルに近い状況に陥り得る

## ジョイントベンチャーとの比較 {/*#comparison-with-joint-venture*/}

どちらの形態も独立した企業間の協力を伴うが、範囲、期間、構造が異なる。

| 観点       | 作業共同体 / コンソーシアム                  | ジョイントベンチャー                              |
| ---------- | -------------------------------------------- | ------------------------------------------------- |
| 期間       | プロジェクト単位で、プロジェクト終了時に解散 | 長期または継続的であることが多い                  |
| 新たな法人 | なし、通常は民法上の組合                     | 通常はあり (例: 共同設立のGmbH)                   |
| 範囲       | 明確に定められた単一のプロジェクト           | より広い戦略的目標 (市場参入、製品ライン)         |
| 資源       | 各構成員が独立して拠出する                   | 共同で管理され、プールされる                      |
| 利益の分配 | 合意に従ってパートナー間で分配される         | 設立契約で明示的に合意される                      |

要するに、作業共同体やコンソーシアムは1つのプロジェクトに限定された一時的な提携であり、その後パートナーはそれぞれの道に分かれる。ジョイントベンチャーは、資源を共有し、しばしば新たに設立された会社を伴う、より緊密で多くは恒久的なパートナーシップである。

## 例 {/*#examples*/}

- **A7高速道路の拡幅** (ドイツ): EUROVIA、ROHDE、STUTZによる作業共同体、BockenemとNortheim-Nord間の6車線化、2023年に終了
- **Stuttgart 21**: Züblin、HOCHTIEF、Deutsche Bahnなどによる大規模な鉄道インフラプロジェクト。トンネル、深基礎、構造の専門知識を結集した
