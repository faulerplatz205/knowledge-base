# 合併の種類

企業が合併する際には、**合併の方向**によって種類が決まる。主な種類は、水平的、垂直的、斜め (異業種) の3つである。

## 水平的合併 {/*#horizontal-merger*/}

**水平的合併**は、**同じ業界**のバリューチェーンの**同じ段階**で事業を行う企業、典型的には直接の競合企業を結合する。

**目標**: 市場シェアを拡大し、競争を排除し、規模の経済を実現する。

**例**: 2つの自動車メーカーの合併、または2つのリテール銀行の統合。

## 垂直的合併 {/*#vertical-merger*/}

**垂直的合併**は、同じバリューチェーンの**異なる段階**で事業を行う企業、すなわち供給業者と顧客を結合する。

方向は2つある。

- **前方統合**: 最終顧客に近い事業を買収する (例: メーカーが小売チェーンを買収する)
- **後方統合**: 原材料に近い事業を買収する (例: メーカーが部品供給業者を買収する)

**目標**: サプライチェーンを確保し、外部パートナーへの依存を減らし、中間業者を排除してコストを削減する。

**例**: 自動車メーカーによる鉄鋼供給業者の買収 (後方)、または生産者による自社の販売網の買収 (前方)。

## 斜めの合併 {/*#diagonal-merger*/}

**斜めの合併** (**コングロマリット合併**とも呼ばれる) は、サプライチェーン上の直接の関係がない、**まったく無関係な業界**の企業を結合する。

**目標**: 事業を多角化し、異なる市場にリスクを分散し、新たな収益源を開拓する。

**例**: 製造業の企業による金融サービス会社の買収、またはメディア企業による物流事業者の買収。

## 比較 {/*#comparison*/}

| 種類     | 関与する企業                           | 主な目標                   |
| -------- | -------------------------------------- | -------------------------- |
| 水平的   | 同じ業界、同じ段階                     | 市場シェア、規模           |
| 垂直的   | 同じ業界、異なる供給段階               | 供給の確保、コスト削減     |
| 斜め     | 異なる業界                             | 多角化                     |
