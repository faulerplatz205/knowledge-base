# ジョイントベンチャー

**ジョイントベンチャー**とは、少なくとも2つの独立した企業による協力であり、多くは新会社を共同で設立するか、プロジェクトで契約に基づいて協働する形をとる。提携企業は、それ以外の面では独立したままである。

## 種類 {/*#types*/}

- **ローカル、地域、国内**: 同じ国または地域の企業が手を組む (例: 地域のプロジェクトのため)
- **国際**: 異なる国の企業が、海外市場に参入するために合弁会社を設立する (自動車産業で非常に多い)

## 動機 {/*#motives*/}

- 新しい市場に参入し、新しい顧客に到達する (例: 海外市場)
- コスト、リスク、利益を分担する
- ノウハウと資源 (技術、研究) を結集する
- 法的要件に対応する (例: 中国はかつて、外国企業にジョイントベンチャーを通じた生産のみを求めていた)

## 独立性への影響 {/*#effect-on-independence*/}

- **法的には**: パートナーは独立したままであり、事業のために新たな法人が設立されることが多い
- **経済的には**: パートナーは他の事業分野では独立したままだが、ベンチャーでは緊密に協力し、責任、利益、損失を分かち合う

## 利点と欠点 {/*#advantages-and-disadvantages*/}

| 利点                             | 欠点                   |
| -------------------------------- | ---------------------- |
| コストとリスクの分担             | パートナー間の対立     |
| 新しい市場と顧客へのアクセス     | 利益が分配される       |
| ノウハウと資源の結合             | パートナーへの依存     |
| 競争上の地位の強化               | 意思決定が遅くなる     |

## 競争と経済への影響 {/*#effects-on-competition-and-economy*/}

- **他の企業**: 企業が手を組むことで競合相手が減るが、他の企業も協力する動機を持つ場合がある
- **消費者**: 新しい製品や技術、場合によっては低価格がもたらされるが、ブランドの多様性は減る
- **経済**: イノベーション、成長、外国からの投資を促すが、市場の集中のリスクがある

## 作業共同体およびコンソーシアムとの比較 {/*#comparison-with-working-group-and-consortium*/}

どちらの形態も、独立した企業が特定の目的のために協力するものだが、範囲と構造が異なる。

| 観点               | ジョイントベンチャー                              | 作業共同体 / コンソーシアム                    |
| ------------------ | ------------------------------------------------- | ---------------------------------------------- |
| 期間               | 長期または継続的であることが多い                  | プロジェクト単位で、プロジェクト終了時に解散   |
| 新たな法人         | 通常はあり (例: 共同設立のGmbH)                   | なし、通常は民法上の組合                       |
| 範囲               | より広い戦略的目標 (市場参入、製品ライン)         | 明確に定められた単一のプロジェクト             |
| 資源               | 共同で管理され、プールされる                      | 各構成員が独立して拠出する                     |
| 利益の分配         | 設立契約で明示的に合意される                      | 合意に従ってパートナー間で分配される           |

要するに、ジョイントベンチャーは、資源を共有し、多くは新会社を伴う、より緊密で、しばしば恒久的なパートナーシップであり、作業共同体やコンソーシアムは1つのプロジェクトに限定された一時的な提携であり、その後パートナーはそれぞれの道に分かれる。

## 利益共同体との比較 {/*#comparison-with-interest-group*/}

どちらの形態も独立した企業間の協力を伴うが、構造と目的が異なる。

| 観点         | ジョイントベンチャー                           | 利益共同体                                        |
| ------------ | ---------------------------------------------- | ------------------------------------------------- |
| 法的形態     | 新たに設立された法人であることが多い (例: GmbH) | 独自の法的形態はなく、多くは民法上の組合          |
| 契約の厳格さ | 形式的に規定され、権利と義務が明確に定められる | 非公式で、決まった形式は不要                      |
| 目的         | 範囲が定められた特定のプロジェクトまたは目標   | 幅広く継続的な共通の利益 (ロビー活動、コスト分担) |
| 損益の分配   | パートナー間で明示的に合意される               | 必ずしも合意されない                              |
| 典型的な期間 | プロジェクト単位または期間限定であることが多い | 期限の定めなし                                    |

要するに、ジョイントベンチャーは、特定の目的を達成するために、多くは新設会社を通じて設けられる、より緊密な契約上のパートナーシップであり、利益共同体は共通の目標を追求するための、より緩やかで多くは非公式な取り決めである。

## 例 (自動車、中国) {/*#examples-automotive-china*/}

| ジョイントベンチャー | 詳細                                      |
| -------------------- | ----------------------------------------- |
| Volkswagen & SAIC    | 中国でのVW車の生産 (1984年から)          |
| BMW & Brilliance     | BMWのモデルを生産する50:50のジョイントベンチャー |
| Daimler & BAIC       | 中国でのMercedesの生産 (Beijing Benz)     |
| Sony & Ericsson      | Sony Ericssonの携帯電話                   |
