# フランチャイズ

**フランチャイズ**とは、独立した事業者 (**フランチャイジー**) が、対価を支払って、別の企業 (**フランチャイザー**) の実績ある事業コンセプトを利用する権利を与えられる、事業提携の一形態である。フランチャイザーは、ブランド、ノウハウ、製品、マーケティング戦略、研修を提供する。

## 期間 {/*#duration*/}

フランチャイズ契約は通常、期間が限定されており (例: **5年から10年**)、期間満了時に更新または終了できる。

## 種類 {/*#types*/}

1. **商品フランチャイズ**: フランチャイジーがフランチャイザーの製品を販売する (例: 自動車ディーラー、飲料の流通)
2. **サービスフランチャイズ**: フランチャイジーがフランチャイザーのブランドの下でサービスを提供する (例: フィットネススタジオ、学習指導)
3. **システムフランチャイズ**: フランチャイジーが完全な事業コンセプトを引き継ぐ (例: McDonald's、Subway、Fressnapf)

## 独立性への影響 {/*#effect-on-independence*/}

- **法的には**: フランチャイジーは独立したままである
- **経済的には**: フランチャイジーは従属しており、価格、広告、品揃えに関するフランチャイザーの規則に拘束される

## 動機 {/*#motives*/}

**フランチャイザーにとって:**

- 少ない資本支出での急速な拡大
- 独立した事業者の意欲の活用

**フランチャイジーにとって:**

- 確立されたブランドの利用
- 開業リスクの低減
- 研修、マーケティング、運営面の支援

## 利点と欠点 {/*#advantages-and-disadvantages*/}

|          | フランチャイザー                                                 | フランチャイジー                                                   |
| -------- | ---------------------------------------------------------------- | ------------------------------------------------------------------ |
| **利点** | 店舗を所有せずにブランドを拡大でき、継続的な手数料収入が得られる | 実績ある事業モデル、研修とマーケティングの支援、低いリスク         |
| **欠点** | 品質管理が難しく、フランチャイジーの行動に左右される             | 高額な手数料と初期投資、企業家としての自由が少ない、契約による拘束 |

## 競争、消費者、経済への影響 {/*#effects-on-competition-consumers-and-economy*/}

- **競争**: 大手ブランドを強化し、小規模事業者への圧力となる
- **消費者**: 一貫した品質と高い認知度
- **経済**: 雇用を創出し、起業を促進する

## 例 {/*#examples*/}

McDonald's、Fressnapf、Backwerk、KFC、Subway

## コンツェルンとの区別 {/*#distinction-from-a-corporate-group*/}

フランチャイズでは、パートナーは**法的にも経済的にも別個の企業**のままであり、ブランドとコンセプトを共有するにすぎない。コンツェルンでは、子会社も法的には独立しているが、親会社によって**中央から管理**される。
