# 競争当局

**競争当局**とは、競争の制限、市場支配力の濫用、独占の形成を防ぐために、国家機関が競争法を監視し執行する措置の総体を指す。ドイツでは主に**連邦カルテル庁**がこれを担う。

## 3つの柱 {/*#three-pillars*/}

### カルテルの摘発 {/*#cartel-prosecution*/}

連邦カルテル庁は、価格協定、市場分割、その他の企業間の秘密協定を発見し、追及する。

| 利点                 | 欠点               |
| -------------------- | ------------------ |
| 価格協定から保護する | 証拠の収集が難しい |
| 公正な市場を促進する | 国際的な差異がある |

### 企業結合規制 {/*#merger-control*/}

| 利点                     | 欠点                 |
| ------------------------ | -------------------- |
| 大型合併による独占を防ぐ | 営業の自由を侵害する |
| 競争の継続を確保する     | 国際的な差異がある   |

### 濫用の監督 {/*#abuse-supervision*/}

| 利点                             | 欠点                   |
| -------------------------------- | ---------------------- |
| 大企業による権力濫用から保護する | 評価が複雑である       |
|                                  | 過剰規制のリスクがある |

## 市場支配力の濫用の類型 {/*#types-of-abuse-of-market-power*/}

市場支配的な企業は、主に2つの方法でその地位を濫用し得る。

- **搾取的濫用**: 支配的企業が、顧客や供給業者を搾取するために、正当化できないほど高い価格を要求したり、不公正な条件を課したりする。
- **排除的濫用**: 支配的企業が、たとえば不可欠なインフラへのアクセスを拒否することで、競争相手を妨害する。典型例は、不当な競争上の優位を得るために、通信会社が競合他社の自社ネットワークへのアクセスを遮断することである。

## 効果 {/*#effects*/}

- **公正な市場環境**を作り出し、どの企業も違法な優位を得られない
- 市場における**透明性と信頼**を高める
- 企業は実力で競争せざるを得なくなる
- **抑止効果**: 年間売上高の最大**10%**に上る制裁金
- 消費者: 価格の低下、選択肢の拡大、品質の向上

## 最近の事例 {/*#recent-examples*/}

**承認された合併:**

- ルフトハンザとITA Airways (2024年7月)
- MicrosoftとActivision Blizzard (2023年末に完了、2024年に実施)

**却下された合併:**

- AmazonとiRobot (2024年1月)
- AdobeとFigma (2023年末)

**その他の措置:**

- **Google** (2025年): Google Maps Platformに関する制限の撤廃を強制された
- **Amazon** (2026年2月): 連邦カルテル庁が特定の価格管理の仕組みを禁止し、5,900万ユーロの利益を没収した
