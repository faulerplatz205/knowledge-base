# 合併とトラスト

**合併**とは、2つ以上の企業を1つの主体に統合することを指す。すべての資産、権利、義務、契約は新会社 (または存続会社) に移り、従前の企業の少なくとも1社は法的に消滅する。

## 合併の2つの形態 {/*#two-forms-of-merger*/}

- **吸収合併**: 一方の企業が他方を吸収する
- **新設合併**: 複数の企業が合わさって、まったく新しい主体になる

## 独立性への影響 {/*#effect-on-independence*/}

- 合併する企業は、**法的にも経済的にも独立性を失う**
- 新会社または存続会社に完全に吸収される

## 動機 {/*#motives*/}

- コストを削減し、効率を高める
- 市場シェアを拡大する
- ノウハウを結集する
- 財務力を強化する
- 新しい市場に参入する

## 利点と欠点 {/*#advantages-and-disadvantages*/}

| 利点                 | 欠点                             |
| -------------------- | -------------------------------- |
| 市場での地位の強化   | 独立性の喪失                     |
| コスト削減           | 統合上の問題                     |
| ノウハウの結集       | 高額な費用 (法務、再編)          |
| 財務力の増大         | 人員削減の可能性                 |
| 新しい市場へのアクセス | 期待したシナジーが実現しない場合がある |

## 周囲への影響 {/*#effects-on-environment*/}

| 影響を受ける対象 | 想定される影響                                                   |
| ---------------- | ---------------------------------------------------------------- |
| 他の企業         | 競争の激化、排除、小規模企業への圧力                             |
| 消費者           | 価格上昇の可能性、選択肢の減少、効率化によってより良い製品が得られる場合もある |
| 経済全体         | 生産性の向上、ただし市場支配力の集中と独占のリスク               |

## 合併の結果としてのトラスト {/*#trust-the-result-of-a-merger*/}

合併が**過程**であるのに対し、**トラスト**は**結果**である。複数の企業が統一的な経営の下で完全に結合し、独立性を放棄して、経済的には1つの企業として行動する。

## 類似の形態との区別 {/*#distinction-from-similar-forms*/}

- **カルテル**: 企業は独立したままで、行動を調整するにとどまる
- **コンツェルン**: 企業は法的には独立したままだが、共通の支配下にある
- **トラスト**: 企業は完全に合併し、独立性を失う

## 例 {/*#examples*/}

- **Daimler-BenzとChrysler** (1998年): 合併してDaimlerChryslerとなった
- **DisneyとPixar** (2006年): DisneyがPixarを完全に買収した
