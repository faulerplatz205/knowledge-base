# カルテル

**カルテル**とは、本来は互いに競争するはずの企業が、競争を制限または排除するために協調する協定を指す。目的は、競争の縮小による利益の増大である。

## ドイツ競争法における分類 {/*#categories-under-german-competition-law*/}

### 原則として禁止されるカルテル {/*#generally-prohibited-cartels*/}

- **価格カルテル**: 企業が価格や入札での応札額について合意する
- **地域カルテル**: 競争を避けるために市場を分割する
- **計算カルテル**: 統一的な価格算定方式を定める
- **数量カルテル**: 固定の生産量を取り決める

例: 価格、販売地域、割当量について合意した**砂糖カルテル**。

### 届出が必要なカルテル {/*#notification-required-cartels*/}

- **条件カルテル**: 統一的な取引条件と支払規則
- **割引カルテル**: すべての顧客に同一の割引
- **専門化カルテル**: 各企業が特定の製品に特化する
- **規格化カルテル**: 統一的な製品規格や型式

### 承認が必要なカルテル {/*#approval-required-cartels*/}

- **構造的不況カルテル**: 危機時に生産を共同で縮小する
- **シンジケート**: 全構成員の受注と支払を扱う共同販売機関

例: **E.ON / Innogyの合併**は、エネルギー分野での合算市場シェアが大きくなるため、連邦カルテル庁への届出が必要であった。

## 独立性への影響 {/*#effect-on-independence*/}

- **法的には**: 企業は形式上独立したままだが、行動の自由はカルテル協定によって制限される
- **経済的には**: 価格、数量、販売政策に対する自主的な管理を失う

## カルテル形成の動機 {/*#motives-for-cartel-formation*/}

- 競争の縮小による利益の最大化
- 価格の安定
- コスト削減
- 市場支配力

## 利点と欠点 {/*#advantages-and-disadvantages*/}

| 利点                           | 欠点                       |
| ------------------------------ | -------------------------- |
| 競争の緩和による利益の増加     | 違反時の高額な制裁金       |
| 協調した行動によるリスクの低減 | 他のカルテル参加者への依存 |

## 他者への影響 {/*#effects-on-others*/}

- **他の企業**: 新規参入者にとって市場参入が難しくなる
- **消費者**: 価格の上昇、選択肢の減少
- **経済**: 自由市場への信頼の喪失
