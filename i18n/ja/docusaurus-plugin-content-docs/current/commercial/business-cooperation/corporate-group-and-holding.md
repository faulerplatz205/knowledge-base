# コンツェルンとホールディング

**コンツェルン**とは、統一的な指揮の下にある、法的に独立した企業の結合を指す。**ホールディング**はその特殊な形態であり、親会社が子会社の持分を保有し、戦略的な方向付けを行う。

## 構造 {/*#structure*/}

- **コンツェルン**: 階層的 (親会社 / 子会社) であり、親会社が子会社を支配する
- **ホールディングの種類**:
  - **純粋持株会社**: 持分の管理のみを行う
  - **事業持株会社**: 自らの事業活動も行う

## コンツェルンの形態 {/*#forms-of-corporate-groups*/}

### 従属コンツェルン {/*#subordination-group*/}

- 親会社が戦略的な意思決定を行う
- 子会社は**法的には独立**しているが、**経済的には従属**している
- 例: Audi、Porsche、Skodaを擁する**Volkswagen AG**

### 対等コンツェルン {/*#coordination-group*/}

- 支配的な親会社が存在しない
- 企業同士が相互に持分を保有するか、共通の指導部を持つ
- 力関係はより均衡しているが、実際にはまれである

## 独立性への影響 {/*#effect-on-independence*/}

- **法的には**: 子会社は独立した法人のままである
- **経済的には**: コンツェルンの中央指揮に服する

## 利点と欠点 {/*#advantages-and-disadvantages*/}

| 利点                 | 欠点                             |
| -------------------- | -------------------------------- |
| 財務力と市場支配力   | 企業家としての独立性の喪失       |
| 共通の戦略           | 権力濫用のリスク                 |
| シナジーの活用       | 複雑な管理                       |
| リスクの分散         | 競争の減少                       |
| 資本調達の容易さ     | コンツェルンと子会社の利害の対立 |

## 例 {/*#examples*/}

- **Oetkerグループ**: 多角化 (食品、海運、ホテル)
- **Procter & Gamble**: 国際的な消費財 (Pampers、Gillette、Ariel)
- **Nestlé**: 世界最大の食品グループ (KitKat、Nescafé、Maggi)
- **Volkswagen AG**: Audi、Porsche、Skodaを傘下に持つ
