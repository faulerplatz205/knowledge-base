# 利益共同体

**利益共同体**とは、共通の経済的または政治的な目的のために共通の利益を追求する、自然人または法人による契約に基づく連合を指す。これは**独自の法的形態ではなく**、構成員は法的に独立したままである。

## 法的・経済的な独立性 {/*#legal-and-economic-independence*/}

- 独自の法的形態ではなく、明確な法的定義もない
- 契約の形式に要件はなく、登録や届出の義務もない
- 通常は民法上の組合として構成されるが、他の形態も可能である
- 経済的には、構成員は有形・無形の資源を共有でき、コストを下げて収益性を高められる
- 生産タスクを分割することで、個々の構成員が単独では得られない経済的独立性を得られる場合がある

## 動機 {/*#motives*/}

- より大きな影響力、知識、行動の余地を得る
- 共通の利益 (経済的、社会的、政治的) を対外的に代表する
- 経験を交換する
- 共同のプロジェクト、研究、マーケティングを行う
- 共通の価値観を促進する

## 利点と欠点 {/*#advantages-and-disadvantages*/}

| 利点                                   | 欠点                                       |
| -------------------------------------- | ------------------------------------------ |
| 資源を束ね、効率的に目標を達成できる   | 妥協が必要となり、自らの利益が損なわれ得る |
| 政治、市場、世論に対する存在感が高まる | 対立や依存のリスク                         |
| ノウハウ、経験、資源の交換             | 組織上の負担                               |
| より安価で効果的な共同プロジェクト     | 競争制限の可能性                           |

## 他者への影響 {/*#effects-on-others*/}

- **他の企業**: (大量購入による) 供給業者の価格低下の恩恵を受けられるが、部外者がその価格に対抗できない場合は排除のおそれがある
- **消費者**: より安価で、場合によっては高品質な製品が得られるが、多様性が減り、イノベーションが乏しくなる可能性がある
- **経済**: 市場を安定させ、需給の衝撃を和らげるが、少数の主体が支配する場合は独占的構造のリスクがある

## ジョイントベンチャーとの比較 {/*#comparison-with-joint-venture*/}

どちらの形態も独立した企業間の協力を伴うが、構造と目的が異なる。

| 観点         | 利益共同体                                        | ジョイントベンチャー                           |
| ------------ | ------------------------------------------------- | ---------------------------------------------- |
| 法的形態     | 独自の法的形態はなく、多くは民法上の組合          | 新たに設立された法人であることが多い (例: GmbH) |
| 契約の厳格さ | 非公式で、決まった形式は不要                      | 形式的に規定され、権利と義務が明確に定められる |
| 目的         | 幅広く継続的な共通の利益 (ロビー活動、コスト分担) | 範囲が定められた特定のプロジェクトまたは目標   |
| 損益の分配   | 必ずしも合意されない                              | パートナー間で明示的に合意される               |
| 典型的な期間 | 期限の定めなし                                    | プロジェクト単位または期間限定であることが多い |

要するに、利益共同体は共通の目標を追求するための、より緩やかで多くは非公式な取り決めであり、ジョイントベンチャーは、通常は特定の目的を達成するために、多くの場合は新設会社を通じて設けられる、より緊密な契約上のパートナーシップである。

## 例 {/*#examples*/}

- **ToyotaとSubaru**: ディーゼルエンジンに関する共同研究開発 (競合関係のままコストを分担)
- **H&MとIKEA**: 持続可能性の要件を満たすための、再生素材の生産に関する協力
