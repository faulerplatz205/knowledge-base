# 経済原則

お金、時間、材料、労働力といった資源は希少である。そのため**経済原則** (*合理原則*とも呼ばれる) は、**インプット** (投入される手段) と**アウトプット** (得られる成果) の比率をできるだけ有利にすることを求める。

## 形態 {/*#forms*/}

| 形態     | 固定されるもの | 規則                                                                  |
| -------- | -------------- | --------------------------------------------------------------------- |
| 最大原則 | インプット     | 与えられたインプットで、可能な限り大きなアウトプットを達成する。      |
| 最小原則 | アウトプット   | 与えられたアウトプットを、可能な限り少ないインプットで達成する。      |
| 最適原則 | どちらもなし   | 両者の比率ができるだけ有利になるよう、インプットとアウトプットを選ぶ。 |

## 例 {/*#examples*/}

- **最大原則:** IT部門にノートPC用の予算が20,000 EURあり、それで要件を満たす機種をできるだけ多く購入する。
- **最小原則:** IT部門が所定の仕様のノートPCを15台必要とし、[見積比較](./offer-comparison.md)によって合計価格が最も低い仕入先を決定し、そこで購入する。
- **最適原則:** 企業が固定の予算も固定の機能範囲もなくWebショップを計画し、費用対効果が最も良くなる予算と機能の組み合わせを選ぶ。
