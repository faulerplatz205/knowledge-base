# 見積計算

## 概要 {/*#overview*/}

見積計算は、仕入価格に関連するすべての費用、上乗せ、税金を加えて、製品の販売価格を決定する。卸売や小売で用いられる標準化された段階的なスキームに従う。

## 計算スキーム {/*#calculation-scheme*/}

### 仕入側 {/*#purchase-side*/}

| 演算 | 項目 | 備考 |
| --------- | ---------------------- | ----------------------------- |
|           | 定価仕入価格 | 仕入先のカタログ価格 |
| −         | 仕入先値引き | 定価に対する%の値引き |
| =         | 正味仕入価格 |                               |
| −         | 仕入先現金割引 | 早期支払いに対する%の値引き |
| =         | 現金仕入価格 |                               |
| +         | 調達費用 | 運送費、関税 |
| =         | **原価** | 商品の真のコスト |

### 販売側 {/*#sales-side*/}

| 演算 | 項目 | 備考 |
| --------- | ---------------------------- | -------------------------------------------------- |
|           | 原価 | 上記から引き継ぐ |
| +         | 間接費上乗せ | 運営費、賃料、人件費など |
| =         | 損益分岐価格 |                                                    |
| +         | 利益上乗せ | 目標とする利益率 |
| =         | 現金販売価格 |                                                    |
| +         | 顧客現金割引 | 加算し直す: 顧客への早期支払い割引を可能にする |
| =         | 正味販売価格 |                                                    |
| +         | 顧客値引き | 加算し直す: 顧客への値引きを可能にする |
| =         | 税抜定価販売価格 |                                                    |
| +         | 付加価値税 | 例: ドイツでは19% |
| =         | **税込定価販売価格** | 顧客への最終価格 |

## 注記 {/*#notes*/}

- Skonto(現金割引)とRabatt(値引き)は、顧客が請求しうる控除の可能性を表すため、販売側で**加算し直される**。販売価格はこれらを賄えなければならない
- 間接費上乗せは、通常、企業の実際の運営費に基づいて、原価に対する割合として表される
- 計算は、順方向(仕入価格から販売価格へ)でも、逆方向(目標販売価格から必要な仕入価格を導出)でも行える
