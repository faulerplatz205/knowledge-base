# AIDAモデル

**AIDAモデル**は、成功した広告が見込み客を最初の接触から購入へと導く、連続する4つの段階を表す。このモデルはアメリカの広告の先駆者エルモ・ルイス (1898年) に由来し、広告の設計と評価の両方に用いられる。広告は、顧客自身がまだ気づいていない[潜在的ニーズ](./needs-and-demand.md#types-of-needs)に訴えることが多い。

## 段階 {/*#stages*/}

| 段階                      | 目的                                                         | 典型的な手段                                                                 |
| ------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| **Attention (注意)**      | 競合する刺激の中で広告が気づかれる。                         | 目を引く画像、色や音楽、珍しい見出し、有名人の顔                             |
| **Interest (関心)**       | 顧客が製品についてもっと知りたいと思う。                     | 機能や利点の情報、製品が解決する問題                                         |
| **Desire (欲求)**         | 顧客が製品を所有したいと思う。                               | 感情への訴求、現状との比較、レビュー、希少性                                 |
| **Action (行動)**         | 顧客が意図された行動、通常は購入を行う。                     | 行動喚起、「今すぐ購入」ボタン、期間限定の割引、簡単な注文手続き             |

意図される行動は購入とは限らない。ニュースレターの登録、試乗、見積依頼も広告の目標になり得る。

## 例 {/*#example*/}

スマートフォンメーカーがソーシャルメディアで新モデルを宣伝する。

| 段階      | 実施内容                                                                                 |
| --------- | ---------------------------------------------------------------------------------------- |
| Attention | 目を引く動画とキャッチーな音楽が、フィードをスクロールする中で際立つ。                   |
| Interest  | 動画で新しいカメラと印象的な夜景写真が示される。                                         |
| Desire    | 古いスマートフォンの写真と比べて、視聴者が「これが欲しい」と思う。                       |
| Action    | 48時間有効の割引付き「今すぐ購入」ボタンが、そのまま注文へ導く。                         |

## 拡張 {/*#extensions*/}

- **AIDAS:** *Satisfaction (満足)* を加える。満足した顧客は再び購入し、製品を推薦するため、購入後の満足も広告目標の一部となる。
- **AIDCA:** DesireとActionの間に*Conviction (確信)* を加える。顧客はテスト結果や保証などの論拠によって、購入が正しい判断であると確信する。

## 限界 {/*#limitations*/}

- 実際の購入判断は直線的ではない。衝動買いでは段階が飛ばされ、高額な購入では、モデルが扱わない調査や比較が行われる。
- このモデルは顧客を受動的な存在として捉えている。現在の顧客は、レビュー、比較サイト、ソーシャルメディアなどを通じて、自ら情報を探すことが多い。

## よくある間違い {/*#common-mistakes*/}

1. **InterestとDesireの混同:** Interestは製品についてもっと知りたいという望みであり、Desireは製品を所有したいという望みである。技術データを読んでいる顧客は関心を持っているが、必ずしも購入を望んでいるわけではない。
