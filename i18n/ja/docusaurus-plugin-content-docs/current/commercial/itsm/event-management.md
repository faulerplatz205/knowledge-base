# イベント管理

## 概要 {/*#overview*/}

**イベント**は、ユーザーからの直接の報告を必要としない。モニタリングシステムによって自動的に生成され、システムの状態に関するステータスメッセージを表す。「イベント」という用語は、関連度によって分類されるトリガーまたは受信通知として理解できる。

ソフトウェアによる支援でフィルタリングが可能になり、例外メッセージが担当者にできるだけ早く転送されるように設定できる。

## イベントの種類 {/*#event-types*/}

### 情報 {/*#information*/}

**対応を必要としない、システムに関するステータスメッセージ**。

システムは正常に動作しており、介入は不要である。

**例:** ネットワーク使用率が45%から48%の間にある。

### 警告 {/*#warning*/}

**より綿密な監視の必要性を示すステータスメッセージ**であり、まもなく対応が必要になる可能性がある。警告は、問題が近づいていることを知らせる。

**例:** RAIDデータアレイが、残り容量20%を報告している。

### 例外 {/*#exception*/}

**直ちに対応を必要とするステータスメッセージ**。システムまたはサービスが停止したか、重大なしきい値を超えている。例外は通常、[インシデント](./incident-management.md)につながる。

**例:** 48ポートのネットワークスイッチが故障した。

## イベント分類の例 {/*#event-classification-examples*/}

| イベント                                                         | 種類 | 理由                                                         |
| ---------------------------------------------------------------- | ---- | ------------------------------------------------------------ |
| ハードドライブの容量が80%                                       | 警告 | まだ問題ではないが、まもなく問題になり得る                   |
| ネットワークが負荷40%で安定稼働                                 | 情報 | システムの正常な状態                                         |
| Webベースの基幹業務システム (ERP) に到達できない                 | 例外 | 直ちに対応を要する停止                                       |
| Webサーバーが負荷85%で安定稼働                                  | 警告 | 負荷が高く、危険域に近づいている                             |
| 50件のUser CALライセンスのうち48件が使用中                       | 警告 | ライセンス上限にほぼ到達。超過すると例外になる               |
| 52台のデバイスが接続されているが、Device CALライセンスは50件のみ | 例外 | ライセンス上限を超過                                         |
