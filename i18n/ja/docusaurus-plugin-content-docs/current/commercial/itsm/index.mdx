# ITサービスマネジメント(ITSM)

ITILフレームワークに基づくITサービスマネジメントの中核的な概念とプロセス。ヘルプデスクでの最初の問い合わせから、インシデント管理、問題管理、変更管理、リリース管理に至るまで、サービスリクエストがどのように分類、優先度付け、解決されるかを扱う。
