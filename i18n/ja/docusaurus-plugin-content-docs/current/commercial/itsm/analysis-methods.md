# 問題分析手法

## 概要 {/*#overview*/}

これらの手法は、[問題管理](./problem-management.md)において、問題の根本原因を体系的に突き止めるために用いられる。

## 5回のなぜ (5-W-Methode) {/*#5-why-method-5-w-methode*/}

**目的:** 「なぜ?」を繰り返し問い、各回答を次の問いにすることで、問題の根本原因を突き止める。通常は5回の反復で十分である。

**例 (プリンターの問題):**

| ステップ | 問い                                         | 答え                                                              |
| -------- | -------------------------------------------- | ----------------------------------------------------------------- |
| 問題     | プリンターがはっきり印刷しない               |                                                                   |
| なぜ?    | なぜプリンターははっきり印刷しないのか?      | すべての文字がはっきり表示されない / 出力が読み取れない          |
| なぜ?    | なぜすべての文字がはっきり表示されないのか?  | インク/トナーの品質が悪い                                         |
| なぜ?    | なぜインク/トナーの品質が悪いのか?           | にじみ、まったく印刷されないこともある                            |
| なぜ?    | なぜにじんだり、印刷されなかったりするのか?  | トナーの品質が低い                                                |
| なぜ?    | なぜトナーの品質が低いのか?                  | **最も安いトナーを購入した** (根本原因)                           |

## 石川ダイアグラム (特性要因図) {/*#ishikawa-diagram-fishbone-diagram*/}

**石川ダイアグラム** (**原因結果図**または**特性要因図**とも呼ばれる) は、日本の科学者、石川馨が1940年代に開発した。問題の原因を可視化する。

**構造:**

- 右を向く水平の矢印 => **先端に問題の記述** (結果)
- 水平線から斜めに伸びる矢印 => **主要な影響カテゴリ** (「骨」)
- 斜めの骨から伸びる小さな矢印 => **副次的な原因** (Nebenursachen)

**矢印の意味:** 各矢印は、先端に記述された結果に「寄与する」ことを表す。

### 主要な影響カテゴリ (8M) {/*#main-influence-categories-8m*/}

- カテゴリ
- 材料 (Material)
- 人 (People)
- 機械 (Machine)
- 方法 (Method)
- マネジメント (Management)
- 環境 (Environment)
- 測定 (Measurement)
- 資金 (Money)

問題に応じて、他の影響カテゴリも可能である。

### 石川ダイアグラムの作成 {/*#creating-an-ishikawa-diagram*/}

1. 水平の矢印の先端 (最も右) に問題の記述を書く
2. 主要な影響カテゴリ (8M) を定義する
3. チームのブレインストーミングで主要な原因を見つける (水平軸に平行な矢印として描く)
4. 各主要原因について副次的な原因を見つける (主要原因の矢印から分岐する斜めの矢印として描く)

## DMAICサイクル {/*#dmaic-cycle*/}

**DMAICサイクル**は、複雑な問題やプロジェクトに用いられる。略語は5つのフェーズを表す。

| フェーズ    | 主要な問い                   | 手法 / ツール                                                                                                          |
| ----------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Define**  | 問題は何か?                  | 顧客フィードバック、問題定義、スコープ、KPI分析、RACIマトリクス                                                        |
| **Measure** | 問題はどれほど大きいか?      | 現状 (IST) 分析、[SLA](./sla.md)の確認、エスカレーションレベルの明確化                                                     |
| **Analyse** | 根本原因は何か?              | 5回のなぜ、顧客調査、[エラーデータベース](./problem-management.md#known-error-database-kedb)、石川ダイアグラム        |
| **Improve** | 解決策を開発できるか?        | シミュレーション、テスト運用、解決策マトリクス、石川ダイアグラム                                                       |
| **Control** | 改善を維持できるか?          | モニタリング、サービス管理システム                                                                                     |

## 問題解決マトリクス / 原因結果マトリクス (Problemlösungsmatrix / Ursachen-Wirkungs-Matrix) {/*#problemlösungsmatrix--ursachen-wirkungs-matrix*/}

**原因結果マトリクス** (ケプナー・トリゴー法に基づく) は、問題を4つの次元で分析し、「である」ことと「でない」ことを比較して、根本原因を体系的に絞り込む。

| 次元                       | である (問題)                     | でない (問題)                          | 差異                                    | 考えられる原因                 |
| -------------------------- | --------------------------------- | -------------------------------------- | --------------------------------------- | ------------------------------ |
| **特定 (何が)**            | 問題は何か?                       | 問題でないものは何か?                  | 現状と目標状態の差はどうなっているか?   | 考えられる原因は何か?          |
| **場所の特定 (どこで)**    | 問題はどこで発生するか?           | どこでは発生しないか?                  | その場所では何が異なるか?               | 考えられる原因は何か?          |
| **時間 (いつ)**            | 問題はいつ現れたか?               | いつ現れなかったか?                    | そのとき何が異なっていたか?             | 考えられる原因は何か?          |
|                            | どの期間に問題が確認されたか?     | どの期間には現れなかったか?            | その期間中に何が異なっていたか?         |                                |
| **重大性 (どれくらい)**    | 問題はどれほど大きい/広範か?      | どれほど小さい、または限定的か?        | 範囲の違いはどうなっているか?           | 考えられる原因は何か?          |
|                            | いくつ (台数) が影響を受けているか? | いくつ (台数) が影響を受けていないか? |                                         |                                |
|                            | どの部分が影響を受けているか?     | どの部分が影響を受けていないか?        |                                         |                                |
