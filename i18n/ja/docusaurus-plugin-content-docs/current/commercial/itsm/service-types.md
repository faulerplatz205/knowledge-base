# ITサービスの種類

## 概要 {/*#overview*/}

ITサービスは、提供方法と管理主体によって分類できる。ここでは、各フレームワークにおける「サービス」の主な定義、代表的なITサービスの種類、IMAC/R/Dライフサイクル、およびITSMの主要用語を扱う。

## サービスの定義 {/*#service-definitions*/}

| 出典 | 定義 |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BSI    | 「サービスとは、タスクを遂行するためのオブジェクトとプロセスの組み合わせである。」 |
| FitSM  | 「サービスとは、顧客の目標を支援することによって顧客に価値を提供する手段である。」 |
| ITIL 4 | 「サービスとは、顧客が特定のコストとリスクを自ら管理することなく、顧客が達成したい成果を促進することで、価値の共創を可能にする手段である。」 |

**品質は納得させ、サービスが決め手となる。**

## ITサービスの種類の概要 {/*#it-service-types-overview*/}

| サービスの種類 | 説明 |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IT Sales / IT Trade | ITシステムおよびコンポーネントの調達(セットアップとネットワーク接続を含む) |
| IT Service | ITによって、またITのために実現されるあらゆるサービス |
| Break/Fix Support / Field Service / On-Site Service | 顧客先で要請に応じて実施されるITサービス。作業費と部品代が請求される。Field Service Management (FSM) によって最適化される |
| On-Site Management | 顧客の拠点でのITサービスの提供 |
| Swap Service | 同一の交換用機器がユーザーに提供される |
| DIY Service | 顧客自身がサービスを実施する(メーカーの許可あり。例: 保証は有効のまま) |
| Cloud Service | クラウドプロバイダーが提供するすべてのサービス |
| Live Chat | ウィジェットやアプリを介して、顧客がWebサービス提供者のスタッフにリアルタイムで接続される |
| Chatbot | Webサイト、アプリ、ソーシャルメディアに組み込まれ、ユーザーと自動的にやり取りするAI搭載システム。ハイブリッド型のチャットボットはライブチャットも提供する |
| Managed Services | Managed Services Provider (MSP) による継続的なITサービス。範囲と品質は事前にSLAで合意される。例: プロアクティブな監視とリモートメンテナンス |
| Warranty Service | 保証または品質保証の請求に基づく無償サービス |
| Goodwill | 受託者による任意の無償サービス |
| Helpdesk Service | オンラインのヘルプデスクを通じて提供されるサービス |
| Maintenance Service | 保守契約の範囲内のサービス |
| Repair Service | 修理サービス |
| IT Outsourcing / IT Sourcing | ITサービスの外部調達。専門のITサービスプロバイダーが、解決の難しいタスクを効率的に処理する |
| IT Induction | 顧客および従業員へのITシステムの導入説明 |
| IT Training / IT Instruction | 有償での顧客への研修と教育 |

## IMAC/R/Dライフサイクル {/*#imacrd-lifecycle*/}

**IMAC/R/D**ライフサイクルは、IT機器の導入から廃棄までの各フェーズを表す。

| 文字 | フェーズ | 説明 |
| ------ | ----------------- | ----------------------------------------------------------------------------------------------------------- |
| **I**  | Install | 調達、事前インストール(ステージング)、および最終設置場所での運用開始 |
| **M**  | Move | 機器の移動。例: オフィス移転や社内組織の再編時 |
| **A**  | Add | ハードウェアやソフトウェアの追加。例: RAMの増設や新しいプログラムのインストール |
| **C**  | Change | 構成の変更、またはユーザー権限やポリシーの調整 |
| **R**  | Remove / Rollback | 機器のアンインストールとIT資産への返却 |
| **D**  | Dispose | 安全なデータ消去(データイレージャー)、その後のリマーケティング(再販)、または環境に配慮した廃棄 |

## ITSMの主要用語 {/*#key-itsm-terms*/}

| 用語 | 説明 |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Service Desk**                                                           | ユーザーの窓口。ヘルプデスクとも呼ばれる |
| **ITSM**                                                                   | IT Service Management: ITサービスの計画、提供、運用、管理のためにITサービスプロバイダーが行うすべての活動の総体 |
| **Service Portfolio**                                                      | 提供されるすべてのITサービスの集合。サービスカタログ、ガイドライン、責任範囲を含む |
| **[SLA](./sla.md)**                                                        | Service Level Agreement: プロバイダーと顧客の間で結ばれるサービスレベルに関する契約上の合意 |
| **OLA**                                                                    | Operational Level Agreement: ITチームや部門間の内部的な合意 |
| **KPI**                                                                    | Key Performance Indicator: 重要なビジネス目標に沿った指標。例: サービスの可用性やサービス中断の件数 |
| **SOA**                                                                    | Service-Oriented Architecture: ビジネスプロセスとシステムがモジュール化され、再利用可能なITサービスを介して連携される |
| **[IaaS](../../cloud/service-models.md#infrastructure-as-a-service-iaas)** | Infrastructure as a Service: アプリケーションの基盤としてインフラストラクチャを提供するクラウドプラットフォーム |
| **Service Availability 24/7**                                              | サービスが常時利用可能である |
| **Service Availability 12/5**                                              | サービスが通常の営業時間内に利用可能である |
