# ファイルシステムの種類

**ファイルシステム**は、記憶装置上でデータをどのように整理して保存するかを定める。ファイルシステムは、最大ファイルサイズ、ジャーナリングのサポート、読み書きできるオペレーティングシステムによって異なる。

## 概要 {/*#overview*/}

| ファイルシステム | 最大ファイルサイズ | ジャーナリング          | 典型的な用途                                    |
| ---------- | ------------- | ------------------- | ---------------------------------------------- |
| FAT32      | 4 GB          | なし                  | USBメモリ、SDカード、幅広い互換性      |
| exFAT      | 16 EB         | なし                  | プラットフォームをまたぐ大容量のUSBメモリとSDカード |
| NTFS       | 16 EB         | あり                 | Windowsのシステムドライブとデータドライブ                 |
| ext4       | 16 TB         | あり                 | Linuxの標準ファイルシステム                       |
| APFS       | 8 EB          | あり(コピーオンライト) | macOSの標準ファイルシステム                 |
| btrfs      | 16 EB         | あり(コピーオンライト) | Linux、スナップショットとプーリングに対応              |

## ファイルシステムの選び方 {/*#choosing-a-filesystem*/}

- **最大限の互換性(小さなファイル):** FAT32はほぼすべてのデバイスで読み書きできるが、1ファイルあたり4 GBに制限される。
- **最大限の互換性(大きなファイル):** exFATは4 GBの制限を取り除き、Linux、Windows、macOSで動作する。
- **Linuxのみ:** ext4が安全な標準であり、btrfsはスナップショットなどの高度な機能を追加する。
- **Windowsのみ:** NTFSはアクセス許可、ジャーナリング、大容量ボリュームをサポートする。
- **macOSのみ:** APFSはSSD向けに最適化されており、現代の標準である。
