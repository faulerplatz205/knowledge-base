# アナログ-デジタル変換器 (ADC)

## ADCが必要な理由 {/* #why-an-adc-is-needed */}

センサーは物理量(温度、光、圧力など)を測定し、比例する**アナログ**信号、通常は連続的な電圧を出力する。マイクロコントローラーやRaspberry Piが処理できるのは**デジタル**値のみである。多くのボード(例: Raspberry Pi)にはアナログ入力がまったくなく、`0`または`1`しか読み取れない。

**アナログ-デジタル変換器 (ADC)** はこの隔たりを埋める。アナログ電圧をサンプリングし、デジタルの数値として符号化する。結果は、多くの場合I²Cなどのバスを介してコントローラーに転送される。

## 分解能と量子化ステップ {/* #resolution-and-quantization-steps */}

ADCの**分解能**は**ビット**数で示される。ビット数は、変換器が出力できる異なるデジタル値(**量子化ステップ**)の数を決定する。

```text
Number of steps = 2^n        (n = resolution in bits)
```

- 8ビット  => 2^8  = 256ステップ
- 10ビット => 2^10 = 1024ステップ
- 16ビット => 2^16 = 65536ステップ

ビット数が多いほど入力範囲がより細かく分割され、測定がより正確になる。

## 測定分解能(検出可能な最小の変化) {/* #measurement-resolution-smallest-detectable-change */}

**測定分解能**は、異なるデジタル値に対応づけられる最小の電圧変化である。電圧範囲をステップ数で割った値となる。

```text
Resolution = voltage range / number of steps
```

**例:** 10ビットのADCが0 Vから10 Vの範囲を測定する。

```text
Steps = 2¹⁰ = 1024 steps
Resolution = 10 V / 1024 steps = 0.009766 V ≈ 9.77 mV
```

約9.77 mVより小さい変化は、この変換器では区別できない。

## 測定値から2進出力へ {/* #from-a-measured-value-to-a-binary-output */}

物理的な測定値をADCのデジタル出力へ変換する作業は、3つのステップで行われる。

**シナリオ:** 温度センサーが-20 °Cから+80 °Cをカバーし、0 Vから10 Vの比例電圧を出力する。ADCの分解能は10ビットである。ちょうど25 °Cに対応する2進値はいくつか。

**ステップ1: 測定値を電圧に対応づける。**

まず単位あたりの電圧を求め、次に値が最小値をどれだけ上回っているかを掛ける。

```text
Voltage span / temperature span = 10 V / 100 °C = 0.1 V per °C

25 °C is 45 °C above the minimum of -20 °C
U = 45 °C x 0.1 V = 4.5 V
```

**ステップ2: 電圧をデジタル値に変換する。**

```text
Digital value = (U / voltage range) x number of steps
Digital value = (4.5 V / 10 V) x 1024 = 460.8 ≈ 461
```

出力は整数にしかなりえないため、結果は最も近い整数のステップに丸められる。

**ステップ3: 値を2進数で表す。**

```text
461 = 0001 1100 1101
```

:::info
一部の教科書では、最大入力が最高コードにちょうど対応するように、`2^n`(1024)ではなく`2^n - 1`(ここでは1023)で割る。どちらの慣例も実務で見られ、分解能が高いほどその差は無視できる。このページでは、ステップ数に合わせて`2^n`を用いる。
:::
