# 画像のストレージサイズ

## ピクセルと色深度 {/* #pixels-and-colour-depth */}

ラスター画像は、**ピクセル**の格子で構成される。**解像度**はピクセル数であり、幅 x 高さ(例: `1920 x 1080`)、または**メガピクセル**での合計(1 MP = 1,000,000ピクセル)として示される。

**色深度**は、各ピクセルが色を保存するために使用するビット数を表す。`n` ビットでは、1つのピクセルは `2ⁿ` 種類の色を取ることができる。

| 色深度 | 色数    | 名称                                                       |
| ------------ | ---------- | ---------------------------------------------------------- |
| 1ビット        | 2          | モノクロ(白黒)                               |
| 8ビット        | 256        | グレースケールまたはインデックスカラー                                |
| 16ビット       | 65,536     | ハイカラー                                                 |
| 24ビット       | 16,777,216 | トゥルーカラー。赤、緑、青にそれぞれ8ビット            |
| 32ビット       | 16,777,216 | トゥルーカラーに8ビットのアルファチャンネル(透明度)を加えたもの        |

---

## 計算式 {/* #formula */}

```text
Storage size in bits  = number of pixels x colour depth
Storage size in bytes = number of pixels x colour depth ÷ 8
```

結果は、生の非圧縮の画像データのサイズである。JPEGやPNGなどの形式はこのデータを圧縮し、どのファイルにもヘッダーとメタデータが加わる。実際のファイルは計算値とは異なる。

---

## 例 {/* #example */}

50メガピクセル、色深度24ビットの写真:

```text
Pixels:        50 MP x 10⁶ = 50,000,000 pixels
Bits:          50,000,000 x 24 bit = 1,200,000,000 bit
Bytes:         1,200,000,000 bit ÷ 8 = 150,000,000 B
Decimal:       150,000,000 B ÷ 10⁶ = 150 MB
Binary:        150,000,000 B ÷ 2²⁰ ≈ 143.05 MiB
```

解像度が幅 x 高さで与えられている場合は、まずピクセル数を計算する。

```text
Pixels:        1920 x 1080 = 2,073,600 pixels
Bytes:         2,073,600 x 24 bit ÷ 8 = 6,220,800 B
Decimal:       6,220,800 B ÷ 10⁶ ≈ 6.22 MB
Binary:        6,220,800 B ÷ 2²⁰ ≈ 5.93 MiB
```

---

## よくある間違い {/* #common-mistakes */}

1. **8での除算の欠落:** ピクセル数と色深度の積はビット数である。8で割らないと、結果は8倍大きくなる。例: 150 MBではなく1,200 MB。
2. **メガピクセルを1,024²で計算すること:** メガピクセルの接頭辞メガは常に10進である。50 MPは50,000,000ピクセルであり、52,428,800ではない。
3. **MBとMiBの混同:** 150,000,000 Bは150 MBだが、およそ143.05 MiBにすぎない。変換先の単位が除数を決める。MBでは10⁶、MiBでは2²⁰である([ビット、バイト、単位変換](./bit-byte-conversions.md)を参照)。
4. **色数を色深度として使うこと:** トゥルーカラーは16,777,216色だが、各ピクセルは24ビットを保存する。計算式で使うのは色数ではなくビット数である。
