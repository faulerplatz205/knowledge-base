# 周波数(Hz)とパルス幅変調(PWM)

## 周波数(Hz) {/*#frequency-hz*/}

**周波数**は、周期的な信号が1秒あたり何回繰り返されるかを表す。単位は**ヘルツ (Hz)** であり、1 Hzは1秒あたり1周期に等しい。

周波数 `f` と、1周期の長さである**周期** `T` は、互いに逆数の関係にある。

```text
f = 1 / T        (frequency  = 1 / period)
T = 1 / f        (period     = 1 / frequency)
```

**例:** ある信号が1 ms(0.001 s)ごとに繰り返される。

```text
f = 1 / 0.001 s = 1000 Hz = 1 kHz
```

## PWMが解決する問題 {/*#the-problem-pwm-solves*/}

デジタルのGPIO出力は、2つの状態しか供給できない。**HIGH**(たとえば3.3 V)または**LOW**(0 V)である。その中間の値はない。しかし、LEDの調光、モーターを半分の速度で動かす、パッシブ[ブザー](./raspberry-pi.md)を駆動するなど、多くの用途では中間の値が必要になる。

**パルス幅変調(PWM)**は、出力をHIGHとLOWの間で非常に高速に切り替えることでこれを解決する。HIGHの時間と周期全体の比率が、供給される*平均*電力を決定し、接続された機器はこれを、完全なオフと完全なオンの間の値として知覚する。

## デューティ比 {/*#duty-cycle*/}

**デューティ比**(ドイツ語では*Puls-Pause-Verhältnis*)は、1周期のうち信号がHIGHである割合である。

```text
Duty cycle = (t_on / T) x 100%

t_on = time HIGH within one period
T    = t_on + t_off (full period)
```

| デューティ比 | 信号                       | 効果(3.3 V時)      |
| ---------- | ---------------------------- | ---------------------- |
| 0 %        | 常にLOW                   | 完全にオフ              |
| 25 %       | 時間の1/4がHIGH         | 低電力              |
| 50 %       | 時間の半分がHIGH           | 半分の電力             |
| 75 %       | 時間の3/4がHIGH         | 高電力             |
| 100 %      | 常にHIGH                  | 完全にオン               |

**例:** 周期1 msのうち、信号が0.25 msの間HIGHである。

```text
Duty cycle = (0.25 ms / 1 ms) x 100% = 25%
```

## 平均出力レベル {/*#average-output-level*/}

機器が受け取る平均電圧は、デューティ比に比例して変化する。

```text
U_avg = duty cycle x U_max
```

**例:** 3.3 Vの出力をデューティ比50 %で動作させる。

```text
U_avg = 0.5 x 3.3 V = 1.65 V
```

:::note
PWMは電圧を実際に下げるわけでは**ない**。出力は0 Vと最大レベルの間を切り替え続ける。切り替えが機器の反応できる速度より速いため、機器は平均値を受け取ったかのように*振る舞う*にすぎない。
:::

## HIGH時間の計算 {/*#calculating-the-high-time*/}

上記の式を組み合わせると、選択した周波数とデューティ比に対するHIGH時間が得られる。

```text
T = 1 / f
t_on = duty cycle x T
```

**例:** 1 kHzの信号をデューティ比25 %で動作させる。

```text
T = 1 / 1000 Hz = 0.001 s = 1 ms
t_on = 0.25 x 1 ms = 0.25 ms
```

## 典型的な用途 {/*#typical-applications*/}

- **LEDの調光:** デューティ比が高いほど、LEDは明るくなる。
- **モーターとファンの速度:** 比較的高い周波数で出力がHIGHとLOWの間で切り替えられ、その比率が電力、ひいては速度を決める。
- **パッシブ[ブザー](./raspberry-pi.md)での音:** PWM信号の*周波数*が、音の高さを決める。
