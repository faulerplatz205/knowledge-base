# OSI参照モデル

## 概要 {/*#overview*/}

OSI (Open Systems Interconnection) モデルは、異なるネットワークシステム同士がどのように通信するかを標準化する概念的な枠組みである。通信を**7つの層**に分割し、各層に特定の役割を与える。このモデルはベンダー中立であり、プロトコルがどのように相互作用するかを理解するための基準として機能する。

## 7つの層 {/*#the-7-layers*/}

| #   | 名称         | 主な責務                      |
| --- | ------------ | --------------------------------------- |
| 7   | アプリケーション  | ユーザーが直接利用するプロトコルとサービス      |
| 6   | プレゼンテーション | データの整形、エンコード、暗号化   |
| 5   | セッション      | アプリケーション間のセッション管理 |
| 4   | トランスポート    | プロセス間のエンドツーエンドの配信   |
| 3   | ネットワーク      | 論理アドレッシングとルーティング          |
| 2   | データリンク    | ローカルネットワーク内でのフレームの配信   |
| 1   | 物理     | 媒体上での生のビット伝送      |

## 各層の詳細 {/*#layer-details*/}

### 第1層 – 物理層 {/*#layer-1--physical*/}

物理的な媒体(ケーブル、無線、光ファイバー)上で生のビットを伝送する。電圧レベル、ピン配置、ビットのタイミングを定義する。アドレッシングの概念はない。

**例:** イーサネットケーブル、Wi-Fiの無線信号、光ファイバー、ハブ、リピーター

### 第2層 – データリンク層 {/*#layer-2--data-link*/}

ビットを**フレーム**にまとめ、**MACアドレス**を使って単一のネットワークセグメント内での配信を扱う。CRCによる伝送エラーの検出も行う。

**サブ層:** LLC (Logical Link Control) と MAC (Media Access Control)

**例:** イーサネット、Wi-Fi (802.11)、ARP、スイッチ

### 第3層 – ネットワーク層 {/*#layer-3--network*/}

**論理アドレッシング**(IP)と、複数のネットワークをまたぐパケットのルーティングを扱う。送信元から宛先までの最適な経路を決定する。

**例:** IP (IPv4、IPv6)、ICMP、ルーター

### 第4層 – トランスポート層 {/*#layer-4--transport*/}

プロセス間の**エンドツーエンドの通信**を提供する。セグメント化、再構成、フロー制御、エラー回復を管理する。

- **TCP**: コネクション指向で、信頼性があり、順序が保証された配信
- **UDP**: コネクションレスで、より高速だが、配信は保証されない

**例:** TCP、UDP、ポート番号

### 第5層 – セッション層 {/*#layer-5--session*/}

アプリケーション間の**セッション**(論理的な接続)を確立、管理、終了する。長いデータ転送のための同期とチェックポイントをサポートする。

**例:** NetBIOS、RPC、セッショントークン

### 第6層 – プレゼンテーション層 {/*#layer-6--presentation*/}

アプリケーションの形式とネットワークの形式の間でデータを変換する。エンコード、シリアライズ、圧縮、暗号化を扱う。

**例:** TLS/SSL(暗号化)、JSON、XML、JPEG、MPEG

### 第7層 – アプリケーション層 {/*#layer-7--application*/}

ユーザーに最も近い層。アプリケーションに直接ネットワークサービスを提供する。アプリケーション自体ではなく、アプリケーションが使用するプロトコルを指す。

**例:** HTTP、HTTPS、FTP、SMTP、DNS、SSH
