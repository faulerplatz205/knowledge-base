# SI接頭辞

SI接頭辞は、非常に大きな量や非常に小さな量を表すために基本単位に付ける、標準化された倍数である。  
メートル、グラム、秒、ボルト、ワット、ヘルツなど、あらゆるSI単位に適用できる。

## 一般的な接頭辞 {/*#common-prefixes*/}

表は、最大の接頭辞から最小の接頭辞の順に並べている。基本単位(係数1)は中央に位置する。

| 接頭辞 | 記号   | 係数                  | べき乗 | 例              |
| ------ | ------ | --------------------- | ----- | --------------- |
| テラ   | T      | 1,000,000,000,000     | 10¹²  | TB, THz         |
| ギガ   | G      | 1,000,000,000         | 10⁹   | GHz, GW         |
| メガ   | M      | 1,000,000             | 10⁶   | MW, MΩ          |
| キロ   | k      | 1,000                 | 10³   | km, kg, kV, kWh |
| —      | —      | 1                     | 10⁰   | m, g, V, W      |
| デシ   | d      | 0.1                   | 10⁻¹  | dl, dm          |
| センチ | c      | 0.01                  | 10⁻²  | cm              |
| ミリ   | m      | 0.001                 | 10⁻³  | mm, mV, ms      |
| マイクロ | µ    | 0.000001              | 10⁻⁶  | µs, µm, µF      |
| ナノ   | n      | 0.000000001           | 10⁻⁹  | nm, ns          |
| ピコ   | p      | 0.000000000001        | 10⁻¹² | pF, ps          |

:::info
「主要な」系列(キロ => メガ => ギガ => テラ、およびミリ => マイクロ => ナノ => ピコ)は、接頭辞ごとに**1,000**(10³)ずつ変化する。**デシ**と**センチ**は、基本単位とミリの間にある、より小さな中間段階(10⁻¹と10⁻²)である。
:::

## 接頭辞間の換算 {/*#scaling-between-prefixes*/}

各接頭辞は10のべき乗である(上の[べき乗](#common-prefixes)の列を参照)。2つの接頭辞間で換算するには、べき乗の差を求め、それをステップ数として適用する。

### 上方向(小さい => 大きい) {/*#upward-smaller--larger*/}

```text
Formula: value / 10^steps

Example: 2,500 mV => V
Steps: mV (10⁻³) => V (10⁰) = 3 powers of 10
2,500 mV / 10³ = 2.5 V
```

### 下方向(大きい => 小さい) {/*#downward-larger--smaller*/}

```text
Formula: value x 10^steps

Example: 5 km => mm
Steps: km (10³) => mm (10⁻³) = 6 powers of 10
5 km x 10⁶ = 5,000,000 mm
```

## 実務での一般的な例 {/*#common-examples-in-practice*/}

- **kV** — キロボルト、1,000 V(高圧送電線)
- **mA** — ミリアンペア、0.001 A(小型電子機器)
- **MHz** — メガヘルツ、1,000,000 Hz(無線周波数、CPUクロック)
- **nm** — ナノメートル、0.000000001 m(半導体のプロセスノード、光の波長)
- **kWh** — キロワット時、1,000 Wh(電気料金の請求書)
- **µF** — マイクロファラド、0.000001 F(コンデンサの値)
