# IPv6 (Internet Protocol Version 6)

## 概要 {/*#overview*/}

IPv6はIPv4の後継であり、32ビットのIPv4アドレス空間の枯渇を克服するために導入された。IPv6アドレスの長さは**128ビット**で、2¹²⁸(およそ3.4 x 10³⁸)個のアドレスが利用可能である。

アドレスは**16ビットの8つのグループ**(*ヘクテット*または*グループ*と呼ばれる)として書かれ、各グループは4桁の16進数で表され、コロンで区切られる(`:`)。

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
```

- 8グループ x 16ビット = 128ビット
- 16進数の桁は大文字と小文字を区別しない(`ff00` は `FF00` と等しい)。ただし、小文字が推奨される正規の形式である

## アドレスの構造 {/*#address-structure*/}

典型的なIPv6ユニキャストアドレスは、それぞれ64ビットの2つの半分に分けられる。

| 部分               | 長さ  | 用途                                                  |
| ------------------ | ------- | -------------------------------------------------------- |
| **ネットワークプレフィックス** | 64ビット | ネットワークを識別する(ルーティングプレフィックス + サブネットID)。     |
| **インターフェースID**   | 64ビット | そのネットワーク内の個々のインターフェースを識別する。 |

プレフィックス長はCIDR表記で書かれ、例: `2001:db8:abcd:1234::/64`。`/64` は、単一のサブネットの標準的なサイズである。

## 短縮(圧縮) {/*#shortening-compression*/}

2つの規則により、IPv6アドレスをより簡潔に書くことができる。両者は組み合わせて使える。

### 規則1: 先頭のゼロを削除する {/*#rule-1-remove-leading-zeros*/}

各グループ内で、先頭のゼロは省略できる。グループごとに少なくとも1桁は残さなければならない。

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
2001:db8:0:0:0:ff00:42:8329
```

### 規則2: ゼロのグループの連続を1か所だけ圧縮する(`::`) {/*#rule-2-collapse-one-run-of-zero-groups-*/}

すべてゼロの1つ以上のグループが連続している部分を、1か所だけ二重コロン `::` で置き換えることができる。

```text
2001:db8:0:0:0:ff00:42:8329
2001:db8::ff00:42:8329
```

**重要:** `::` はアドレス内に**1回しか**現れてはならない。そうでなければ長さが曖昧になる。同じ長さのゼロの連続が2つある場合は、最も左側のものを圧縮するのが望ましい。

```text
fe80:0:0:0:1:0:0:1   =>   fe80::1:0:0:1   (correct)
fe80:0:0:0:1:0:0:1   =>   fe80::1::1      (invalid, two "::")
```

## 展開 {/*#expanding*/}

展開は圧縮を元に戻し、128ビットの完全な形式を復元する。比較や手作業でのサブネット計算に役立つ。

1. **`::` を復元する** – 存在するグループを数え、合計で8グループになるのに必要な数の `0` グループを挿入する。
2. **各グループを埋める** – すべてのグループが4桁の16進数になるまで、先頭にゼロを加える。

```text
2001:db8::ff00:42:8329

Step 1 (restore zero groups, 5 groups present => insert 3):
2001:db8:0:0:0:ff00:42:8329

Step 2 (pad to 4 digits each):
2001:0db8:0000:0000:0000:ff00:0042:8329
```

## アドレスの種類 {/*#address-types*/}

IPv6にはブロードキャストがない。その役割はマルチキャストが担う。

| 種類          | 意味                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------- |
| **ユニキャスト**   | 1対1。単一のインターフェースを識別し、パケットはまさにそのインターフェースに配信される。 |
| **マルチキャスト** | 1対多。マルチキャストグループに参加しているすべてのインターフェースに配信される。                     |
| **エニーキャスト**   | 1対最寄り。複数のインターフェースで共有され、トポロジー上で最も近いものに配信される。  |

## スコープ {/*#scopes*/}

*スコープ*は、アドレスが有効でルーティング可能なネットワークの範囲を定める。最も重要なユニキャストのスコープは次の2つである。

- **リンクローカル** – 直接接続されたリンク(1つのセグメント)でのみ有効。ルーティングされない。すべてのIPv6インターフェースで自動的に設定される。
- **グローバル** – 世界的に一意で、インターネット全体でルーティング可能。パブリックなIPv4アドレスに相当する。

マルチキャストアドレスには、明示的なスコープフィールドがある(例: インターフェースローカル、リンクローカル、サイトローカル、グローバル)。

### リンクローカルのゾーンインデックス {/*#zone-index-for-link-local*/}

リンクローカルアドレス(`fe80::/10`)は複数のインターフェース間で一意ではないため、`%` を付加したゾーンインデックスを使って送信インターフェースを指定する必要がある。

```text
ping fe80::1%eth0      # Linux (interface name)
ping fe80::1%12        # Windows (interface index)
```

## 重要なアドレス {/*#important-addresses*/}

| アドレス / プレフィックス | 名称               | 説明                                                                           |
| ---------------- | ------------------ | ------------------------------------------------------------------------------------- |
| `::/128`         | 未指定        | すべてゼロ。アドレスが割り当てられる前の送信元アドレスとして使われる(`0.0.0.0`に相当)。    |
| `::1/128`        | ループバック           | ローカルホスト。IPv4の `127.0.0.1` に相当する。                                       |
| `fe80::/10`      | リンクローカル         | 自動設定され、ローカルリンクでのみ有効で、ルーティングされない。                          |
| `fc00::/7`       | ユニークローカル (ULA) | 内部使用のプライベートアドレス。インターネット上ではルーティングされない(RFC 1918に相当)。 |
| `2000::/3`       | グローバルユニキャスト     | パブリックで、世界的にルーティング可能なアドレス。                                                  |
| `ff00::/8`       | マルチキャスト          | すべてのマルチキャストアドレスは `ff` で始まる。                                              |
| `ff02::1`        | 全ノード(リンク)   | リンク上のすべてのノードへのマルチキャスト。                                                  |
| `ff02::2`        | 全ルーター(リンク) | リンク上のすべてのルーターへのマルチキャスト。                                                |
| `2001:db8::/32`  | ドキュメント用      | 例示とドキュメント用に予約されており、本番環境では決して使用されない。                    |

## IPv6とIPv4の比較 {/*#ipv6-vs-ipv4*/}

| 特性       | IPv4                   | IPv6                         |
| -------------- | ---------------------- | ---------------------------- |
| アドレス長 | 32ビット                | 128ビット                     |
| 表記       | 10進数、ドット区切り | 16進数、コロン区切り |
| ブロードキャスト      | あり                    | なし(マルチキャストに置き換え)   |
| ループバック       | `127.0.0.1`            | `::1`                        |
| 自動設定    | DHCP / APIPA           | SLAAC + リンクローカル           |
