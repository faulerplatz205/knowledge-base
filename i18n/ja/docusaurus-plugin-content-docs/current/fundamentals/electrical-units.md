# 電気の単位 – 電力、電圧、電流、エネルギー

## 3つの基本単位 {/*#the-three-core-units*/}

| 記号 | 量 | 単位       |
| ------ | -------- | ---------- |
| P      | 電力    | ワット (W)   |
| U      | 電圧  | ボルト (V)   |
| I      | 電流  | アンペア (A) |

## パワートライアングル {/*#the-power-triangle*/}

3つの量は **P = U x I** の式で関係付けられる。求めたい量を隠すと、その式が現れる。

```text
      P
    -----
    U | I
```

- **P = U x I** (電力 = 電圧 x 電流)
- **U = P / I** (電圧 = 電力 / 電流)
- **I = P / U** (電流 = 電力 / 電圧)

## オームの法則 {/*#ohms-law*/}

オームの法則は、抵抗 **R**(単位はオーム、Ω)を導入し、電圧および電流と結び付ける。

ここでも同じトライアングルの方法が当てはまる。

```text
      U
    -----
    R | I
```

- **U = R x I** (電圧 = 抵抗 x 電流)
- **R = U / I** (抵抗 = 電圧 / 電流)
- **I = U / R** (電流 = 電圧 / 抵抗)

## 組み合わせた式 {/*#combined-formulas*/}

電力の式とオームの法則を組み合わせると、電力を計算する方法がさらに得られる。

- **P = U² / R**
- **P = I² x R**

## 例 {/*#examples*/}

**例1:** ある機器が230 Vで動作し、2 Aの電流が流れる。消費電力(P)はいくらか。

```text
P = U x I = 230 V x 2 A = 460 W
```

**例2:** 100 Wの電球が230 Vで動作する。流れる電流(I)はいくらか。

```text
I = P / U = 100 W / 230 V ≈ 0.43 A
```

**例3:** 50 Ωの抵抗に3 Aが流れる。抵抗の両端の電圧降下はいくらか。

```text
U = R x I = 50 Ω x 3 A = 150 V
```

## 電気的仕事(エネルギー) {/*#electrical-work-energy*/}

電気的仕事 **W**(エネルギーとも呼ばれ、**E** と書かれることもある)は、機器が一定の時間にわたって消費または生成するエネルギーの量である。SI単位は**ジュール (J)** であるが、日常的な電気の分野では**ワット時 (Wh)** または**キロワット時 (kWh)** で表されることが多い。

基本となる式は次のとおり。

- **W = P x t** (仕事 = 電力 x 時間)

**P** を **U x I** に置き換えると、先に **P** を計算することなく、**U**、**I**、**t** から直接 **W** を計算できる形になる。

- **W = U x I x t**

### エネルギーの一般的な単位 {/*#common-units-of-energy*/}

| 単位          | 記号 | 等価                 |
| ------------- | ------ | ---------------------- |
| ジュール         | J      | 1 W x 1 s              |
| ワット時     | Wh     | 3,600 J                |
| キロワット時 | kWh    | 1,000 Wh = 3,600,000 J |

:::info
記号 **W** は、単位「ワット」(電力の単位)と量「仕事」の両方に使われる。意味は通常、文脈から明らかである。混同を避けるために、「仕事」に **E** を使う文献もある。
:::

### 例 {/*#examples-1*/}

**例1:** 60 Wの電球が5時間点灯する。消費するエネルギーはいくらか。

```text
W = P x t = 60 W x 5 h = 300 Wh = 0.3 kWh
```

**例2:** ある機器が230 Vで2 Aの電流を30分間流す。使用するエネルギーはいくらか。

```text
W = U x I x t = 230 V x 2 A x 0.5 h = 230 Wh
```

**例3:** 電気料金の請求書に、1 kWhあたり0.30ユーロで250 kWhの消費量が記載されている。合計金額はいくらか。

```text
Cost = 250 kWh x €0.30/kWh = €75.00
```
