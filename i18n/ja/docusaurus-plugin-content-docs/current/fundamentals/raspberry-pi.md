# Raspberry Piの概要

## Raspberry Piとは {/*#what-is-a-raspberry-pi*/}

Raspberry Piは小型のシングルボードコンピューターである。通常のポート(USB、HDMI、ネットワーク)に加えて、電子部品を直接接続できる一列の**GPIOピン**を備えており、ハードウェアプロジェクトで人気のあるプラットフォームとなっている。

## GPIOピン {/*#gpio-pins*/}

**GPIO**は*General-Purpose Input/Output*の略である。ピンヘッダーには、複数の種類のピンが含まれる。

- **電源ピン:** 部品に電力を供給する、固定の**3.3 V**および**5 V**の出力。
- **グランドピン(GND):** 電流の共通の基準および帰路。
- **I/Oピン:** 自由にプログラムでき、読み取り(**入力**)または設定(**出力**)が可能なピン。

GPIOのI/Oピンは純粋に**デジタル**であり、**HIGH**(3.3 V)と**LOW**(0 V)しか扱えない。アナログ電圧を直接測定できないため、アナログセンサーには間に[アナログ-デジタル変換器(ADC)](./analog-digital-converter.mdx)が必要である。逆に、アナログに近い出力は[パルス幅変調(PWM)](./pulse-width-modulation.md)で近似される。

## センサーとアクチュエーター {/*#sensors-vs-actuators*/}

部品は、正反対の2つの役割に分けられる。

- **センサー**は、環境からの物理量(温度、湿度、圧力、加速度など)を**電気信号**に変換する部品である。
- **アクチュエーター**はセンサーの対となるもので、まったく逆の働きをする。**電気信号**を、動き、圧力、音、光などの物理量に変換する。

| 役割     | 方向                        | 例                             |
| -------- | -------------------------------- | ------------------------------------ |
| センサー   | 環境 => 電気信号 | 温度センサー、光センサー     |
| アクチュエーター | 電気信号 => 環境 | モーター、ランプ/LED、スピーカー、ブザー |

## ブレッドボード {/*#the-breadboard*/}

**ブレッドボード**を使うと、はんだ付けなしで部品を接続できる。ワイヤーや部品の足を穴に差し込むだけでよい。同じ内部ストリップに属する穴は、電気的に接続されている。

- 端に沿った2本の長い**電源レール**(`+` と `-` で示される)は、ボードの端から端まで通っている。通常は3.3 V / 5 Vのピンと、GNDピンから1回だけ給電されるため、電源とグランドがどこでも利用できる。
- 内側の**端子ストリップ**は、各短い列の穴同士を接続し、ボードの中央にある溝で分けられている。

同じ接続されたストリップに差し込まれた部品は電気的な接続を共有し、これによって回路が構成される。

## 部品の接続 {/*#connecting-components*/}

ほとんどの部品は、明確に定義されたいくつかの接続を備えている。最も一般的な3つは、**電源(VCC / `+`)**、**グランド(GND / `-`)**、**信号**線である。

| 部品          | 役割     | 接続                  | 補足                             |
| ------------------ | -------- | ---------------------------- | ----------------------------------------------- |
| LED / ランプ         | アクチュエーター | アノード(`+`)、カソード(`-`)   | 長い足が `+`、短い足が `-`           |
| 温度センサー | センサー   | VCC(`+`)、GND(`-`)、信号 | 信号が測定値をGPIOピンに運ぶ |
| ブザー             | アクチュエーター | `+`(信号)、`-`(GND)      | 信号が音を切り替えるか駆動する         |

### 一般的なピンの表記 {/*#common-pin-labels*/}

センサーモジュールやブレイクアウトボードは、接続を文字で書き表すことはほとんどなく、各ピンの横に標準化された短い略語が印字されている。

- **VDD / VDC / VCC(`+`):** 正の電源電圧(電源入力)。`VDD` と `VCC` はチップ設計に由来し、`VDC` は単に「直流ボルト」を意味する。実際には、3つとも電源ピンを示す(例: 3.3 Vまたは5 V)。
- **GND / VSS(`-`):** グランド。電流の共通の基準および帰路。
- **SDA:** **I2C**バスの**データ**線。センサーはこれを通じてPiと値をやり取りする。
- **SCL:** **I2C**バスの**クロック**線。双方の同期を保つ。

**I2C**は2線式のバス(SDA + SCL)で、複数のデジタルセンサーが同じ2つのGPIOピンを共有でき、それぞれが個別にアドレス指定される。I2Cセンサーには[ADC](./analog-digital-converter.mdx)は不要であり、デジタル値への変換はすでにモジュール内部で行われている。

### LED / ランプ {/*#led--lamp*/}

LEDには、極性が固定された2本の足がある。

- **アノード(`+`):** **長い**足。GPIO / 正極側に接続される。
- **カソード(`-`):** **短い**足(縁の平らな部分でも示される)。GNDに接続される。

LEDは必ず**直列抵抗**を通して駆動し、電流を制限しなければならない。抵抗がなければ、LEDは過大な電流を引き込んで焼損する。

### 温度センサー {/*#temperature-sensor*/}

典型的なセンサーモジュールには、3つのピンがある。

- **VCC(`+`):** 電源。例: 3.3 V。
- **GND(`-`):** グランド。
- **信号:** 測定値を運ぶ出力。

信号が**アナログ**(温度に比例した電圧)の場合、GPIOピンに直接入力することはできず、先に[ADC](./analog-digital-converter.mdx)が必要である。

### ブザー {/*#buzzer*/}

ブザーには `+`(信号)と `-`(GND)の2つの接続しかなく、2種類がある。

- **アクティブブザー:** 内部に発振器を持ち、音のオンとオフを切り替えるHIGH / LOWの信号だけで動作する。決まった単一の音を鳴らす。
- **パッシブブザー:** 発振器を持たず、異なる音を鳴らせるが、変化する信号が必要である。音の高さは[PWM](./pulse-width-modulation.md)信号の周波数で決まる。
