# التردد (Hz) وتعديل عرض النبضة (PWM)

## التردد (Hz) {/*#frequency-hz*/}

يصف **التردد** عدد مرات تكرار إشارة دورية في الثانية. ووحدته **الهرتز (Hz)**: 1 Hz يعادل دورة كاملة واحدة في الثانية.

التردد `f` ومدة الدورة الواحدة، أي **الزمن الدوري** `T`، مقلوبان لبعضهما:

```text
f = 1 / T        (frequency  = 1 / period)
T = 1 / f        (period     = 1 / frequency)
```

**مثال:** إشارة تتكرر كل 1 ms (0.001 s).

```text
f = 1 / 0.001 s = 1000 Hz = 1 kHz
```

## المشكلة التي يحلّها PWM {/*#the-problem-pwm-solves*/}

لا يستطيع خرج GPIO رقمي أن يوفر سوى حالتين: **HIGH** (مثلاً 3.3 V) أو **LOW** (0 V). ولا توجد قيمة بينهما. ومع ذلك تحتاج مهام كثيرة إلى قيمة وسطى، مثل تعتيم LED أو تشغيل محرك بنصف السرعة أو قيادة [طنان](./raspberry-pi.md) سلبي.

يحلّ **تعديل عرض النبضة (PWM)** ذلك بتبديل الخرج بين HIGH وLOW بسرعة كبيرة. وتحدد نسبة زمن HIGH إلى الدورة الكاملة القدرة *المتوسطة* المُسلَّمة، ويدركها الجهاز المتصل كقيمة بين الإيقاف الكامل والتشغيل الكامل.

## دورة التشغيل (Duty Cycle) {/*#duty-cycle*/}

**دورة التشغيل** (بالألمانية *Puls-Pause-Verhältnis*) هي حصة الزمن الدوري الواحد التي تكون الإشارة خلالها HIGH:

```text
Duty cycle = (t_on / T) x 100%

t_on = time HIGH within one period
T    = t_on + t_off (full period)
```

| دورة التشغيل | الإشارة                      | التأثير (عند 3.3 V)    |
| ------------ | ---------------------------- | ---------------------- |
| 0 %          | LOW دائماً                   | إيقاف كامل             |
| 25 %         | HIGH ربع الوقت               | قدرة منخفضة            |
| 50 %         | HIGH نصف الوقت               | نصف القدرة             |
| 75 %         | HIGH ثلاثة أرباع الوقت       | قدرة مرتفعة            |
| 100 %        | HIGH دائماً                  | تشغيل كامل             |

**مثال:** إشارة تكون HIGH لمدة 0.25 ms ضمن زمن دوري قدره 1 ms.

```text
Duty cycle = (0.25 ms / 1 ms) x 100% = 25%
```

## مستوى الخرج المتوسط {/*#average-output-level*/}

يتناسب الجهد المتوسط الذي يراه الجهاز خطياً مع دورة التشغيل:

```text
U_avg = duty cycle x U_max
```

**مثال:** خرج 3.3 V يعمل بدورة تشغيل 50 %.

```text
U_avg = 0.5 x 3.3 V = 1.65 V
```

:::note
لا يخفض PWM الجهد فعلياً، فالخرج ما زال يتبدل بين 0 V والمستوى الكامل. ويتصرف الجهاز فقط *كما لو* أنه تلقى المتوسط، لأن التبديل أسرع مما يستطيع الاستجابة له.
:::

## حساب زمن HIGH {/*#calculating-the-high-time*/}

يعطي الجمع بين الصيغ السابقة زمن HIGH لتردد ودورة تشغيل مختارين:

```text
T = 1 / f
t_on = duty cycle x T
```

**مثال:** إشارة 1 kHz بدورة تشغيل 25 %.

```text
T = 1 / 1000 Hz = 0.001 s = 1 ms
t_on = 0.25 x 1 ms = 0.25 ms
```

## التطبيقات النموذجية {/*#typical-applications*/}

- **تعتيم LED:** كلما ارتفعت دورة التشغيل ازداد سطوع LED.
- **سرعة المحرك والمروحة:** بتردد مرتفع نسبياً يُبدَّل الخرج بين HIGH وLOW، وتحدد النسبة القدرة، ومن ثم السرعة.
- **النغمات على [طنان](./raspberry-pi.md) سلبي:** *تردد* إشارة PWM يحدد حدّة النغمة.
