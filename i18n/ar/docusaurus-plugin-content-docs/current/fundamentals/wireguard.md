# WireGuard

## ما هو WireGuard؟ {/*#what-is-wireguard*/}

WireGuard هو بروتوكول VPN حديث ينشئ أنفاقًا مشفرة بين الأجهزة. صُمم ليكون أبسط وأسرع بكثير من البروتوكولات الأقدم مثل IPsec أو OpenVPN، بقاعدة شيفرة أصغر بكثير (نحو 4,000 سطر مقابل مئات الآلاف).

يعمل WireGuard على **[طبقة الشبكة](./osi-model.md#layer-3--network) (الطبقة 3)** وينشئ واجهة شبكة افتراضية على كل جهاز. تُشفَّر حركة المرور الموجَّهة عبر تلك الواجهة وتُرسل إلى النظراء عبر UDP.

---

## كيف يعمل {/*#how-it-works*/}

يستخدم WireGuard مفهومًا يُسمى **التوجيه بمفتاح التشفير (cryptokey routing)**: يُعرَّف كل نظير بمفتاحه العام، ويحدد كل نظير عناوين IP التي يمكن الوصول إليها عبره.

```text
[Interface]
PrivateKey = <your private key>
Address    = 10.0.0.1/24
ListenPort = 51820

[Peer]
PublicKey  = <peer's public key>
AllowedIPs = 10.0.0.2/32
Endpoint   = 203.0.113.5:51820
```

عندما يطابق عنوان IP الوجهة لحزمة صادرة `AllowedIPs` الخاص بنظير ما، يشفّرها WireGuard ويرسلها إلى `Endpoint` الخاص بذلك النظير. أما الحزم الواردة فتُفكّ تشفيرها وتُقبل فقط إذا وصلت من مفتاح عام معروف وكان عنوان IP المصدر ضمن `AllowedIPs` الخاص بذلك النظير.

## المفاهيم الأساسية {/*#key-concepts*/}

### أزواج المفاتيح {/*#key-pairs*/}

لكل واجهة WireGuard **مفتاح خاص** و**مفتاح عام** مشتق منه. تُتبادل المفاتيح العامة خارج النطاق (يدويًا أو بأداة مثل [Tailscale](../tools/tailscale.md)) وتمثّل هوية النظير.

### الواجهة (Interface) {/*#interface*/}

**واجهة** WireGuard هي واجهة شبكة افتراضية (مثل `wg0`) على جهاز. لها عنوان IP خاص بها وتستمع إلى حزم UDP الواردة على منفذ مُعدّ.

### النظير (Peer) {/*#peer*/}

**النظير** هو أي واجهة WireGuard أخرى يُسمح لهذه الواجهة بالتواصل معها. يحدد كل إدخال نظير ما يلي:

- **PublicKey**: المفتاح العام للنظير
- **AllowedIPs**: نطاقات IP التي تُوجَّه حركة مرورها عبر هذا النظير
- **Endpoint** *(اختياري)*: عنوان IP الفعلي للنظير ومنفذ UDP

### AllowedIPs {/*#allowedips*/}

يؤدي `AllowedIPs` غرضين:

- **الصادر**: يعمل كقاعدة توجيه — تُرسل الحزم المتجهة إلى عناوين IP هذه إلى هذا النظير
- **الوارد**: يعمل كمرشح — لا تُقبل الحزم الواردة من هذا النظير إلا إذا كان عنوان IP المصدر ضمن هذا النطاق

يؤدي ضبط `AllowedIPs = 0.0.0.0/0` إلى توجيه كل حركة المرور عبر نظير، وهو أساس إعدادات عقدة الخروج / VPN بنفق كامل.

## التشفير {/*#cryptography*/}

يستخدم WireGuard مجموعة تشفير ثابتة وحديثة — لا توجد مفاوضة، مما يلغي فئة كاملة من هجمات خفض المستوى (downgrade):

| الغرض             | الخوارزمية          |
| ------------------- | ------------------ |
| تبادل المفاتيح        | Curve25519 (ECDH)  |
| التشفير المتماثل    | ChaCha20           |
| المصادقة      | Poly1305 (MAC)     |
| التجزئة             | BLAKE2s            |
| اشتقاق المفاتيح      | HKDF               |

## المقارنة مع بروتوكولات VPN الأخرى {/*#comparison-to-other-vpn-protocols*/}

| الخاصية        | WireGuard     | OpenVPN        | IPsec            |
| --------------- | ------------- | -------------- | ---------------- |
| حجم قاعدة الشيفرة   | نحو 4,000 سطر  | نحو 70,000 سطر  | كبير جدًا       |
| البروتوكول        | UDP فقط      | TCP أو UDP     | UDP / ESP        |
| الإعداد   | بسيط        | معقد        | معقد          |
| الأداء     | سريع جدًا     | متوسط       | سريع             |
| التشفير    | ثابت وحديث | قابل للضبط   | قابل للضبط     |
| اجتياز NAT   | مدمج      | محدود        | يتطلب إضافات  |

## العلاقة مع Tailscale {/*#relation-to-tailscale*/}

يتولى WireGuard **مستوى البيانات** فقط => فهو يشفّر الحزم ويوجّهها بين النظراء. ولا يتولى اكتشاف النظراء ولا توزيع المفاتيح ولا التحكم في الوصول.

[Tailscale](../tools/tailscale.md) مبني فوق WireGuard ويضيف **مستوى تحكم** مُدارًا: تبادل تلقائي للمفاتيح واكتشاف النظراء واجتياز NAT وMagicDNS وACLs. وبذلك يتحقق أداء WireGuard دون أي إعداد يدوي.
