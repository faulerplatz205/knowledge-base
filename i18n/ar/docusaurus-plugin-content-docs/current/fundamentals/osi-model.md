# نموذج OSI

## نظرة عامة {/*#overview*/}

نموذج OSI (الربط البيني للأنظمة المفتوحة) إطار مفاهيمي يوحّد طريقة تواصل أنظمة الشبكات المختلفة فيما بينها. ويقسّم الاتصال إلى **7 طبقات**، لكل منها دور محدد. والنموذج محايد تجاه الشركات المصنِّعة ويُستخدم مرجعاً لفهم كيفية تفاعل البروتوكولات.

## الطبقات السبع {/*#the-7-layers*/}

| #   | الاسم        | المسؤولية الرئيسية                      |
| --- | ------------ | --------------------------------------- |
| 7   | التطبيق      | البروتوكولات والخدمات المواجهة للمستخدم |
| 6   | العرض        | تنسيق البيانات وترميزها وتشفيرها        |
| 5   | الجلسة       | إدارة الجلسات بين التطبيقات             |
| 4   | النقل        | التسليم من طرف إلى طرف بين العمليات     |
| 3   | الشبكة       | العنونة المنطقية والتوجيه               |
| 2   | ارتباط البيانات | تسليم الإطارات داخل الشبكة المحلية   |
| 1   | الفيزيائية   | إرسال البتات الخام عبر وسط              |

## تفاصيل الطبقات {/*#layer-details*/}

### الطبقة 1 – الفيزيائية {/*#layer-1--physical*/}

ترسل البتات الخام عبر وسط فيزيائي (كابلات أو راديو أو ألياف ضوئية). وتحدد مستويات الجهد وتخطيطات الأطراف وتوقيت البتات. ولا مفهوم للعنونة فيها.

**أمثلة:** كابلات Ethernet، وإشارات Wi-Fi الراديوية، والألياف الضوئية، وأجهزة hub، والمكرّرات

### الطبقة 2 – ارتباط البيانات {/*#layer-2--data-link*/}

تجمّع البتات في **إطارات** وتتولى التسليم داخل قطاع شبكة واحد باستخدام **عناوين MAC**. وتكشف كذلك أخطاء الإرسال عبر CRC.

**الطبقتان الفرعيتان:** LLC (التحكم في الارتباط المنطقي) وMAC (التحكم في الوصول إلى الوسط)

**أمثلة:** Ethernet، وWi-Fi (802.11)، وARP، والمحوّلات (switches)

### الطبقة 3 – الشبكة {/*#layer-3--network*/}

تتولى **العنونة المنطقية** (IP) وتوجيه الحزم عبر شبكات متعددة. وتحدد أفضل مسار من المصدر إلى الوجهة.

**أمثلة:** IP (IPv4 وIPv6)، وICMP، وأجهزة التوجيه

### الطبقة 4 – النقل {/*#layer-4--transport*/}

توفر **اتصالاً من طرف إلى طرف** بين العمليات. وتدير التجزئة وإعادة التجميع والتحكم في التدفق واستعادة الأخطاء.

- **TCP**: موجّه بالاتصال، موثوق، تسليم مرتب
- **UDP**: عديم الاتصال، أسرع، بلا ضمان للتسليم

**أمثلة:** TCP وUDP وأرقام المنافذ

### الطبقة 5 – الجلسة {/*#layer-5--session*/}

تنشئ **الجلسات** (الاتصالات المنطقية) بين التطبيقات وتديرها وتنهيها. وتدعم المزامنة ونقاط التحقق لعمليات نقل البيانات الطويلة.

**أمثلة:** NetBIOS وRPC ورموز الجلسة

### الطبقة 6 – العرض {/*#layer-6--presentation*/}

تترجم البيانات بين صيغة التطبيق وصيغة الشبكة. وتتولى الترميز والتسلسل والضغط والتشفير.

**أمثلة:** TLS/SSL (التشفير)، وJSON، وXML، وJPEG، وMPEG

### الطبقة 7 – التطبيق {/*#layer-7--application*/}

الطبقة الأقرب إلى المستخدم. توفر خدمات الشبكة مباشرة للتطبيقات. ولا تشير إلى التطبيقات نفسها، بل إلى البروتوكولات التي تستخدمها.

**أمثلة:** HTTP وHTTPS وFTP وSMTP وDNS وSSH
