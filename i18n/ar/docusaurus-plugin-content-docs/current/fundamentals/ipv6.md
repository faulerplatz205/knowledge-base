# IPv6 (الإصدار السادس من بروتوكول الإنترنت)

## نظرة عامة {/*#overview*/}

IPv6 هو خليفة IPv4، وقد أُدخل للتغلب على استنفاد فضاء عناوين IPv4 ذي 32 بت. يبلغ طول عنوان IPv6 **128 بت**، مما يتيح 2¹²⁸ (نحو 3.4 x 10³⁸) عنواناً ممكناً.

يُكتب العنوان على شكل **8 مجموعات من 16 بت** (تسمى غالباً *hextets* أو *groups*)، تُمثَّل كل منها بـ 4 أرقام ست عشرية وتُفصل بنقطتين رأسيتين (`:`).

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
```

- 8 مجموعات x 16 بت = 128 بت
- الأرقام الست عشرية غير حساسة لحالة الأحرف (`ff00` تساوي `FF00`)، لكن الأحرف الصغيرة هي الصيغة القياسية الموصى بها

## بنية العنوان {/*#address-structure*/}

ينقسم عنوان IPv6 من نوع unicast النموذجي إلى نصفين بطول 64 بت لكل منهما:

| الجزء                | الطول   | الغرض                                                    |
| -------------------- | ------- | -------------------------------------------------------- |
| **بادئة الشبكة**     | 64 بت   | تحدد الشبكة (بادئة التوجيه + معرّف الشبكة الفرعية).      |
| **معرّف الواجهة**    | 64 بت   | يحدد الواجهة الفردية داخل تلك الشبكة.                    |

يُكتب طول البادئة بصيغة CIDR، مثل `2001:db8:abcd:1234::/64`. و`/64` هو الحجم القياسي لشبكة فرعية واحدة.

## الاختصار (الضغط) {/*#shortening-compression*/}

تتيح قاعدتان كتابة عنوان IPv6 بصورة أكثر إيجازاً. ويمكن الجمع بينهما.

### القاعدة 1: حذف الأصفار البادئة {/*#rule-1-remove-leading-zeros*/}

يمكن حذف الأصفار البادئة داخل كل مجموعة. ويجب أن يبقى رقم واحد على الأقل في كل مجموعة.

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
2001:db8:0:0:0:ff00:42:8329
```

### القاعدة 2: طيّ سلسلة واحدة من المجموعات الصفرية (`::`) {/*#rule-2-collapse-one-run-of-zero-groups-*/}

يمكن استبدال سلسلة متصلة واحدة فقط من مجموعة صفرية بالكامل أو أكثر بنقطتين رأسيتين مزدوجتين `::`.

```text
2001:db8:0:0:0:ff00:42:8329
2001:db8::ff00:42:8329
```

**مهم:** يجوز ظهور `::` **مرة واحدة فقط** في العنوان، وإلا أصبح الطول ملتبساً. وإذا وُجدت سلسلتا أصفار بالطول نفسه، تُضغط السلسلة الأولى من اليسار.

```text
fe80:0:0:0:1:0:0:1   =>   fe80::1:0:0:1   (correct)
fe80:0:0:0:1:0:0:1   =>   fe80::1::1      (invalid, two "::")
```

## التوسيع {/*#expanding*/}

يعكس التوسيع عملية الضغط لاستعادة الصيغة الكاملة ذات 128 بت. وهذا مفيد للمقارنة أو لحساب الشبكات الفرعية يدوياً.

1. **استعادة `::`** – تُعدّ المجموعات الموجودة، ثم تُدرج مجموعات `0` بالعدد اللازم للوصول إلى 8 مجموعات في المجموع.
2. **حشو كل مجموعة** – تُضاف أصفار بادئة حتى تحتوي كل مجموعة على 4 أرقام ست عشرية.

```text
2001:db8::ff00:42:8329

Step 1 (restore zero groups, 5 groups present => insert 3):
2001:db8:0:0:0:ff00:42:8329

Step 2 (pad to 4 digits each):
2001:0db8:0000:0000:0000:ff00:0042:8329
```

## أنواع العناوين {/*#address-types*/}

لا يوجد بث (broadcast) في IPv6. ويحل محله multicast.

| النوع         | المعنى                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------- |
| **Unicast**   | واحد إلى واحد. يحدد واجهة واحدة، وتُسلَّم الحزمة إلى تلك الواجهة تحديداً.                   |
| **Multicast** | واحد إلى متعدد. تُسلَّم إلى جميع الواجهات التي انضمت إلى مجموعة multicast.                   |
| **Anycast**   | واحد إلى الأقرب. تتشاركه عدة واجهات، وتُسلَّم الحزمة إلى أقربها طبولوجياً.                   |

## النطاقات (Scopes) {/*#scopes*/}

يحدد *النطاق* منطقة الشبكة التي يكون العنوان صالحاً وقابلاً للتوجيه فيها. ونطاقا unicast الأكثر أهمية هما:

- **Link-Local** – صالح فقط على الوصلة المتصلة مباشرة (قطاع واحد). لا يُوجَّه. يُهيَّأ تلقائياً على كل واجهة IPv6.
- **Global** – فريد عالمياً وقابل للتوجيه عبر الإنترنت، ويماثل عنوان IPv4 العام.

تحمل عناوين multicast حقل نطاق صريحاً (مثل interface-local وlink-local وsite-local وglobal).

### فهرس المنطقة لعناوين Link-Local {/*#zone-index-for-link-local*/}

لأن عناوين link-local (`fe80::/10`) ليست فريدة عبر واجهات متعددة، يجب تحديد الواجهة الصادرة بواسطة فهرس منطقة يُلحق باستخدام `%`.

```text
ping fe80::1%eth0      # Linux (interface name)
ping fe80::1%12        # Windows (interface index)
```

## العناوين المهمة {/*#important-addresses*/}

| العنوان / البادئة | الاسم              | الوصف                                                                                 |
| ---------------- | ------------------ | ------------------------------------------------------------------------------------- |
| `::/128`         | Unspecified        | أصفار كلها. تُستخدم كعنوان مصدر قبل إسناد عنوان (مشابه لـ `0.0.0.0`).                  |
| `::1/128`        | Loopback           | المضيف المحلي، ويعادل `127.0.0.1` في IPv4.                                                |
| `fe80::/10`      | Link-Local         | يُهيَّأ تلقائياً، وصالح على الوصلة المحلية فقط، ولا يُوجَّه أبداً.                    |
| `fc00::/7`       | Unique Local (ULA) | عناوين خاصة للاستخدام الداخلي، لا تُوجَّه على الإنترنت (مشابهة لـ RFC 1918).          |
| `2000::/3`       | Global Unicast     | عناوين عامة قابلة للتوجيه عالمياً.                                                    |
| `ff00::/8`       | Multicast          | تبدأ جميع عناوين multicast بـ `ff`.                                              |
| `ff02::1`        | All Nodes (link)   | Multicast إلى كل عقدة على الوصلة.                                                     |
| `ff02::2`        | All Routers (link) | Multicast إلى كل جهاز توجيه على الوصلة.                                               |
| `2001:db8::/32`  | Documentation      | محجوز للأمثلة والتوثيق، ولا يُستخدم أبداً في الإنتاج.                                 |

## IPv6 مقابل IPv4 {/*#ipv6-vs-ipv4*/}

| الخاصية        | IPv4                   | IPv6                         |
| -------------- | ---------------------- | ---------------------------- |
| طول العنوان    | 32 بت                  | 128 بت                       |
| الصيغة         | عشرية، مفصولة بنقاط    | ست عشرية، مفصولة بنقطتين رأسيتين |
| البث (Broadcast) | نعم                  | لا (يحل محله multicast)      |
| Loopback       | `127.0.0.1`            | `::1`                        |
| التهيئة التلقائية | DHCP / APIPA        | SLAAC + link-local           |
