# أنواع البيانات

## نظرة عامة {/* #overview */}

يحدد نوع البيانات ثلاثة أمور لكل متغير ومعامل وقيمة مُعادة:

- **نطاق القيم:** القيم الصالحة، مثل `true` و`false` للقيمة المنطقية
- **استهلاك الذاكرة:** عدد البايتات المحجوزة لقيمة واحدة
- **العمليات:** ما يجوز فعله بالقيمة، مثل `+` الذي يعني الجمع في الأعداد والضمّ في السلاسل النصية

| الفئة         | تحتوي على                         | أمثلة                                |
| ------------- | --------------------------------- | ------------------------------------ |
| **أولية**     | قيمة واحدة غير قابلة للتجزئة      | `int`, `double`, `boolean`, `char`   |
| **مركّبة**    | عدة قيم تحت اسم واحد              | array, tuple, record, object, string |
| **مجرّدة**    | عقد وليس بنية ملموسة              | interface, generic type parameter    |

:::info
تتبع أسماء الأنواع وأحجامها أدناه عائلة C/Java/C# الشائعة. وتختلف لغات أخرى: فالأعداد الصحيحة في Python ذات دقة اعتباطية، وتمتلك JavaScript نوعاً واحداً هو `number` مدعوماً بعدد عائم 64 بت، وتسمّي Go أنواعها بحسب العرض (`int32`، `uint64`).
:::

## أنواع البيانات الأولية {/* #primitive-data-types */}

### الأنواع الصحيحة {/* #integer-types */}

تخزّن الأعداد الصحيحة أعداداً كاملة بلا جزء كسري. ينتج نطاق القيم مباشرة من عدد البتات `n`:

```text
signed:    -2^(n-1)  to  2^(n-1) - 1
unsigned:         0  to  2^n - 1
```

| البتات | الاسم المعتاد | النطاق بإشارة                                           | النطاق بلا إشارة                |
| ------ | ------------- | ------------------------------------------------------- | ------------------------------- |
| 8      | `byte`       | -128 إلى 127                                            | 0 إلى 255                       |
| 16     | `short`      | -32,768 إلى 32,767                                      | 0 إلى 65,535                    |
| 32     | `int`        | -2,147,483,648 إلى 2,147,483,647                        | 0 إلى 4,294,967,295             |
| 64     | `long`       | -9,223,372,036,854,775,808 إلى 9,223,372,036,854,775,807 | 0 إلى 18,446,744,073,709,551,615 |

**معلومات إضافية:**

- يرمّز بت واحد من العدد الصحيح ذي الإشارة إلى الإشارة، ولذلك يغطي النطاق ذو الإشارة نحو نصف النطاق بلا إشارة.
- يمتد الجانب السالب خطوة واحدة أبعد من الجانب الموجب، لأن الصفر يشغل موضعاً بين القيم غير السالبة.

### أنواع الفاصلة العائمة {/* #floating-point-types */}

تخزّن أنواع الفاصلة العائمة الأعداد ذات الجزء الكسري على شكل إشارة وأساس (mantissa) وأس وفق IEEE 754.

| البتات | الاسم المعتاد     | الأرقام العشرية المعنوية | الحجم التقريبي        |
| ------ | ----------------- | ------------------------ | --------------------- |
| 32     | `float`, `single` | نحو 7                    | حتى 3.4 x 10^38       |
| 64     | `double`          | نحو 15 إلى 16            | حتى 1.8 x 10^308      |

ولأن الأساس ثنائي، لا يوجد تمثيل دقيق للكسور العشرية مثل `0.1`:

```text
0.1 + 0.2 = 0.30000000000000004
```

**اعتبارات مهمة تنتج عن ذلك:**

- لا تُقارن قيم الفاصلة العائمة باستخدام `==`، بل بالنسبة إلى هامش تسامح صغير
- لا تُخزَّن المبالغ النقدية في `float` أو `double`، بل في [نوع الفاصلة الثابتة](#fixed-point-types) أو كعدد صحيح من السنتات

### أنواع الفاصلة الثابتة {/* #fixed-point-types */}

يخزّن نوع الفاصلة الثابتة عدداً ثابتاً من المنازل العشرية. تكون القيمة داخلياً عدداً صحيحاً مضروباً بقوة للعدد عشرة، فيُحفظ `12.34` على صورة `1234` بمقياس 2. وبذلك تُمثَّل الكسور العشرية بدقة، وهو ما لا يستطيعه نوع الفاصلة العائمة.

**مثال:**

`DECIMAL(10, 2)` تعني 10 أرقام في المجموع، منها 2 بعد الفاصلة العشرية، ويبقى 8 أرقام قبلها.

ثمن هذه الدقة هو حساب أبطأ بكثير من `double` وحجم ذاكرة أكبر. ولذلك تُستخدم أنواع الفاصلة الثابتة حيث تكون الدقة إلزامية، وفي مقدمة ذلك المبالغ النقدية ونسب الضرائب وإجماليات الفواتير، وليس القياسات أو الرسوميات.

### القيمة المنطقية (Boolean) {/* #boolean */}

تحمل القيمة المنطقية إحدى قيمتي الحقيقة `true` و`false` فقط، وهي نوع النتيجة لكل مقارنة وعملية منطقية (`&&`، `||`، `!`). وعلى الرغم من أن بتاً واحداً يكفي، يُحجز عادةً بايت واحد على الأقل لأن الذاكرة تُعنوَن بالبايت.

### المحرف (Character) {/* #character */}

يحمل نوع المحرف محرفاً واحداً، يُخزَّن على هيئة رمز عددي (code point) في ترميز المحارف.

| الترميز  | الحجم لكل محرف       | النطاق                                   |
| -------- | -------------------- | ---------------------------------------- |
| ASCII    | بايت واحد (7 بتات مستخدمة) | 128 محرفاً، بلا محارف مثل الـ umlaut |
| UTF-8    | من 1 إلى 4 بايت      | Unicode كاملاً، متوافق مع ASCII          |
| UTF-16   | 2 أو 4 بايت          | Unicode كاملاً، يستخدمه Java وC# `char` |

**معلومة طريفة:** بما أن المحرف يُخزَّن على هيئة عدد، تعمل عليه العمليات الحسابية والمقارنة: `'A' + 1` تعطي `'B'`، و`'a' < 'b'` هي `true`.

## أنواع البيانات المركّبة {/* #composite-data-types */}

### السلسلة النصية (String) {/* #string */}

السلسلة النصية متتالية من المحارف. يميّز التنفيذات قراران تصميميان:

- **الطول:** ثابت (نادر في شيفرة التطبيقات) أو متغير
- **قابلية التعديل:** غير قابلة للتعديل في Java وC# وPython، وقابلة للتعديل في C++ وRust

حيث تكون السلسلة غير قابلة للتعديل، ينشئ كل تعديل كائناً جديداً. ولذلك فإن بناء سلسلة بضمّ متكرر داخل حلقة ينسخ النص كله في كل دورة، ويُستعاض عنه بنوع بنّاء (`StringBuilder`، `StringBuffer`).

### المصفوفة (Array) {/* #array */}

تخزّن المصفوفة عدداً ثابتاً من العناصر **من النوع نفسه** تحت اسم واحد، ويُوصل إليها بفهرس يبدأ من الصفر.

```text
scores = [17, 42, 8, 23]

scores[0] = 17
scores[3] = 23
```

الخصائص:

- الحجم ثابت عند الإنشاء، ولذلك يتطلب التوسّع مصفوفة جديدة ونسخاً
- الوصول بالفهرس يستغرق زمناً ثابتاً، لأن العنوان يُحسب على النحو `start + index x elementSize`
- تمثّل المصفوفات متعددة الأبعاد (`matrix[row][column]`) الجداول والشبكات

### Tuple {/* #tuple */}

تجمع الـ tuple عدداً ثابتاً من القيم **التي قد تختلف أنواعها** بترتيب ثابت. تُعنوَن العناصر بموضعها لا باسمها.

```text
point    = (3, 7)
httpCall = ("GET", "/users", 200)
```

تفيد الـ tuple في إرجاع عدة قيم من دالة دون تعريف نوع مخصص. وما إن تحتاج المواضع إلى شرح، يصبح الـ record الخيار الأفضل.

### Record وStruct وObject {/* #record-struct-and-object */}

يجمع الـ record (ويسمى أيضاً struct، أو كائن من صنف) قيماً من أنواع مختلفة تحت حقول **مسمّاة**.

```text
Customer {
    id:      int
    name:    string
    active:  boolean
    revenue: decimal
}
```

على عكس الـ tuple، يحمل كل حقل اسماً، مما يجعل معنى كل قيمة صريحاً ويسمح بتوسيع النوع دون كسر المواضع القائمة.

### التعداد (Enumeration) {/* #enumeration */}

يعرّف الـ enum مجموعة ثابتة مسمّاة من القيم المسموح بها.

```text
enum OrderState { NEW, PAID, SHIPPED, CANCELLED }
```

الميزة مقارنة بالرقم السحري أو ثابت السلسلة النصية الفضفاض: يرفض المترجم أي قيمة خارج المجموعة، وتُوثَّق جميع الحالات الصالحة في مكان واحد.

### المجموعات (Collections) {/* #collections */}

القوائم والمجموعات والخرائط والطوابير أنواع مركّبة توفرها المكتبة القياسية لا نواة اللغة. وتُتناول بشكل منفصل ضمن بنى البيانات. {/* TODO: add link to datastructures.md here once it exists */}

## تحويل النوع {/* #type-conversion */}

تحويل قيمة من نوع إلى آخر إما **ضمني** (يجريه المترجم تلقائياً) وإما **صريح** (يُطلب في الشيفرة المصدرية بواسطة cast أو دالة تحويل).

| الاتجاه       | المعنى                             | مثال            | الخطر                |
| ------------- | ---------------------------------- | --------------- | -------------------- |
| **توسيع**     | نطاق الهدف يحتوي نطاق المصدر       | `int` => `long` | لا يوجد، بلا فقدان   |
| **تضييق**     | نطاق الهدف أصغر                    | `long` => `int` | فيض، بتر             |

```text
implicit widening:   long total = 42;          // int fits into long
explicit narrowing:  int  count = (int) 42L;   // cast required
truncation:          int  n     = (int) 3.99;  // yields 3, not 4
```

التحويل بين سلسلة نصية وعدد ليس cast، بل **تحليل** (parsing) أو **تنسيق** (formatting)، لأن تمثيل الذاكرة يتغير كلياً. ويعتمد التحليل على المُدخل ولذلك قد يفشل، ولهذا يعيد خطأً أو يطلق استثناءً.

## المزالق الشائعة {/* #common-pitfalls */}

- **فيض الأعداد الصحيحة:** إضافة 1 إلى القيمة العظمى تلتف إلى القيمة الصغرى في معظم اللغات بدلاً من إطلاق خطأ
- **القسمة الصحيحة:** `7 / 2` تعطي `3` وليس `3.5` ما دام المعاملان عددين صحيحين
- **مقارنة الأعداد العائمة:** `0.1 + 0.2 == 0.3` تُقيَّم إلى `false`
- **المال كعدد عائم:** تتراكم أخطاء التقريب عبر عمليات كثيرة
- **البتر عند التضييق:** تحويل قيمة عائمة إلى عدد صحيح يقتطع الجزء الكسري ولا يقرّبه
- **أنواع كبيرة بلا حاجة:** استخدام `long` حيث يكفي `byte` يهدر الذاكرة في المصفوفات والـ records الكبيرة

## اختيار نوع البيانات {/* #choosing-a-data-type */}

1. **نطاق القيم:** أكبر قيمة وأصغرها يمكن أن تحدثا بشكل مشروع، بما في ذلك النمو المتوقع
2. **الدقة:** هل يلزم جزء كسري، وهل يجب أن يكون دقيقاً (المال) أم يجوز أن يكون تقريبياً (القياسات)
3. **الذاكرة والأداء:** مهمان للمصفوفات الكبيرة والأنظمة المدمجة ونقل البيانات عبر الشبكة، وضئيلا الأثر للمتغيرات المفردة
4. **الدلالة:** هل يمكن استبعاد القيم غير الصالحة بالنوع نفسه، مثل enum بدلاً من سلسلة نصية أو قيمة منطقية بدلاً من `0` و`1`، بحيث تفشل القيمة الخاطئة عند الترجمة
