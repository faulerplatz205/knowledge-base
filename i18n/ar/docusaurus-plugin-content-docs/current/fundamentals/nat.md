# NAT (ترجمة عناوين الشبكة)

## نظرة عامة {/*#overview*/}

كان النمو السريع للإنترنت سيستنفد مجموعة عناوين IP المتاحة بسرعة لولا آليات تستخدمها بكفاءة أكبر. وتعالج NAT (ترجمة عناوين الشبكة) ذلك بالسماح لأجهزة كثيرة في شبكة خاصة بتقاسم عدد صغير من عناوين IP العامة.

تعمل NAT على جهاز حدودي (عادةً جدار حماية أو جهاز توجيه). وعند مرور الحزمة به، تستبدل NAT عنوان IP المصدر (عنوان خاص غير قابل للتوجيه) بعنوان IP عام قابل للتوجيه. ثم يُترجَم العنوان العام في الرد عائداً إلى العنوان الخاص حتى تصل الحزمة إلى المضيف الداخلي الصحيح.

## الفوائد {/*#benefits*/}

- **تغيير الترقيم بصورة أبسط**: عند تغيير مزوّد خدمة الإنترنت، لا تحتاج المضيفات الداخلية إلى عناوين IP جديدة. فقط يتغير العنوان العام الذي يسنده المزوّد الجديد.
- **الحفاظ على العناوين**: تتيح [PAT](#nat-overloading-pat) لمضيفات داخلية كثيرة مشاركة عنوان IP عام واحد، مما يقلل كثيراً عدد العناوين العامة اللازمة.
- **زيادة الأمان**: تُخفى العناوين الداخلية وطبولوجيا الشبكة عن الشبكات الخارجية، لأن العنوان العام وحده هو المرئي.

## كيف تعمل NAT {/*#how-nat-works*/}

1. يرسل مضيف داخلي (مثل `10.0.0.3`) حزمة موجهة إلى مضيف خارجي (مثل `128.23.2.2`)
2. يتعرّف جهاز التوجيه الحدودي (RTA) على أن الحزمة متجهة إلى الإنترنت ويختار عنوان IP عالمياً متاحاً (مثل `179.9.8.80`)
3. يستبدل RTA عنوان المصدر في الحزمة بالعنوان العالمي ويسجّل الربط في جدول NAT
4. تُمرَّر الحزمة إلى الوجهة
5. عند وصول الرد الموجّه إلى `179.9.8.80`، يبحث RTA في جدول NAT ويجد العنوان الداخلي المقابل ويستبدل حقل الوجهة ويمرّر الحزمة داخلياً

يسجّل جدول NAT ثلاثة أنواع من العناوين:

- **عنوان IP المحلي الداخلي**: عنوان IP الخاص بالمضيف الداخلي
- **عنوان IP العالمي الداخلي**: عنوان IP العام الذي يسنده جهاز توجيه NAT ليمثّل المضيف الداخلي خارجياً
- **عنوان IP العالمي الخارجي**: عنوان IP الخاص بالمضيف الوجهة في الشبكة الخارجية

**مثال على جدول NAT:**

| عنوان IP المحلي الداخلي | عنوان IP العالمي الداخلي | عنوان IP العالمي الخارجي |
| ----------------------- | ------------------------ | ------------------------ |
| 10.0.0.3                | 179.9.8.80               | 128.23.2.2               |

## NAT Overloading (PAT) {/*#nat-overloading-pat*/}

تربط NAT Overloading، وتسمى أيضاً PAT (ترجمة عناوين المنافذ)، عدة عناوين IP خاصة بعنوان IP عام واحد عبر تتبع أرقام المنافذ إضافةً إلى ذلك. ويحصل كل اتصال داخلي على رقم منفذ فريد في الجانب العام، مما يتيح لجهاز التوجيه توزيع الردود الواردة على المضيف الداخلي الصحيح.

**جدول NAT مع overloading:**

| IP الداخلي | المنفذ الداخلي | IP العالمي | المنفذ الخارجي |
| ---------- | -------------- | ---------- | -------------- |
| 10.0.0.2   | 1555           | 179.9.8.80 | 1555           |
| 10.0.0.3   | 1331           | 179.9.8.80 | 1331           |
| 10.0.0.4   | 1444           | 179.9.8.80 | 1444           |

## إعادة توجيه المنافذ {/*#port-forwarding*/}

افتراضياً تحجب NAT جميع الاتصالات الواردة التي تبدؤها جهة خارجية. وتتيح إعادة توجيه المنافذ لحركة خارجية محددة الوصول إلى مضيف داخلي بربط رقم منفذ وجهة على IP العام بعنوان IP داخلي محدد.

مثال على المسار:

1. يرسل عميل طلباً إلى `https://knowledge.moritz-grimm.dev` (IP العام `209.165.200.225`، المنفذ `443`)
2. يستلم جهاز التوجيه الحزمة، لأن `209.165.200.225` هو IP العام الخاص به
3. تربط قاعدة إعادة توجيه المنافذ المنفذ الخارجي `443` بالمضيف الداخلي `192.168.1.254:443`، فيعيد جهاز التوجيه كتابة الوجهة ويمرّر الحزمة داخلياً

:::info
لا يلزم أن يكون رقما المنفذين الخارجي والداخلي متطابقين.
:::
