# نظرة عامة على قواعد البيانات

## نظرة عامة {/*#overview*/}

قاعدة البيانات مجموعة منظمة من البيانات المهيكلة يديرها نظام إدارة قواعد البيانات (DBMS). والنموذجان الرئيسيان هما قواعد البيانات **العلائقية (SQL)** و**غير العلائقية (NoSQL)**.

## قواعد البيانات العلائقية (SQL) {/*#relational-databases-sql*/}

تُخزَّن البيانات في **جداول** ذات صفوف وأعمدة. ويمكن تحديد كل سجل بيانات بشكل فريد بواسطة **مفتاح أساسي (Primary Key)**، وترتبط الجداول عبر **مفاتيح خارجية (Foreign Keys)**، مكوّنة مخططًا منظمًا.

- يُستعلَم عن البيانات باستخدام **SQL** (لغة الاستعلام المهيكلة)
- يُعرَّف المخطط مسبقًا وتفرضه قاعدة البيانات
- الأنسب للبيانات المهيكلة ذات العلاقات الواضحة

**الأنظمة الشائعة**: PostgreSQL وMySQL وSQLite وMicrosoft SQL Server وOracle DB

### المفاهيم الأساسية {/*#key-concepts*/}

**[التطبيع](./normalization.md)**: تنظيم الجداول لتقليل تكرار البيانات:

- **1NF**: قيم ذرية، دون مجموعات متكررة
- **2NF**: دون اعتماديات جزئية على المفاتيح المركبة
- **3NF**: دون اعتماديات متعدية

**خصائص ACID**: ضمانات للمعاملات الموثوقة:

- **الذرية (Atomicity)**: إما أن تنجح المعاملة بالكامل أو تفشل بالكامل
- **الاتساق (Consistency)**: تنتقل البيانات دائمًا من حالة صالحة إلى أخرى
- **العزل (Isolation)**: لا تتداخل المعاملات المتزامنة مع بعضها
- **الثبات (Durability)**: تبقى التغييرات المعتمدة حتى بعد حدوث عطل

## قواعد البيانات غير العلائقية (NoSQL) {/*#non-relational-databases-nosql*/}

مصمَّمة لتخزين مرن وقابل للتوسع للبيانات غير المهيكلة أو شبه المهيكلة. ولا يلزم مخطط ثابت.

| النوع             | الوصف                                       | أنظمة نموذجية    |
| ----------------- | ------------------------------------------- | ---------------- |
| مستندات           | تخزّن مستندات شبيهة بـ JSON                 | MongoDB, CouchDB |
| مفتاح-قيمة        | أزواج مفتاح => قيمة بسيطة                   | Redis, DynamoDB  |
| عائلة الأعمدة     | محسّنة للقراءة/الكتابة العمودية             | Apache Cassandra |
| الرسوم البيانية   | عُقد وحواف للبيانات كثيفة العلاقات          | Neo4j            |

## العلائقية مقابل NoSQL {/*#relational-vs-nosql*/}

|                | علائقية                        | NoSQL                                      |
| -------------- | ------------------------------ | ------------------------------------------ |
| المخطط         | ثابت ومحدد مسبقًا              | مرن / بلا مخطط                             |
| لغة الاستعلام  | SQL                            | تختلف (مثل MongoDB Query Language)         |
| التوسع         | رأسي (التوسع للأعلى)           | أفقي (التوسع للخارج)                       |
| الاتساق        | قوي (ACID)                     | غالبًا اتساق نهائي                         |
| الأنسب لـ      | البيانات المهيكلة، وعمليات الربط (Joins) المعقدة | الحجم الكبير، والبيانات المرنة أو الهرمية |
