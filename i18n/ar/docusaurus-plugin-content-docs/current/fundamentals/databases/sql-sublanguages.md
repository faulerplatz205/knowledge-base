# اللغات الفرعية لـ SQL

## DDL (لغة تعريف البيانات) {/*#ddl-data-definition-language*/}

تعرّف أوامر DDL بنية قاعدة البيانات وتديرها، أي جداولها وأعمدتها وقيودها وفهارسها.

**الأوامر الشائعة:**

- `CREATE` — ينشئ جدولاً أو عرضاً أو فهرساً أو قاعدة بيانات جديدة
- `ALTER` — يعدّل بنية موجودة (مثل إضافة عمود أو حذفه)
- `DROP` — يحذف جدولاً أو قاعدة بيانات نهائياً
- `TRUNCATE` — يزيل جميع الصفوف من جدول دون حذف الجدول نفسه

## DML (لغة معالجة البيانات) {/*#dml-data-manipulation-language*/}

تُستخدم أوامر DML لتعديل البيانات المخزّنة فعلياً.

**الأوامر الشائعة:**

- `INSERT` — يضيف صفوفاً جديدة إلى جدول
- `UPDATE` — يعدّل صفوفاً موجودة
- `DELETE` — يزيل صفوفاً من جدول

## DQL (لغة استعلام البيانات) {/*#dql-data-query-language*/}

تُستخدم DQL للاستعلام عن البيانات واسترجاعها من قاعدة البيانات دون تعديلها.

**الأوامر الشائعة:**

- `SELECT` — يسترجع صفوفاً من جدول واحد أو أكثر، مع إمكانية التصفية أو التجميع أو الترتيب

## DCL (لغة التحكم في البيانات) {/*#dcl-data-control-language*/}

تدير DCL حقوق الوصول والأذونات لمستخدمي قاعدة البيانات.

**الأوامر الشائعة:**

- `GRANT` — يمنح مستخدماً إذن تنفيذ إجراءات محددة
- `REVOKE` — يزيل الأذونات الممنوحة سابقاً
