# مسارات الملفات

يصف **المسار** موقع ملف أو دليل في نظام الملفات. وهناك طريقتان لكتابته: **مطلقة** و**نسبية**.

## المسارات المطلقة {/*#absolute-paths*/}

يبدأ المسار المطلق من **جذر** نظام الملفات، ولذلك فهو لا لبس فيه مهما كان الموقع الحالي.

- في Linux وmacOS يكون الجذر `/`، مثل `/home/user/notes.txt`
- في Windows يبدأ بحرف قرص، مثل `C:\Users\user\notes.txt`

## المسارات النسبية {/*#relative-paths*/}

يُفسَّر المسار النسبي **بالنسبة إلى دليل العمل الحالي**. ولا يبدأ بـ `/` (أو بحرف قرص).

```bash
cd /home/user
cat notes.txt          # => /home/user/notes.txt
cat projects/app.js    # => /home/user/projects/app.js
```

## مكوّنات المسار الخاصة {/*#special-path-components*/}

| المكوّن   | المعنى                                    |
| --------- | ----------------------------------------- |
| `/`       | الدليل الجذر (بداية المسار المطلق)        |
| `.`       | الدليل الحالي                             |
| `..`      | الدليل الأب (مستوى واحد للأعلى)           |
| `~`       | الدليل الرئيسي (home) للمستخدم الحالي     |

### أمثلة {/*#examples*/}

```bash
cd ..        # Move up one directory
cd ./bin     # Enter the bin directory below the current one
cd ~         # Go to the home directory
cat ../config.txt
```

## دليل العمل {/*#working-directory*/}

**دليل العمل** هو الدليل الذي تكون العملية "داخله" حالياً. وهو نقطة الارتكاز التي تُحلّ بالنسبة إليها كل المسارات النسبية.

```bash
pwd    # Print the current working directory
```
