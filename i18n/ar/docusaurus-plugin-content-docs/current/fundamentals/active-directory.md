# Active Directory

**Active Directory (AD)** هي خدمة دليل توفر إدارة مركزية للهويات والوصول في بيئة Windows. فبدلًا من إعداد كل جهاز على حدة، يُدار المستخدمون والحواسيب والموارد مركزيًا. و**وحدة تحكم النطاق (DC، Domain Controller)** هي خادم Windows Server يستضيف خدمات نطاق Active Directory (AD DS).

تتطلب وحدة تحكم النطاق اسمًا فريدًا (مثل `dc1`) وعنوان IP ثابتًا وخادم DNS يعمل؛ ثم يُثبَّت الدور «Active Directory Domain Services» ويُرقَّى الخادم.

## البنية المنطقية {/*#logical-structure*/}

يفصل Active Directory بين البنية المنطقية والبنية الفيزيائية (المواقع والشبكات الفرعية ووحدات DC). وتتمثل اللبنات المنطقية فيما يلي:

- **الكائن (Object):** أصغر وحدة قابلة للإدارة؛ ويُمثَّل كل مورد شبكي (مستخدم، حاسوب، طابعة …) بكائن.
- **الوحدة التنظيمية (OU، Organizational Unit):** حاوية تجمع الكائنات (المستخدمين والحواسيب والمجموعات) لنمذجة هيكل الشركة. وتُستخدم الوحدات التنظيمية أيضًا لربط سياسات المجموعة.
- **النطاق (Domain):** الوحدة المركزية التي تحتوي Active Directory. تسري السياسات الأمنية داخل النطاق، ويجب أن يضم وحدة DC واحدة على الأقل.
- **الشجرة (Tree):** عدة نطاقات مرتبة هرميًا تتشارك مساحة أسماء متصلة (مثل `de.abc.com` تحت `abc.com`).
- **الغابة (Forest):** شجرة واحدة أو أكثر، عادةً بمساحات أسماء مختلفة. تعمل النطاقات باستقلالية لكنها تستطيع التواصل عبر الغابة.

## الكتالوج العام {/*#global-catalog*/}

**الكتالوج العام (Global Catalog)** قاعدة بيانات تُستخدم للبحث عن الكائنات في الغابة بأكملها، بما في ذلك الكائنات في مساحات أسماء أخرى. ينبغي أن يستضيف كل موقع AD وحدة DC واحدة على الأقل تحتوي نسخة من الكتالوج العام.

## علاقات الثقة {/*#trusts*/}

تصف **علاقة الثقة (Trust)** العلاقة بين نطاقين: يقبل النطاق الواثق المصادقة الصادرة من النطاق الموثوق به.

- **أحادية الاتجاه (Unidirectional):** ثقة في اتجاه واحد / **ثنائية الاتجاه (Bidirectional):** ثقة في الاتجاهين
- **متعدية (Transitive):** تمتد الثقة عبر علاقات ثقة أخرى / **غير متعدية (Non-transitive):** لعلاقة الثقة المعدَّة صراحةً فقط

الإعداد الافتراضي هو **ثنائية الاتجاه ومتعدية**.

## LDAP والتسمية {/*#ldap-and-naming*/}

يُستخدم **LDAP** (Lightweight Directory Access Protocol) للوصول إلى خدمة الدليل.

- **الاسم المميز (DN، Distinguished Name):** «مسار LDAP» الفريد للكائن، ويستخدم `CN` (Common Name) و`OU` (Organizational Unit) و`DC` (Domain Component)، مثل `CN=HPjet5, OU=Assistenz, DC=Firma, DC=DE`.
- **الاسم القانوني (Canonical Name):** المعلومات نفسها بصيغة اسم نطاق DNS، مثل `HPjet5.Assistenz.firma.de`.

## ملفات التعريف المتجولة {/*#roaming-profiles*/}

يُخزَّن **ملف التعريف المتجول (Roaming Profile)** مركزيًا على خادم ليجد المستخدم البيئة نفسها على أي حاسوب في النطاق. ويُنسخ ملف التعريف إلى الجهاز عند تسجيل الدخول ويُزامَن مجددًا عند تسجيل الخروج.

- **الميزة:** البيئة نفسها على كل حاسوب.
- **العيب:** يتطلب مساحة تخزين كبيرة؛ وقد يكون تسجيل الدخول والخروج بطيئًا.

تُنشأ المشاركتان **SYSVOL** و**NETLOGON** عند ترقية خادم إلى DC. وتخزّنان سياسات المجموعة ونصوص تسجيل الدخول التي تجلبها الأجهزة العميلة.

## المستويات الوظيفية {/*#functional-levels*/}

عند ترقية DC، يُختار **مستوى وظيفي للغابة (forest functional level)** و**مستوى وظيفي للنطاق (domain functional level)**. وهما يحددان ميزات AD المتاحة ويضمنان إمكانية التشغيل البيني بين وحدات DC ذات إصدارات Windows Server المختلفة (التوافق مع الإصدارات السابقة). توفر المستويات الأعلى ميزات أكثر لكن لا يمكن التراجع عنها. ويمكن أن يعمل النطاق بمستوى أعلى من الغابة، لكن ليس أقل.

## سياسات المجموعة (GPO) {/*#group-policies-gpo*/}

**سياسات المجموعة** تعليمات إعداد تُستخدم لفرض إعدادات (مثل سياسات كلمات المرور وإعدادات الطاقة وقيود الوصول). تُخزَّن في Active Directory وتتوفر على مستوى النطاق عبر النسخ المتماثل. ويخزّن **كائن سياسة المجموعة (GPO، Group Policy Object)** الإعدادات الفردية ويُ**ربط** بالكائن الذي ينبغي أن يؤثر فيه. تحتوي كائنات GPO على إعدادات منفصلة للمستخدمين وللحواسيب، وتعمل على حسابات المستخدمين والحواسيب الموجودة في وحدة تنظيمية، لا على المجموعات.

### ترتيب المعالجة {/*#processing-order*/}

يمكن ربط سياسات المجموعة بموقع أو نطاق أو وحدة تنظيمية؛ ولكل حاسوب أيضًا سياسة محلية. ترتيب المعالجة هو **L-S-D-OU**:

1. **المحلية (Local)**
2. **الموقع (Site)**
3. **النطاق (Domain)**
4. **الوحدة التنظيمية (OU)**

تتجاوز كل خطوة لاحقة الإعدادات المتعارضة في الخطوة السابقة. وبذلك تكون للسياسة المحلية أدنى أولوية ولسياسة الوحدة التنظيمية أعلاها. وإذا رُبطت عدة كائنات GPO على المستوى نفسه، يحسم ترتيب الربط الأمر (تفوز أدنى قيمة ربط لأنها تُعالَج أخيرًا).

### التحديث {/*#refresh*/}

تُحدَّث إعدادات سياسة المجموعة في الخلفية تقريبًا كل **90 دقيقة** على الأجهزة العميلة وكل **5 دقائق** على وحدات تحكم النطاق. ويمكن فرض التحديث باستخدام `gpupdate /force`. وإعادة توجيه المجلدات استثناء: فهي لا تُطبَّق إلا عند تسجيل دخول المستخدم.
