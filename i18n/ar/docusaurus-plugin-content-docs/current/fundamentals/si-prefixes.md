# بادئات النظام الدولي للوحدات (SI)

بادئات SI هي معاملات ضرب موحّدة تُلحق بوحدة أساسية للتعبير عن كميات كبيرة جدًا أو صغيرة جدًا.  
وتنطبق على أي وحدة من وحدات SI: المتر والغرام والثانية والفولت والواط والهرتز وغيرها.

## البادئات الشائعة {/*#common-prefixes*/}

الجدول مرتب من أكبر بادئة إلى أصغرها. وتقع الوحدة الأساسية (المعامل 1) في المنتصف.

| البادئة | الرمز | المعامل               | الأس  | مثال            |
| ------ | ------ | --------------------- | ----- | --------------- |
| تيرا   | T      | 1,000,000,000,000     | 10¹²  | TB, THz         |
| غيغا   | G      | 1,000,000,000         | 10⁹   | GHz, GW         |
| ميغا   | M      | 1,000,000             | 10⁶   | MW, MΩ          |
| كيلو   | k      | 1,000                 | 10³   | km, kg, kV, kWh |
| —      | —      | 1                     | 10⁰   | m, g, V, W      |
| ديسي   | d      | 0.1                   | 10⁻¹  | dl, dm          |
| سنتي   | c      | 0.01                  | 10⁻²  | cm              |
| ميلي   | m      | 0.001                 | 10⁻³  | mm, mV, ms      |
| ميكرو  | µ      | 0.000001              | 10⁻⁶  | µs, µm, µF      |
| نانو   | n      | 0.000000001           | 10⁻⁹  | nm, ns          |
| بيكو   | p      | 0.000000000001        | 10⁻¹² | pF, ps          |

:::info
التسلسل "الرئيسي" (كيلو => ميغا => غيغا => تيرا وميلي => ميكرو => نانو => بيكو) يتدرج بخطوات قدرها **1,000** (10³) لكل بادئة. أما **ديسي** و**سنتي** فتقعان بين الوحدة الأساسية وميلي كخطوتين وسيطتين أصغر (10⁻¹ و10⁻²).
:::

## التحويل بين البادئات {/*#scaling-between-prefixes*/}

كل بادئة هي ببساطة قوة للعدد 10 (انظر عمود [الأس](#common-prefixes) أعلاه). وللتحويل بين بادئتين يُؤخذ الفرق بين قوتيهما ويُطبَّق على شكل خطوات.

### للأعلى (من الأصغر => إلى الأكبر) {/*#upward-smaller--larger*/}

```text
Formula: value / 10^steps

Example: 2,500 mV => V
Steps: mV (10⁻³) => V (10⁰) = 3 powers of 10
2,500 mV / 10³ = 2.5 V
```

### للأسفل (من الأكبر => إلى الأصغر) {/*#downward-larger--smaller*/}

```text
Formula: value x 10^steps

Example: 5 km => mm
Steps: km (10³) => mm (10⁻³) = 6 powers of 10
5 km x 10⁶ = 5,000,000 mm
```

## أمثلة شائعة في التطبيق العملي {/*#common-examples-in-practice*/}

- **kV** — كيلوفولت، 1,000 V (خطوط نقل الكهرباء عالية الجهد)
- **mA** — ميلي أمبير، 0.001 A (الإلكترونيات الصغيرة)
- **MHz** — ميغاهرتز، 1,000,000 Hz (الترددات الراديوية، ساعات المعالج)
- **nm** — نانومتر، 0.000000001 m (عُقد تصنيع أشباه الموصلات، أطوال الموجات الضوئية)
- **kWh** — كيلوواط ساعة، 1,000 Wh (فواتير الكهرباء)
- **µF** — ميكروفاراد، 0.000001 F (قيم المكثفات)
