# أنواع أنظمة الملفات

يحدد **نظام الملفات** كيفية تنظيم البيانات وتخزينها على وسيط التخزين. وتختلف أنظمة الملفات في الحد الأقصى لحجم الملف ودعم السجل (journaling) وأنظمة التشغيل القادرة على قراءتها والكتابة عليها.

## نظرة عامة {/*#overview*/}

| نظام الملفات | الحد الأقصى لحجم الملف | السجل (Journaling)  | الاستخدام النموذجي                              |
| ------------ | ---------------------- | ------------------- | ----------------------------------------------- |
| FAT32        | 4 GB                   | لا                  | وحدات USB وبطاقات SD، توافق واسع                |
| exFAT        | 16 EB                  | لا                  | وحدات USB وبطاقات SD كبيرة عبر المنصات          |
| NTFS         | 16 EB                  | نعم                 | أقراص نظام Windows وبياناته                     |
| ext4         | 16 TB                  | نعم                 | نظام الملفات الافتراضي في Linux                 |
| APFS         | 8 EB                   | نعم (copy-on-write) | نظام الملفات الافتراضي في macOS                 |
| btrfs        | 16 EB                  | نعم (copy-on-write) | Linux، مع اللقطات (snapshots) وتجميع الأقراص    |

## اختيار نظام الملفات {/*#choosing-a-filesystem*/}

- **أقصى توافق (ملفات صغيرة):** يقرأ FAT32 ويكتب عليه تقريباً كل جهاز، لكنه محدود بـ 4 GB لكل ملف.
- **أقصى توافق (ملفات كبيرة):** يزيل exFAT حد 4 GB ويعمل عبر Linux وWindows وmacOS.
- **Linux فقط:** ext4 هو الخيار الافتراضي الآمن، ويضيف btrfs اللقطات وميزات متقدمة أخرى.
- **Windows فقط:** يدعم NTFS الأذونات والسجل والأقراص الكبيرة.
- **macOS فقط:** APFS مُحسَّن لأقراص SSD وهو الخيار الافتراضي الحديث.
