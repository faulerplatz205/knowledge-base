# حلّ الأسماء

تُعرَّف الحواسيب المتصلة بالشبكة بعناوين فريدة (عنوان IP وعنوان MAC) وتستخدمها للتواصل. ولأن العناوين الرقمية يصعب على الناس تذكرها، تُستخدم الأسماء بدلاً منها. و**حلّ الأسماء** هو الآلية التي تربط اسماً (مثل اسم حاسوب) بعنوانه (مثل عنوان IP).

## أنظمة الحلّ {/*#resolution-systems*/}

توجد عدة أنظمة لشبكات Windows وLinux:

| النظام      | النطاق                   | ملاحظة                                                                                                                            |
| ----------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| **DNS**     | الشبكة كلها / الإنترنت   | النظام الأهم، ويتطلبه Active Directory. منفذ UDP `53`، حتى 255 حرفاً (مثل `pc01.bs1-landshut.de`)            |
| **LLMNR**   | الشبكة الفرعية نفسها فقط | Link Local Multicast Name Resolution (منذ Windows Vista)، لمجموعات العمل. يستخدم multicast، ويدعم IPv6، ولا يحتاج إلى تهيئة       |
| **NetBIOS** | الشبكة الفرعية نفسها / قديم | استُخدم قبل Windows Vista للعثور على الحواسيب. 15 حرفاً كحد أقصى، المنافذ `137/138/139/445`                                          |
| **mDNS**    | LAN، link-local          | Multicast DNS (طورته Apple)، نطاق المستوى الأعلى `.local`، ولا حاجة إلى خادم أسماء. التنفيذ في Linux هو `avahi`                          |

## DNS {/*#dns*/}

DNS (نظام أسماء النطاقات) هو نظام حلّ الأسماء الأساسي وأساس حلّ الأسماء على الإنترنت. ويُعالَج بالتفصيل في [DNS](./dns.md).

## LLMNR {/*#llmnr*/}

يحلّ LLMNR الأسماء داخل الشبكة الفرعية نفسها فقط، وهو مخصص لمجموعات العمل الصغيرة. ويستخدم multicast بدلاً من البث (حركة شبكة أقل)، وعلى عكس NetBIOS يدعم IPv6. ولا يستطيع حلّ أسماء الأنظمة الأقدم (مثل Windows Server 2003 وWindows XP).

## NetBIOS {/*#netbios*/}

كان NetBIOS (NetBIOS over TCP/IP، أي NetBT/NBT) مهماً حتى Windows 2000/Vista، وكان يُستخدم لتصفح الشبكة بحثاً عن الحواسيب. ويُستخدم كخيار احتياطي عندما لا يكون DNS مهيأً ويكون LLMNR معطلاً أو عاجزاً عن حلّ اسم.

## mDNS {/*#mdns*/}

يتيح mDNS (Multicast DNS) حلّ الأسماء على LAN دون خادم أسماء مخصص، باستخدام رسائل multicast تحت نطاق المستوى الأعلى link-local `.local`. ومنذ Windows 11 22H2، تعتزم Microsoft أن يحلّ mDNS محل NetBIOS وLLMNR معاً.
