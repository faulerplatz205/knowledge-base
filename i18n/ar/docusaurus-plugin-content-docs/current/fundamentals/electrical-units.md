# الوحدات الكهربائية – القدرة والجهد والتيار والطاقة

## الوحدات الأساسية الثلاث {/*#the-three-core-units*/}

| الرمز | الكمية | الوحدة       |
| ----- | ------ | ------------ |
| P     | القدرة | واط (W)      |
| U     | الجهد  | فولت (V)     |
| I     | التيار | أمبير (A)    |

## مثلث القدرة {/*#the-power-triangle*/}

ترتبط الكميات الثلاث بالصيغة **P = U x I**. وتظهر الصيغة المطلوبة بتغطية الكمية المراد حسابها:

```text
      P
    -----
    U | I
```

- **P = U x I** (القدرة = الجهد x التيار)
- **U = P / I** (الجهد = القدرة / التيار)
- **I = P / U** (التيار = القدرة / الجهد)

## قانون أوم {/*#ohms-law*/}

يُدخل قانون أوم المقاومة **R** (وتُقاس بالأوم، Ω) ويربطها بالجهد والتيار.

وينطبق أسلوب المثلث نفسه هنا:

```text
      U
    -----
    R | I
```

- **U = R x I** (الجهد = المقاومة x التيار)
- **R = U / I** (المقاومة = الجهد / التيار)
- **I = U / R** (التيار = الجهد / المقاومة)

## الصيغ المركّبة {/*#combined-formulas*/}

يتيح الجمع بين صيغة القدرة وقانون أوم طرقاً إضافية لحساب القدرة:

- **P = U² / R**
- **P = I² x R**

## أمثلة {/*#examples*/}

**المثال 1:** جهاز يعمل بجهد 230 V ويسحب تياراً قدره 2 A. ما قدرته المستهلكة (P)؟

```text
P = U x I = 230 V x 2 A = 460 W
```

**المثال 2:** مصباح قدرته 100 W يعمل بجهد 230 V. ما التيار (I) الذي يسحبه؟

```text
I = P / U = 100 W / 230 V ≈ 0.43 A
```

**المثال 3:** مقاومة قيمتها 50 Ω يمرّ بها تيار قدره 3 A. ما الجهد الهابط عليها؟

```text
U = R x I = 50 Ω x 3 A = 150 V
```

## الشغل الكهربائي (الطاقة) {/*#electrical-work-energy*/}

الشغل الكهربائي **W** (ويسمى غالباً الطاقة، ويُكتب أحياناً **E**) هو مقدار الطاقة التي يستهلكها جهاز أو ينتجها خلال زمن. وحدته في النظام الدولي هي **الجول (J)**، لكنها تُعطى في الاستخدام الكهربائي اليومي عادةً بـ **الواط ساعة (Wh)** أو **الكيلوواط ساعة (kWh)**.

الصيغة الأساسية هي:

- **W = P x t** (الشغل = القدرة x الزمن)

وباستبدال **P** بـ **U x I** تنتج صيغة تحسب **W** مباشرة من **U** و**I** و**t** دون الحاجة إلى حساب **P** أولاً:

- **W = U x I x t**

### وحدات الطاقة الشائعة {/*#common-units-of-energy*/}

| الوحدة        | الرمز | تساوي                  |
| ------------- | ----- | ---------------------- |
| جول           | J     | 1 W x 1 s              |
| واط ساعة      | Wh    | 3,600 J                |
| كيلوواط ساعة  | kWh   | 1,000 Wh = 3,600,000 J |

:::info
يُستخدم الرمز **W** لوحدة "الواط" (وحدة القدرة) ولكمية "الشغل" معاً. وعادةً يوضّح السياق المقصود. وتستخدم بعض المراجع **E** للدلالة على "الشغل" تفادياً للالتباس.
:::

### أمثلة {/*#examples-1*/}

**المثال 1:** مصباح قدرته 60 W يعمل لمدة 5 ساعات. ما كمية الطاقة التي يستهلكها؟

```text
W = P x t = 60 W x 5 h = 300 Wh = 0.3 kWh
```

**المثال 2:** جهاز يسحب 2 A عند 230 V لمدة 30 دقيقة. ما كمية الطاقة التي يستخدمها؟

```text
W = U x I x t = 230 V x 2 A x 0.5 h = 230 Wh
```

**المثال 3:** تُظهر فاتورة الكهرباء استهلاك 250 kWh بسعر 0.30 € لكل kWh. ما التكلفة الإجمالية؟

```text
Cost = 250 kWh x €0.30/kWh = €75.00
```
