# حجم تخزين الصورة

## البكسلات وعمق اللون {/* #pixels-and-colour-depth */}

تتكوّن الصورة النقطية من شبكة من **البكسلات**. و**الدقة** هي عدد البكسلات، وتُعطى إما بالعرض x الارتفاع (مثل `1920 x 1080`) أو بالمجموع بوحدة **الميغابكسل** (1 MP = 1,000,000 بكسل).

يبيّن **عمق اللون** عدد البتات التي يستخدمها كل بكسل لتخزين لونه. وبـ `n` بت، يمكن للبكسل أن يتخذ `2ⁿ` لوناً مختلفاً.

| عمق اللون | الألوان    | الاسم                                                      |
| --------- | ---------- | ---------------------------------------------------------- |
| 1 بت      | 2          | أحادي اللون (أبيض وأسود)                                   |
| 8 بت      | 256        | تدرّج رمادي أو لون مفهرس                                   |
| 16 بت     | 65,536     | High Color                                                 |
| 24 بت     | 16,777,216 | True Color، 8 بتات لكل من الأحمر والأخضر والأزرق           |
| 32 بت     | 16,777,216 | True Color مضافاً إليه قناة ألفا (الشفافية) بـ 8 بتات      |

---

## الصيغة {/* #formula */}

```text
Storage size in bits  = number of pixels x colour depth
Storage size in bytes = number of pixels x colour depth ÷ 8
```

النتيجة هي حجم بيانات الصورة الخام غير المضغوطة. تضغط صيغ مثل JPEG وPNG هذه البيانات، ويضيف كل ملف ترويسة وبيانات وصفية. ولذلك يختلف الملف الفعلي عن القيمة المحسوبة.

---

## مثال {/* #example */}

صورة بدقة 50 ميغابكسل وعمق لون 24 بت:

```text
Pixels:        50 MP x 10⁶ = 50,000,000 pixels
Bits:          50,000,000 x 24 bit = 1,200,000,000 bit
Bytes:         1,200,000,000 bit ÷ 8 = 150,000,000 B
Decimal:       150,000,000 B ÷ 10⁶ = 150 MB
Binary:        150,000,000 B ÷ 2²⁰ ≈ 143.05 MiB
```

عند إعطاء الدقة بالعرض x الارتفاع، يُحسب عدد البكسلات أولاً:

```text
Pixels:        1920 x 1080 = 2,073,600 pixels
Bytes:         2,073,600 x 24 bit ÷ 8 = 6,220,800 B
Decimal:       6,220,800 B ÷ 10⁶ ≈ 6.22 MB
Binary:        6,220,800 B ÷ 2²⁰ ≈ 5.93 MiB
```

---

## الأخطاء الشائعة {/* #common-mistakes */}

1. **غياب القسمة على 8:** حاصل ضرب البكسلات في عمق اللون هو عدد من البتات. وبدون القسمة على 8 تكون النتيجة أكبر بثمانية أضعاف، مثل 1,200 MB بدلاً من 150 MB.
2. **حساب الميغابكسل بـ 1,024²:** البادئة ميغا في الميغابكسل عشرية دائماً. فـ 50 MP تساوي 50,000,000 بكسل وليس 52,428,800.
3. **الخلط بين MB وMiB:** 150,000,000 B تساوي 150 MB لكنها تساوي نحو 143.05 MiB فقط. وتحدد وحدة الهدف المقسوم عليه: 10⁶ لـ MB و2²⁰ لـ MiB (انظر [البت والبايت وتحويلات الوحدات](./bit-byte-conversions.md)).
4. **استخدام عدد الألوان بدل عمق اللون:** لدى True Color ‏16,777,216 لوناً، لكن كل بكسل يخزّن 24 بت. والصيغة تأخذ البتات وليس عدد الألوان.
