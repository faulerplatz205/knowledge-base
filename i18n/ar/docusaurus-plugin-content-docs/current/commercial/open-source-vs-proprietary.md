# البرمجيات مفتوحة المصدر مقابل البرمجيات المملوكة

## التعريفات {/*#definitions*/}

**البرمجيات مفتوحة المصدر (Open Source Software)**: الشيفرة المصدرية متاحة للعموم. يمكن لأي شخص فحص البرمجية وتعديلها وتوزيعها، وفقًا لشروط ترخيصها (مثل MIT وGPL وApache).

**البرمجيات المملوكة (Proprietary Software)**: يحتفظ المورد بالشيفرة المصدرية سرية. ويخضع الاستخدام لاتفاقية ترخيص، ويُحظر عادةً التعديل وإعادة التوزيع.

## المصدر المفتوح {/*#open-source*/}

### المزايا {/*#advantages*/}

- **الاستخدام المجاني**: مجاني الاستخدام في معظم الحالات دون رسوم ترخيص
- **الشفافية**: يمكن تدقيق الشيفرة بحثًا عن الثغرات الأمنية والأخطاء
- **قيادة المجتمع**: يمكن للمجتمع مواصلة تطويره دون اعتماد كامل على المطور الأصلي
- **المرونة**: يمكن للفرد تخصيصه بما يناسب احتياجاته الخاصة

### العيوب {/*#disadvantages*/}

- **الدعم**: قد لا يكون دعم المجتمع موثوقًا، وفي المجتمعات الصغيرة قد لا يوجد أو يتطلب دفعًا إضافيًا
- **سهولة الاستخدام**: واجهات أقل صقلًا في الغالب مقارنة بالبدائل التجارية
- **المخاطر الأمنية**: الشيفرة المرئية للعموم يمكن أن يحللها المهاجمون أيضًا
- **تعقيد الترخيص**: قد تفرض تراخيص المصدر المفتوح المختلفة قيودًا (مثل copyleft)
- **عبء الصيانة**: تتطلب الاستضافة الذاتية خبرة داخلية ووقتًا

### أمثلة {/*#examples*/}

- Firefox
- Linux
- React
- VSCode

## البرمجيات المملوكة {/*#proprietary-software*/}

### المزايا {/*#advantages-1*/}

- **الدعم المهني**: دعم مخصص من المورد مع اتفاقيات SLA
- **الصقل وتجربة المستخدم**: استثمار أعلى عادةً في تجربة المستخدم والتوثيق
- **تحديثات وصيانة موثوقة**: يوفر المزود تحديثات وتصحيحات مختبرة بانتظام دون الحاجة إلى خبرة داخلية لإجراء التحديثات.
- **التكامل**: غالبًا ما تتوافق جيدًا مع البرمجيات الأخرى من الشركة المصنِّعة نفسها

### العيوب {/*#disadvantages-1*/}

- **التكلفة**: قد تكون رسوم الترخيص كبيرة، خاصة على نطاق واسع
- **الارتباط بالمورد (Vendor lock-in)**: الاعتماد على خارطة طريق المورد وأسعاره
- **انعدام الشفافية**: لا يمكن تدقيق الشيفرة المصدرية من حيث الأمان أو الجودة
- **القيود**: قدرة محدودة على التخصيص أو التوسيع بما يتجاوز ما يسمح به المورد

### أمثلة {/*#examples-1*/}

- Microsoft Office
- Windows وiOS وMacOS
- Discord
- Google Chrome

## المقارنة {/*#comparison*/}

|                       | مفتوح المصدر      | مملوك           |
| --------------------- | ----------------- | --------------- |
| الشيفرة المصدرية      | عامة              | سرية            |
| التكلفة               | مجاني عادةً       | رسوم ترخيص      |
| الدعم                 | المجتمع / مدفوع   | من المورد       |
| قابلية التخصيص        | عالية             | منخفضة          |
| الارتباط بالمورد      | منخفض             | مرتفع           |
| شفافية الأمان         | عالية             | منخفضة          |
