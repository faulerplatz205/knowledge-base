# حساب العرض

## نظرة عامة {/*#overview*/}

يحدد حساب العرض سعر بيع المنتج استنادًا إلى سعر الشراء مضافًا إليه جميع التكاليف والهوامش والضرائب المرتبطة به. ويتبع مخططًا موحدًا خطوة بخطوة يُستخدم في التجارة والتجزئة.

## مخطط الحساب {/*#calculation-scheme*/}

### جانب الشراء {/*#purchase-side*/}

| العملية | البند | ملاحظة |
| ------- | ----- | ------ |
|         | سعر الشراء حسب القائمة | سعر كتالوج المورد |
| −       | خصم المورد | نسبة مئوية تُخصم من سعر القائمة |
| =       | سعر الشراء الصافي |  |
| −       | خصم السداد النقدي من المورد | نسبة مئوية تُخصم مقابل الدفع المبكر |
| =       | سعر الشراء النقدي |  |
| +       | تكاليف التوريد | الشحن والجمارك |
| =       | **سعر التكلفة** | التكلفة الفعلية للبضائع |

### جانب البيع {/*#sales-side*/}

| العملية | البند | ملاحظة |
| ------- | ----- | ------ |
|         | سعر التكلفة | منقول من الجدول أعلاه |
| +       | علاوة التكاليف العامة | تكاليف التشغيل والإيجار والموظفين وغيرها |
| =       | سعر التعادل |  |
| +       | هامش الربح | هامش الربح المرغوب |
| =       | سعر البيع النقدي |  |
| +       | خصم السداد النقدي للعميل | يُضاف مجددًا: يتيح للعميل خصم الدفع المبكر |
| =       | سعر البيع الصافي |  |
| +       | خصم العميل | يُضاف مجددًا: يتيح للعميل الحصول على خصم |
| =       | سعر البيع حسب القائمة (صافي) |  |
| +       | ضريبة القيمة المضافة | مثل 19% في ألمانيا |
| =       | **سعر البيع حسب القائمة (إجمالي)** | السعر النهائي للعميل |

## ملاحظات {/*#notes*/}

- يُضاف كل من خصم السداد النقدي (Skonto) والخصم التجاري (Rabatt) **مجددًا** في جانب البيع لأنهما يمثلان خصومات محتملة قد يطالب بها العميل، ويجب أن يغطيها سعر البيع
- يُعبَّر عن علاوة التكاليف العامة عادةً بنسبة مئوية من سعر التكلفة، استنادًا إلى تكاليف التشغيل الفعلية للشركة
- يمكن إجراء الحساب تصاعديًا (من سعر الشراء إلى سعر البيع) أو تنازليًا (من سعر بيع مستهدف لاستنتاج سعر الشراء المطلوب)
