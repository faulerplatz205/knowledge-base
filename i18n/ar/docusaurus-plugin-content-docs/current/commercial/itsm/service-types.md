# أنواع خدمات تقنية المعلومات

## نظرة عامة {/*#overview*/}

يمكن تصنيف خدمات تقنية المعلومات بحسب طريقة تقديمها والجهة التي تديرها. يتناول هذا المدخل التعريفات الرئيسية لمفهوم «الخدمة» في الأطر المختلفة، وأنواع خدمات تقنية المعلومات الشائعة، ودورة حياة IMAC/R/D، والمصطلحات الأساسية في ITSM.

## تعريفات الخدمة {/*#service-definitions*/}

| المصدر | التعريف |
| ------ | ------- |
| BSI    | «الخدمة هي تركيب من الكائنات والعمليات لأداء مهمة ما.» |
| FitSM  | «الخدمة هي وسيلة لتقديم القيمة للعملاء من خلال دعم أهداف العميل.» |
| ITIL 4 | «الخدمة هي وسيلة لتمكين المشاركة في صنع القيمة من خلال تيسير النتائج التي يرغب العملاء في تحقيقها، دون أن يتولى العميل إدارة تكاليف ومخاطر محددة.» |

**الجودة تقنع، والخدمة تحسم.**

## نظرة عامة على أنواع خدمات تقنية المعلومات {/*#it-service-types-overview*/}

| نوع الخدمة | الوصف |
| ---------- | ----- |
| مبيعات تقنية المعلومات / تجارة تقنية المعلومات | توريد أنظمة ومكونات تقنية المعلومات، بما في ذلك الإعداد والاتصال بالشبكة |
| خدمة تقنية المعلومات (IT Service) | أي خدمة تُتاح بواسطة تقنية المعلومات ومن أجلها |
| دعم Break/Fix / الخدمة الميدانية / الخدمة في الموقع | خدمات تقنية معلومات تُنفَّذ عند الطلب في موقع العميل، وتُحاسَب على أساس العمل وقطع الغيار. تُحسَّن بواسطة إدارة الخدمة الميدانية (FSM) |
| الإدارة في الموقع | تقديم خدمات تقنية المعلومات في مقر العميل |
| خدمة الاستبدال (Swap Service) | يُزوَّد المستخدم بجهاز بديل مطابق |
| خدمة DIY | ينفّذ العميل الخدمة بنفسه (بإذن من الشركة المصنِّعة، بحيث يظل الضمان ساريًا مثلًا) |
| الخدمة السحابية | جميع الخدمات التي يقدمها مزودو الخدمات السحابية |
| الدردشة المباشرة (Live Chat) | يتصل العميل مباشرة، عبر أداة مدمجة أو تطبيق، بأحد موظفي مزود الخدمة على الويب |
| روبوت الدردشة (Chatbot) | نظام قائم على الذكاء الاصطناعي ومدمج في مواقع الويب والتطبيقات ووسائل التواصل الاجتماعي للتواصل تلقائيًا مع المستخدمين؛ وتوفر روبوتات الدردشة الهجينة دردشة مباشرة أيضًا |
| الخدمات المُدارة (Managed Services) | خدمات تقنية معلومات متكررة من مزود خدمات مُدارة (MSP)؛ يُتفق مسبقًا على نطاقها وجودتها في اتفاقية SLA، مثل المراقبة الاستباقية والصيانة عن بُعد |
| خدمة الضمان | خدمة مجانية بموجب مطالبات الضمان أو الكفالة |
| المجاملة (Goodwill) | خدمة مجانية طوعية يقدمها المتعاقد |
| خدمة مكتب المساعدة | خدمات تُقدَّم عبر مكتب مساعدة عبر الإنترنت |
| خدمة الصيانة | خدمة ضمن عقود الصيانة |
| خدمة الإصلاح | خدمات الإصلاح |
| الاستعانة بمصادر خارجية لتقنية المعلومات (IT Outsourcing / IT Sourcing) | التوريد الخارجي لخدمات تقنية المعلومات؛ إذ يتولى مزودو خدمات متخصصون المهام الصعبة بكفاءة |
| التهيئة على تقنية المعلومات (IT Induction) | تعريف العملاء والموظفين بأنظمة تقنية المعلومات |
| التدريب على تقنية المعلومات / التوجيه (IT Training / IT Instruction) | تدريب العملاء وتعليمهم مقابل رسوم |

## دورة حياة IMAC/R/D {/*#imacrd-lifecycle*/}

تصف دورة حياة **IMAC/R/D** مراحل جهاز تقنية المعلومات من التشغيل حتى التخلص منه:

| الحرف | المرحلة | الوصف |
| ----- | ------- | ----- |
| **I** | Install (التثبيت) | التوريد، والتثبيت المسبق (staging)، والنشر التشغيلي في الموقع النهائي |
| **M** | Move (النقل) | نقل الأجهزة، مثل عند الانتقال بين المكاتب أو إعادة التنظيم الداخلي |
| **A** | Add (الإضافة) | إضافات في العتاد/البرمجيات، مثل إضافة ذاكرة RAM أو تثبيت برامج جديدة |
| **C** | Change (التغيير) | تغييرات في الإعدادات أو تعديلات على صلاحيات المستخدمين والسياسات |
| **R** | Remove / Rollback (الإزالة / التراجع) | إلغاء تثبيت الأجهزة وإعادتها إلى مخزون تقنية المعلومات |
| **D** | Dispose (التخلص) | المحو الآمن للبيانات (data erasure)، ثم إعادة التسويق (إعادة البيع)، أو التخلص المتوافق مع المعايير البيئية |

## مصطلحات ITSM الأساسية {/*#key-itsm-terms*/}

| المصطلح | الوصف |
| ------- | ----- |
| **Service Desk** | نقطة خدمة للمستخدمين؛ يُسمى أيضًا Helpdesk |
| **ITSM** | إدارة خدمات تقنية المعلومات (IT Service Management): مجموع الأنشطة التي ينفذها مزود خدمات تقنية المعلومات لتخطيط خدمات تقنية المعلومات وتقديمها وتشغيلها والتحكم فيها |
| **Service Portfolio** | مجموعة جميع خدمات تقنية المعلومات المعروضة؛ تشمل كتالوج الخدمات والإرشادات والمسؤوليات |
| **[SLA](./sla.md)** | اتفاقية مستوى الخدمة (Service Level Agreement): اتفاق تعاقدي على مستويات الخدمة بين المزود والعميل |
| **OLA** | اتفاقية المستوى التشغيلي (Operational Level Agreement): اتفاق داخلي بين فرق تقنية المعلومات/أقسامها |
| **KPI** | مؤشر الأداء الرئيسي (Key Performance Indicator): مقاييس مرتبطة بأهداف العمل الحرجة، مثل توافر الخدمة أو عدد انقطاعات الخدمة |
| **SOA** | البنية الموجهة بالخدمات (Service-Oriented Architecture): تُقسَّم عمليات الأعمال والأنظمة إلى وحدات وتُربط عبر خدمات تقنية معلومات قابلة لإعادة الاستخدام |
| **[IaaS](../../cloud/service-models.md#infrastructure-as-a-service-iaas)** | البنية التحتية كخدمة (Infrastructure as a Service): منصة سحابية توفر البنية التحتية كأساس لتطبيق ما |
| **Service Availability 24/7** | الخدمة متاحة في جميع الأوقات |
| **Service Availability 12/5** | الخدمة متاحة خلال ساعات العمل الاعتيادية |
