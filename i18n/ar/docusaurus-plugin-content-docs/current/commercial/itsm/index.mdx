# إدارة خدمات تقنية المعلومات (ITSM)

المفاهيم والعمليات الأساسية لإدارة خدمات تقنية المعلومات وفق إطار ITIL، وتشمل كيفية تصنيف طلبات الخدمة وتحديد أولوياتها وحلها، بدءًا من الاتصال الأول بمكتب المساعدة وصولًا إلى إدارة الحوادث والمشكلات والتغيير والإصدارات.
