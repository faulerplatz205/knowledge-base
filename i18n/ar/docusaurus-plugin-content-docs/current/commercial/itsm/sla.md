# اتفاقية مستوى الخدمة (SLA)

## نظرة عامة {/*#overview*/}

**اتفاقية مستوى الخدمة (SLA، Service Level Agreement)** هي عقد بين مزود خدمات تقنية المعلومات وعميل، يحدد نطاق خدمات تقنية المعلومات المقدمة وجودتها وشروطها.

## البنية النموذجية لاتفاقية SLA {/*#typical-sla-structure*/}

### 1. الوصف / النطاق {/*#1-description--scope*/}

يحدد المشكلات التقنية المشمولة وكيفية معالجتها وقنوات الدعم المستخدمة (الهاتف، البريد الإلكتروني). ويحدد أيضًا العتاد والأنظمة المشمولة.

### 2. [الأولويات](./priorities.md) {/*#2-priorities*/}

ثلاثة مستويات أولوية أو أكثر بأزمنة استجابة مختلفة. مثال:

| الأولوية | زمن الاستجابة |
| -------- | ------------- |
| الأولوية 1 | ساعة عمل واحدة، مع رسم إضافي للاستعجال |
| الأولوية 2 | 5 ساعات عمل، أولوية قياسية |
| الأولوية 3 | يوم عمل واحد |

**زمن الاستجابة:** الفترة بين الإبلاغ عن العطل إلى [مكتب المساعدة](./service-requests.md) وبدء العمل على حل المشكلة في مستوى الدعم المسؤول.

### 3. أوقات الخدمة {/*#3-service-times*/}

| اليوم | الساعات |
| ----- | ------- |
| الاثنين–الجمعة | 07:00–20:00 |
| السبت | 09:00–18:00 |
| الأحد والعطلات الرسمية | لا توجد خدمة |
| ساعات ممتدة | متاحة عند الطلب |

### 4. اللغات {/*#4-languages*/}

اللغات المدعومة في الدعم (مثل الألمانية والإنجليزية).

### 5. مقاييس الجودة: استقبال المكالمات {/*#5-quality-metrics-call-acceptance*/}

| المقياس | الهدف |
| ------- | ----- |
| المكالمات المُجابة | 95 % من جميع المكالمات الواردة، وأقل من 5 % مفقودة |
| الإجابة خلال 20 ثانية | 75 % |
| الإجابة خلال 40 ثانية | 90 % |
| المعالجة عبر البريد الصوتي | 10 % كحد أقصى |

### 6. مقاييس الجودة: حل المشكلات {/*#6-quality-metrics-problem-resolution*/}

| المقياس | الهدف |
| ------- | ----- |
| متوسط زمن معالجة المكالمات | 30 دقيقة كحد أقصى |
| تقرير مرحلي في حال عدم الإجابة خلال | 4 ساعات |
| متوسط زمن معالجة الأعطال | ساعتان كحد أقصى |
| أقصى زمن معالجة | 3 أيام |
| الحد الأدنى لمعدل الحل | 70 % خلال يومي عمل |

### 7. مقياس الجودة: رضا العملاء {/*#7-quality-metric-customer-satisfaction*/}

يُقاس عبر استبيان إلكتروني ومكالمات متابعة (اتصال لاحق وتقييم مع 10 % من المتصلين).

### 8. إعداد التقارير {/*#8-reporting*/}

مراجعة شهرية؛ وتقييم إحصائي ربع سنوي.

### 9. السريان والمدة {/*#9-validity-and-duration*/}

يحدد مدة اتفاقية SLA وموعد إعادة التفاوض عليها (مثل «سارية حتى 1 أغسطس 20xx»).

### 10. الموقّعون {/*#10-signatories*/}

يوقّع المزود والعميل كل منهما على الاتفاقية.

## إدارة مستوى الخدمة (SLM) {/*#service-level-management-slm*/}

تضمن **SLM** إبرام اتفاقيات SLA مع العملاء وتصميم الخدمات بما يحقق مستويات الخدمة المتفق عليها.

**المهام:**

- جمع متطلبات الخدمة
- التحقق من تحقيق مستويات الخدمة المتفق عليها
- توفير المعلومات في تقارير مستوى الخدمة

## الأدوار {/*#roles*/}

### مدير مستوى الخدمة (Service Level Manager) {/*#service-level-manager*/}

مالك عملية إدارة مستوى الخدمة.

المسؤوليات:

- التفاوض على اتفاقيات SLA
- ضمان الالتزام بها
- ضمان دعم جميع عمليات ITSM واتفاقيات OLA وعقود الأطراف الخارجية لأهداف مستوى الخدمة المتفق عليها
- مراقبة مستويات الخدمة وإعداد التقارير

### مالك الخدمة (Service Owner، Serviceverantwortlicher) {/*#service-owner-serviceverantwortlicher*/}

مسؤول عن تقديم خدمة البنية التحتية ضمن اتفاقيات SLA المتفق عليها.

المسؤوليات:

- العمل بصفة طرف مفاوض لمدير مستوى الخدمة عند الاتفاق على اتفاقيات OLA
- عادةً مدير يقود فريقًا من المتخصصين التقنيين أو قسم دعم داخلي

## اتفاقية المستوى التشغيلي (OLA) {/*#ola-operational-level-agreement*/}

**OLA** هي اتفاق داخلي بين فرق تقنية المعلومات أو أقسامها بشأن تقديم الخدمة على المستوى التشغيلي. تدعم اتفاقيات OLA الوفاء باتفاقيات SLA الخارجية.
