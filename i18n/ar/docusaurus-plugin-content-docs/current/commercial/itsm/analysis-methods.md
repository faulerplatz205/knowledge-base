# طرق تحليل المشكلات

## نظرة عامة {/*#overview*/}

تُستخدم هذه الطرق في [إدارة المشكلات](./problem-management.md) للعثور بصورة منهجية على السبب الجذري للمشكلة.

## طريقة 5 لماذا (5-W-Methode) {/*#5-why-method-5-w-methode*/}

**الهدف:** العثور على السبب الجذري للمشكلة بطرح السؤال "لماذا؟" مرارًا، بحيث تصبح كل إجابة السؤال التالي. وتكفي عادة خمس مرات.

**مثال (مشكلة طابعة):**

| الخطوة    | السؤال                                    | الإجابة                                                          |
| ------- | ------------------------------------------- | --------------------------------------------------------------- |
| المشكلة | الطابعة لا تطبع بوضوح          |                                                                 |
| لماذا؟    | لماذا لا تطبع الطابعة بوضوح؟      | لا تُظهر جميع الأحرف بوضوح / المخرجات غير مقروءة |
| لماذا؟    | لماذا لا تُظهر جميع الأحرف بوضوح؟ | الحبر/المسحوق رديء                                       |
| لماذا؟    | لماذا الحبر/المسحوق رديء؟                  | يتلطخ وأحيانًا لا يطبع إطلاقًا                   |
| لماذا؟    | لماذا يتلطخ وأحيانًا لا يطبع؟  | جودة المسحوق منخفضة                                        |
| لماذا؟    | لماذا جودة المسحوق منخفضة؟               | **شُري أرخص مسحوق** (السبب الجذري)               |

## مخطط إيشيكاوا (مخطط عظم السمكة) {/*#ishikawa-diagram-fishbone-diagram*/}

طوّر العالم الياباني كاورو إيشيكاوا **مخطط إيشيكاوا** (ويسمى أيضًا **مخطط السبب والنتيجة** أو **مخطط عظم السمكة**) في أربعينيات القرن العشرين. وهو يعرض أسباب المشكلة بصريًا.

**البنية:**

- سهم أفقي يشير إلى اليمين => **وصف المشكلة عند الرأس** (النتيجة)
- أسهم مائلة تتفرع من الخط الأفقي => **فئات التأثير الرئيسية** ("العظام")
- أسهم أصغر تتفرع من العظام المائلة => **الأسباب الفرعية** (Nebenursachen)

**معنى السهم:** كل سهم "يسهم في" النتيجة الموصوفة عند الرأس.

### فئات التأثير الرئيسية (8M) {/*#main-influence-categories-8m*/}

- Category
- Material
- People
- Machine
- Method
- Management
- Environment
- Measurement
- Money

ويمكن اعتماد فئات تأثير أخرى بحسب المشكلة.

### إنشاء مخطط إيشيكاوا {/*#creating-an-ishikawa-diagram*/}

1. كتابة وصف المشكلة عند رأس السهم الأفقي (في أقصى اليمين)
2. تحديد فئات التأثير الرئيسية (8M)
3. إيجاد الأسباب الرئيسية عبر العصف الذهني للفريق (تُرسم أسهمًا موازية للمحور الأفقي)
4. إيجاد الأسباب الفرعية لكل سبب رئيسي (تُرسم أسهمًا مائلة تتفرع من سهم السبب الرئيسي)

## دورة DMAIC {/*#dmaic-cycle*/}

تُستخدم **دورة DMAIC** للمشكلات والمشاريع المعقدة. ويرمز الاختصار إلى المراحل الخمس:

| المرحلة       | السؤال الرئيسي                    | الطرق / الأدوات                                                                                                       |
| ----------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Define** (التعريف)  | ما المشكلة؟            | ملاحظات العملاء، تعريف المشكلة، النطاق، تحليل مؤشرات الأداء الرئيسية، مصفوفة RACI                                               |
| **Measure** (القياس) | ما حجم المشكلة؟         | تحليل الوضع الراهن (IST)، مراجعة [SLA](./sla.md)، توضيح مستوى التصعيد                                     |
| **Analyse** (التحليل) | ما الأسباب الجذرية؟       | طريقة 5 لماذا، استطلاعات العملاء، [قاعدة بيانات الأخطاء](./problem-management.md#known-error-database-kedb)، مخطط إيشيكاوا |
| **Improve** (التحسين) | هل يمكن تطوير حل؟    | المحاكاة، التشغيل التجريبي، مصفوفة الحلول، مخطط إيشيكاوا                                                             |
| **Control** (الضبط) | هل يمكن تأمين التحسين؟ | المراقبة، نظام إدارة الخدمات                                                                          |

## مصفوفة حل المشكلات / مصفوفة السبب والنتيجة (Problemlösungsmatrix / Ursachen-Wirkungs-Matrix) {/*#problemlösungsmatrix--ursachen-wirkungs-matrix*/}

تحلل **مصفوفة السبب والنتيجة** (المبنية على طريقة Kepner-Tregoe) المشكلة وفق أربعة أبعاد لحصر السبب الجذري بصورة منهجية عبر مقارنة ما هو قائم (IS) بما هو غير قائم (IS NOT):

| البعد                   | IS (المشكلة)                            | IS NOT (المشكلة)               | الانحراف                                          | السبب المحتمل              |
| --------------------------- | ------------------------------------------- | ---------------------------------- | -------------------------------------------------- | --------------------------- |
| **التحديد (ماذا)**         | ما المشكلة؟                        | ما الذي ليس المشكلة؟           | ما الفرق بين الحالة القائمة والحالة المستهدفة؟ | ما السبب المحتمل؟ |
| **التموضع (أين)**        | أين تحدث المشكلة؟               | أين لا تحدث؟           | ما المختلف في ذلك الموضع؟                | ما السبب المحتمل؟ |
| **الزمن (متى)**             | متى ظهرت المشكلة؟                | متى لم تظهر؟            | ما المختلف في ذلك الوقت؟                   | ما السبب المحتمل؟ |
|                             | في أي فترة رُصدت المشكلة؟ | في أي فترة لم تظهر؟ | ما المختلف خلال تلك الفترة؟             |                             |
| **الأهمية (كم)** | ما حجم المشكلة / مدى انتشارها؟        | ما مدى صغرها أو محدوديتها؟        | ما الفرق في النطاق؟                | ما السبب المحتمل؟ |
|                             | كم عدد (الوحدات) المتأثرة؟              | كم عدد (الوحدات) غير المتأثرة؟ |                                                    |                             |
|                             | أي جزء متأثر؟                     | أي جزء غير متأثر؟           |                                                    |                             |
