# اصطلاحات تسمية Class وID

## Class {/*#class*/}

kebab-case

### مثال {/*#example*/}

```text
class="nav-bar"
class="button-primary"
```

---

## Id {/*#id*/}

camelCase

### مثال {/*#example-1*/}

```text
id="mainHeader"
id="userProfileForm"
```
