# الروابط الصلبة والرمزية

**الرابط** هو مرجع من مسار في نظام الملفات إلى ملف أو دليل آخر. يدعم Linux نوعين: **الروابط الصلبة** و**الروابط الرمزية (اللينة)**. يتم إنشاء كلا النوعين بالأمر `ln` لكنهما يتصرفان بشكل مختلف تمامًا.

## Inodes {/*#inodes*/}

يُعرَّف كل ملف في نظام ملفات Linux بواسطة **inode**، وهو رقم يشير إلى البيانات الفعلية على القرص. اسم الملف ليس سوى تسمية ترتبط بـ inode، ويمكن لعدة أسماء ملفات أن تشير إلى inode نفسه.

```bash
ls -i file.txt    # Show the inode number of a file
```

## الروابط الصلبة {/*#hard-links*/}

ينشئ الرابط الصلب **اسم ملف إضافيًا للـ inode نفسه**. يشير الاسمان إلى الملف نفسه تمامًا على القرص. ولا يُعدّ أي منهما "الأصل". لا تُحرَّر بيانات الملف إلا عند إزالة آخر رابط صلب إليه.

### إنشاء رابط صلب {/*#creating-a-hard-link*/}

```bash
ln target.txt linkname.txt
```

### الخصائص {/*#properties*/}

- يشترك الاسمان في inode نفسه
- إزالة أحد الاسمين لا تؤثر في الآخر
- لا يمكنه العبور بين أنظمة ملفات مختلفة، إذ يجب أن يوجد الاسمان على القسم نفسه
- لا يمكن ربط الدلائل (مع استثناءات نادرة محجوزة للنظام)
- لا يمكن الربط بملف غير موجود

### مثال {/*#example*/}

```bash
echo "hello" > original.txt
ln original.txt hardlink.txt
ls -li original.txt hardlink.txt
# 12345 -rw-r--r-- 2 user user 6 Apr 25 10:00 original.txt
# 12345 -rw-r--r-- 2 user user 6 Apr 25 10:00 hardlink.txt
rm original.txt
cat hardlink.txt    # still prints "hello"
```

## الروابط الرمزية (اللينة) {/*#symbolic-soft-links*/}

الرابط الرمزي ملف خاص صغير **يخزّن مسار** ملف أو دليل آخر. وله inode خاص به. إذا نُقل الهدف أو حُذف، يصبح الرابط الرمزي "معلّقًا" (dangling) ومعطلًا.

### إنشاء رابط رمزي {/*#creating-a-symbolic-link*/}

```bash
ln -s target.txt linkname.txt
```

### الخصائص {/*#properties-1*/}

- له inode خاص به منفصل عن الهدف
- يمكنه العبور بين أنظمة ملفات مختلفة بحرية
- يمكنه ربط الدلائل
- يمكنه الإشارة إلى هدف غير موجود (رابط معطل/معلّق)
- يمكنه استخدام مسارات مطلقة أو نسبية كهدف

### مثال {/*#example-1*/}

```bash
echo "hello" > original.txt
ln -s original.txt softlink.txt
ls -li original.txt softlink.txt
# 12345 -rw-r--r-- 1 user user  6 Apr 25 10:00 original.txt
# 12346 lrwxrwxrwx 1 user user 12 Apr 25 10:00 softlink.txt -> original.txt
rm original.txt
cat softlink.txt    # error: No such file or directory
```

## الروابط الصلبة مقابل اللينة {/*#hard-vs-soft-links*/}

| الخاصية                   | الرابط الصلب           | الرابط اللين |
| -------------------------- | ------------------- | --------- |
| يشير إلى                  | inode               | مسار      |
| له inode خاص؟                 | لا (نفس الهدف) | نعم       |
| يمكنه العبور بين أنظمة الملفات؟ | لا                  | نعم       |
| يمكنه ربط الدلائل؟      | لا                  | نعم       |
| يمكنه استهداف ملف مفقود؟ | لا                  | نعم       |
| يبقى بعد حذف الهدف؟  | نعم                 | لا        |
| يُنشأ باستخدام               | `ln`                | `ln -s`   |

## خيارات `ln` الشائعة {/*#common-ln-options*/}

| الأمر              | الوصف                                                                       |
| -------------------- | --------------------------------------------------------------------------------- |
| `ln target name`     | إنشاء رابط صلب                                                                |
| `ln -s target name`  | إنشاء رابط رمزي (لين)                                                     |
| `ln -f target name`  | إزالة (استبدال) ملف وجهة موجود                                   |
| `ln -i target name`  | طلب التأكيد قبل استبدال وجهة موجودة                                 |
| `ln -b target name`  | نسخ احتياطي لوجهة موجودة قبل استبدالها (يُلحق `~` باسم الملف) |
| `ln -v target name`  | طباعة اسم كل ملف مرتبط (وضع مفصل)                                      |
| `ln -sf target name` | فرض استبدال رابط موجود بالاسم نفسه                                   |
| `readlink name`      | عرض المسار الذي يشير إليه رابط رمزي                                           |
| `readlink -f name`   | تحليل جميع الروابط الرمزية إلى المسار المطلق المعياري                               |

## متى يُستخدم كل نوع {/*#when-to-use-which*/}

- **الروابط الصلبة** مفيدة للاحتفاظ بعدة أسماء ثابتة للملف نفسه (مثل لقطات النسخ الاحتياطي التي تشترك في المحتوى غير المتغير) دون استهلاك مساحة قرص إضافية.
- **الروابط اللينة** هي الخيار الأكثر شيوعًا للاختصارات. على سبيل المثال التبديل بين إصدارات أداة ما (مثل `/usr/bin/python => python3.12`)، أو الإشارة إلى ملفات عبر نقاط ربط مختلفة.
