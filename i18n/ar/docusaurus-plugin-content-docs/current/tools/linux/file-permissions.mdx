# أذونات الملفات في Linux

يغطي خياران من `ls` الحالات اليومية: عرض التفاصيل (بما فيها الأذونات) وإظهار الملفات المخفية.

## عرض الملفات {/* #listing-files */}

```bash
ls -l    # Long format: permissions, owner, size, date, name
ls -a    # Show all files, including hidden ones
```

الملفات والدلائل التي يبدأ اسمها بنقطة (`.bashrc`، `.config`) تكون **مخفية** ولا تظهر إلا مع `ls -a`. غالبًا ما يُجمع الخياران معًا على الصورة `ls -la`.

## مثال على المخرجات {/* #example-output */}

يصف كل سطر من `ls -l` عنصرًا واحدًا عبر عدة أعمدة:

```bash
-rw-r--r-- 1 user staff 1024 Apr 25 10:00 notes.txt
drwxr-xr-x 2 user staff 4096 Apr 25 09:30 projects
```

| العمود      | مثال        | المعنى                   |
| ----------- | -------------- | ------------------------- |
| الأذونات | `-rw-r--r--`   | نوع الملف والأذونات |
| الروابط       | `1`            | عدد الروابط الصلبة      |
| المالك       | `user`         | مالك الملف         |
| المجموعة       | `staff`        | المجموعة التي ينتمي إليها الملف |
| الحجم        | `1024`         | الحجم بالبايت             |
| التاريخ والوقت | `Apr 25 10:00` | وقت آخر تعديل    |
| الاسم        | `notes.txt`    | اسم الملف أو الدليل    |

## قراءة تدوين الأذونات {/* #reading-the-permission-notation */}

يبدأ سطر `ls -l` بسلسلة من 10 أحرف مثل `-rwxr-xr-x`. وتتكون من أربعة أجزاء:

| الموضع | مثال | المعنى                                                |
| -------- | ------- | ------------------------------------------------------ |
| 1        | `-`     | نوع الملف (`-` = ملف، `d` = دليل، `l` = رابط رمزي) |
| 2-4      | `rwx`   | أذونات **المالك**                          |
| 5-7      | `r-x`   | أذونات **المجموعة**                          |
| 8-10     | `r-x`   | أذونات **الآخرين**                         |

تستخدم كل مجموعة من المجموعات الثلاث العلامات الثلاث نفسها:

| العلامة | المعنى | التأثير على الملف    | التأثير على الدليل      |
| ---- | ------- | ------------------- | -------------------------- |
| `r`  | قراءة    | قراءة المحتويات   | عرض العناصر           |
| `w`  | كتابة   | تعديل المحتويات | إنشاء/حذف العناصر      |
| `x`  | تنفيذ | التشغيل كبرنامج    | الدخول (`cd`) إلى الدليل |

تعني `-` في موضع الحرف أن الإذن غير ممنوح. وبذلك تعني `-rwxr-xr-x`: ملف عادي، يمكن للمالك القراءة والكتابة والتنفيذ، ويمكن للمجموعة والآخرين القراءة والتنفيذ دون الكتابة.
