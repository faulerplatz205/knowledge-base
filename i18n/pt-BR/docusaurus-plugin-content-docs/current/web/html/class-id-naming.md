# Convenções de Nomenclatura de Class e ID

## Class {/*#class*/}

kebab-case

### Exemplo {/*#example*/}

```text
class="nav-bar"
class="button-primary"
```

---

## Id {/*#id*/}

camelCase

### Exemplo {/*#example-1*/}

```text
id="mainHeader"
id="userProfileForm"
```
