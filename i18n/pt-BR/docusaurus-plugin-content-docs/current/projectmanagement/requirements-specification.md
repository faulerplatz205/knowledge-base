# Caderno de requisitos e caderno de especificações funcionais

## Visão geral {/*#overview*/}

No gerenciamento de projetos, o **caderno de requisitos** e o **caderno de especificações funcionais** são dois documentos centrais que definem o que um sistema deve fazer e como será implementado.

- O **caderno de requisitos** é redigido pelo cliente e descreve **o que** é necessário
- O **caderno de especificações funcionais** é redigido pelo contratado e descreve **como** os requisitos serão atendidos

## Caderno de requisitos {/*#requirement-specification*/}

Contém os requisitos de um cliente a um contratado e uma ideia aproximada do sistema desejado.

- Descrição dos objetivos do projeto
- Descrição da situação atual
- Requisitos relacionados à segurança
- Requisitos funcionais (O que o sistema deve fazer?)
- Requisitos não funcionais (p. ex. desempenho, segurança, disponibilidade, usabilidade)
- Prazo
- Orçamento

## Caderno de especificações funcionais {/*#functional-specification*/}

Derivado do caderno de requisitos. É a resposta do contratado, que descreve como os requisitos serão implementados.

- Conceito técnico (arquitetura, tecnologias)
  - Descrição detalhada dos componentes do sistema
  - Definições de interfaces
  - Modelos de dados
- Critérios de teste e condições de aceitação
- Cronograma do projeto e marcos
- Estimativa de custos
