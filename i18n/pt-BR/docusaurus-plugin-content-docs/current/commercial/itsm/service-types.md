# Tipos de serviços de TI

## Visão geral {/*#overview*/}

Os serviços de TI podem ser classificados de acordo com a forma como são prestados e com quem os gerencia. Isso abrange as principais definições de "serviço" nos diversos frameworks, os tipos comuns de serviços de TI, o ciclo de vida IMAC/R/D e a terminologia essencial de ITSM.

## Definições de serviço {/*#service-definitions*/}

| Fonte  | Definição                                                                                                                                                                                                  |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BSI    | "Um serviço é a composição de objetos e processos para cumprir uma tarefa."                                                                                                                                |
| FitSM  | "Um serviço é um meio de entregar valor aos clientes apoiando os objetivos do cliente."                                                                                                                    |
| ITIL 4 | "Um serviço é um meio de possibilitar a cocriação de valor, facilitando os resultados que os clientes desejam alcançar, sem que o cliente tenha de gerenciar custos e riscos específicos."                  |

**A qualidade convence, o serviço decide.**

## Visão geral dos tipos de serviços de TI {/*#it-service-types-overview*/}

| Tipo de serviço                                     | Descrição                                                                                                                                                                                       |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vendas de TI / Comércio de TI                       | Aquisição de sistemas e componentes de TI, incluindo instalação e conexão à rede                                                                                                                |
| Serviço de TI                                       | Qualquer serviço possibilitado por e para a TI                                                                                                                                                  |
| Suporte Break/Fix / Field Service / Serviço no local | Serviços de TI executados sob demanda nas instalações do cliente; cobrança de mão de obra e peças. Otimizado pelo Field Service Management (FSM)                                               |
| On-Site Management                                  | Prestação de serviços de TI nas instalações do cliente                                                                                                                                          |
| Swap Service                                        | Um dispositivo de reposição idêntico é fornecido ao usuário                                                                                                                                     |
| Serviço DIY                                         | O cliente executa o serviço por conta própria (com permissão do fabricante, p. ex., a garantia permanece válida)                                                                                |
| Cloud Service                                       | Todos os serviços oferecidos por provedores de nuvem                                                                                                                                            |
| Live Chat                                           | Por meio de um widget/aplicativo, o cliente é conectado ao vivo a um colaborador do prestador de serviços web                                                                                   |
| Chatbot                                             | Sistema com IA integrado a sites, aplicativos e redes sociais para se comunicar automaticamente com os usuários; chatbots híbridos também oferecem live chat                                    |
| Managed Services                                    | Serviços de TI recorrentes de um Managed Services Provider (MSP); escopo e qualidade são acordados antecipadamente em um SLA, p. ex., monitoramento proativo e manutenção remota                |
| Serviço de garantia (Warranty Service)              | Serviço gratuito em razão de direitos de garantia                                                                                                                                               |
| Goodwill                                            | Serviço gratuito voluntário por parte do contratado                                                                                                                                             |
| Serviço de helpdesk                                 | Serviços prestados por meio de um helpdesk online                                                                                                                                               |
| Serviço de manutenção                               | Serviço no âmbito de contratos de manutenção                                                                                                                                                    |
| Serviço de reparo                                   | Serviços de reparo                                                                                                                                                                              |
| Terceirização de TI / IT Sourcing                   | Aquisição externa de serviços de TI; prestadores de serviços de TI especializados tratam com eficiência tarefas de difícil solução                                                             |
| IT Induction                                        | Introdução de clientes e colaboradores aos sistemas de TI                                                                                                                                       |
| Treinamento de TI / Instrução de TI                 | Treinamento e capacitação de clientes mediante pagamento                                                                                                                                        |

## Ciclo de vida IMAC/R/D {/*#imacrd-lifecycle*/}

O ciclo de vida **IMAC/R/D** descreve as fases de um dispositivo de TI, da implantação ao descarte:

| Letra  | Fase                 | Descrição                                                                                                                              |
| ------ | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **I**  | Install              | Aquisição, pré-instalação (staging) e implantação operacional no local final                                                           |
| **M**  | Move                 | Realocação de dispositivos, p. ex., em mudanças de escritório ou reorganizações internas                                               |
| **A**  | Add                  | Adições de hardware/software, p. ex., inclusão de RAM ou instalação de novos programas                                                 |
| **C**  | Change               | Alterações de configuração ou ajustes de direitos de usuário e políticas                                                               |
| **R**  | Remove / Rollback    | Desinstalação de dispositivos e devolução ao inventário de TI                                                                          |
| **D**  | Dispose              | Exclusão segura de dados (data erasure), posterior remarketing (revenda) ou descarte ambientalmente adequado                           |

## Principais termos de ITSM {/*#key-itsm-terms*/}

| Termo                                                                      | Descrição                                                                                                                                                         |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Service Desk**                                                           | Ponto de atendimento para usuários; também chamado de Helpdesk                                                                                                    |
| **ITSM**                                                                   | IT Service Management: soma de todas as atividades realizadas por um prestador de serviços de TI para planejar, fornecer, operar e controlar serviços de TI        |
| **Service Portfolio**                                                      | Coleção de todos os serviços de TI oferecidos; inclui catálogo de serviços, diretrizes e responsabilidades                                                        |
| **[SLA](./sla.md)**                                                        | Service Level Agreement: acordo contratual sobre níveis de serviço entre prestador e cliente                                                                      |
| **OLA**                                                                    | Operational Level Agreement: acordo interno entre equipes/departamentos de TI                                                                                     |
| **KPI**                                                                    | Key Performance Indicator: métricas alinhadas a metas críticas de negócio, p. ex., disponibilidade do serviço ou número de interrupções de serviço                |
| **SOA**                                                                    | Service-Oriented Architecture: processos de negócio e sistemas são modularizados e vinculados por meio de serviços de TI reutilizáveis                            |
| **[IaaS](../../cloud/service-models.md#infrastructure-as-a-service-iaas)** | Infrastructure as a Service: plataforma em nuvem que fornece infraestrutura como base para uma aplicação                                                          |
| **Disponibilidade de serviço 24/7**                                        | O serviço está disponível o tempo todo                                                                                                                            |
| **Disponibilidade de serviço 12/5**                                        | O serviço está disponível durante o horário comercial regular                                                                                                     |
