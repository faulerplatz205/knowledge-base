# Dados Pessoais

Segundo o GDPR (Regulamento Geral sobre a Proteção de Dados), dados pessoais são quaisquer informações relativas a uma pessoa natural identificada ou identificável (Art. 4 GDPR).

## Dados Pessoais Regulares {/*#regular-personal-data*/}

Os dados pessoais regulares incluem informações que podem identificar uma pessoa direta ou indiretamente:

- Nome (primeiro nome, sobrenome)
- Endereço (rua, cidade, código postal)
- Endereço de e-mail
- Número de telefone
- Data de nascimento
- Endereço IP
- Dados de localização
- Identificadores online (p. ex. cookies, IDs de dispositivo)
- Números de conta bancária ou de cartão de crédito
- IDs de cliente ou de funcionário

## Categorias Especiais de Dados Pessoais {/*#special-categories-of-personal-data*/}

As categorias especiais de dados pessoais (Art. 9 GDPR) são particularmente sensíveis e estão sujeitas a requisitos de tratamento mais rigorosos. O tratamento é, em regra, proibido, a menos que se aplique uma exceção específica:

- Origem racial ou étnica
- Opiniões políticas
- Convicções religiosas ou filosóficas
- Filiação sindical
- Dados genéticos
- Dados biométricos utilizados para identificação unívoca (p. ex. impressões digitais, reconhecimento facial)
- Dados de saúde
- Dados relativos à vida sexual ou à orientação sexual

## Princípios do Tratamento (Art. 5 GDPR) {/*#principles-of-processing-art-5-gdpr*/}

O Art. 5 GDPR estabelece os princípios que todo tratamento de dados pessoais deve satisfazer. Eles se aplicam além de uma base legal: uma atividade de tratamento coberta pelo Art. 6 GDPR continua sendo ilícita se violar um desses princípios.

| Princípio                          | Significado                                                                                                                  |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Licitude, lealdade e transparência | O tratamento exige uma base legal, deve ser compreensível para o titular dos dados e não pode ocorrer de forma oculta        |
| Limitação da finalidade            | Os dados são coletados para finalidades determinadas e não podem ser usados posteriormente para uma finalidade incompatível  |
| Minimização de dados               | Somente podem ser tratados os dados adequados e necessários para a finalidade                                                |
| Exatidão                           | Os dados devem estar corretos e atualizados; dados inexatos precisam ser corrigidos ou apagados                              |
| Limitação da conservação           | Os dados são mantidos apenas pelo tempo necessário para a finalidade; depois disso, são apagados ou anonimizados             |
| Integridade e confidencialidade    | Medidas técnicas e organizacionais adequadas protegem os dados contra perda e acesso não autorizado                          |
| Responsabilização                  | O controlador deve ser capaz de demonstrar a conformidade com todos esses princípios                                         |

Consequências na prática:

- **Limitação da finalidade** significa que um endereço de e-mail coletado para o processamento de pedidos não pode simplesmente ser usado para uma newsletter.
- **Minimização de dados** aplica-se a todo formulário de entrada: um campo que não é necessário para a finalidade não pode ser obrigatório.
- **Limitação da conservação** exige um conceito de exclusão com prazos de retenção por categoria de dados, o que pode entrar em conflito com obrigações legais de guarda, por exemplo no direito tributário.
- **Integridade e confidencialidade** correspondem aos clássicos [objetivos de segurança](../fundamentals/security-goals.md), implementados por meio de criptografia, controle de acesso, registro de logs e backups.
- **Responsabilização** inverte o ônus da prova: cabe ao controlador documentar a licitude, e não ao titular dos dados provar a violação. Registros das atividades de tratamento, a base legal por atividade e comprovantes de consentimento servem a esse propósito.

## Bases Legais para o Tratamento de Dados (Art. 6 GDPR) {/*#legal-bases-for-data-processing-art-6-gdpr*/}

Dados pessoais somente podem ser tratados se pelo menos uma das seguintes bases legais se aplicar:

- **Consentimento (Art. 6(1)(a) GDPR):** O titular dos dados deu consentimento voluntário, informado e inequívoco para o tratamento de seus dados para uma ou mais finalidades específicas. O consentimento pode ser retirado a qualquer momento.
- **Execução de contrato (Art. 6(1)(b) GDPR):** O tratamento é necessário para a execução de um contrato do qual o titular dos dados é parte, ou para diligências pré-contratuais a pedido dele (p. ex. processamento de um contrato de compra ou de trabalho).
- **Obrigação legal (Art. 6(1)(c) GDPR):** O tratamento é necessário para o cumprimento de uma obrigação legal (p. ex. exigências fiscais ou contábeis).
- **Interesses vitais (Art. 6(1)(d) GDPR):** O tratamento é necessário para proteger os interesses vitais do titular dos dados ou de outra pessoa (p. ex. em uma emergência médica).
- **Função pública (Art. 6(1)(e) GDPR):** O tratamento é necessário para o exercício de uma função de interesse público ou para o exercício de autoridade oficial.
- **Interesses legítimos (Art. 6(1)(f) GDPR):** O tratamento é necessário para os fins dos interesses legítimos perseguidos pelo controlador ou por terceiros (p. ex. segurança de TI), exceto quando prevalecerem os interesses, direitos ou liberdades do titular dos dados. Isso exige um teste de ponderação e não pode ser invocado por autoridades públicas no exercício de suas funções.

## Direitos dos Titulares de Dados {/*#rights-of-data-subjects*/}

- **Direito de acesso (Art. 15 GDPR):** O direito de obter a confirmação de que dados pessoais estão sendo tratados e, em caso afirmativo, de receber uma cópia desses dados juntamente com informações sobre o tratamento.
- **Direito de retificação (Art. 16 GDPR):** O direito de obter a correção de dados pessoais inexatos ou incompletos sem demora injustificada.
- **Direito ao apagamento / "Direito de ser esquecido" (Art. 17 GDPR):** O direito de ter os dados pessoais excluídos, p. ex. se deixarem de ser necessários para a finalidade original, se o consentimento tiver sido retirado ou se o tratamento tiver sido ilícito.
- **Direito à limitação do tratamento (Art. 18 GDPR):** O direito de ter o tratamento de dados pessoais limitado em determinadas circunstâncias, p. ex. enquanto a exatidão dos dados é contestada.
- **Direito à portabilidade dos dados (Art. 20 GDPR):** O direito de receber os dados pessoais em um formato estruturado, de uso corrente e legível por máquina e de transmiti-los a outro controlador (aplica-se a tratamentos baseados em consentimento ou contrato).
- **Direito de oposição (Art. 21 GDPR):** O direito de se opor ao tratamento baseado em interesses legítimos ou em função pública, bem como ao tratamento para fins de marketing direto (que deve ser sempre atendido, sem teste de ponderação).
- **Direito de não ser submetido a decisões automatizadas (Art. 22 GDPR):** O direito de não ficar sujeito a decisões baseadas exclusivamente em tratamento automatizado, incluindo a definição de perfis, que produzam efeitos jurídicos ou igualmente significativos.
- **Direito de apresentar reclamação (Art. 77 GDPR):** O direito de apresentar reclamação a uma autoridade de controle se o titular dos dados considerar que o tratamento viola o GDPR.
