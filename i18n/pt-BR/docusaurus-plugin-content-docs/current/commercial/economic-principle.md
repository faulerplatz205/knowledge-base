# Princípio Econômico

Recursos como dinheiro, tempo, material e trabalho são escassos. O **princípio econômico** (também *princípio racional*) exige, portanto, que a relação entre **input** (os meios empregados) e **output** (o resultado alcançado) seja a mais favorável possível.

## Formas {/*#forms*/}

| Forma                | Fixo    | Regra                                                                              |
| -------------------- | ------- | ---------------------------------------------------------------------------------- |
| Princípio do máximo  | Input   | Alcançar o maior output possível com um input dado.                                |
| Princípio do mínimo  | Output  | Alcançar um output dado com o menor input possível.                                |
| Princípio do ótimo   | Nenhum  | Escolher input e output de modo que sua relação seja a mais favorável possível.    |

## Exemplos {/*#examples*/}

- **Princípio do máximo:** Um departamento de TI dispõe de um orçamento de 20.000 EUR para laptops e compra com ele o maior número possível de aparelhos da especificação exigida.
- **Princípio do mínimo:** Um departamento de TI precisa de 15 laptops de uma determinada especificação, identifica o fornecedor com o menor preço total por meio de uma [comparação de ofertas](./offer-comparison.md) e os compra nele.
- **Princípio do ótimo:** Uma empresa planeja uma loja virtual sem orçamento fixo nem conjunto fixo de funcionalidades e escolhe a combinação de orçamento e funcionalidades com a melhor relação entre custo e benefício.
