# Conventions de nommage des classes et des ID

## Classe {/*#class*/}

kebab-case

### Exemple {/*#example*/}

```text
class="nav-bar"
class="button-primary"
```

---

## ID {/*#id*/}

camelCase

### Exemple {/*#example-1*/}

```text
id="mainHeader"
id="userProfileForm"
```
