# Logiciel open source et logiciel propriétaire

## Définitions {/*#definitions*/}

**Logiciel open source :** Le code source est accessible au public. Chacun peut examiner, modifier et distribuer le logiciel, dans le respect des termes de sa licence (par ex. MIT, GPL, Apache).

**Logiciel propriétaire :** Le code source est tenu secret par l'éditeur. L'utilisation est régie par un contrat de licence, et la modification et la redistribution sont généralement interdites.

## Open source {/*#open-source*/}

### Avantages {/*#advantages*/}

- **Utilisation gratuite :** Dans la plupart des cas, utilisable sans frais de licence
- **Transparence :** le code peut être audité à la recherche de failles de sécurité et de bogues
- **Piloté par la communauté :** Peut être développé davantage par la communauté sans dépendre entièrement du développeur d'origine
- **Flexibilité :** Peut être adapté par chacun à ses besoins individuels

### Inconvénients {/*#disadvantages*/}

- **Support :** Le support communautaire peut être peu fiable, inexistant dans le cas de petites communautés, ou soumis à un paiement supplémentaire
- **Ergonomie :** interfaces souvent moins soignées que celles des alternatives commerciales
- **Risque de sécurité :** un code visible publiquement peut aussi être analysé par des attaquants
- **Complexité des licences :** différentes licences open source peuvent imposer des restrictions (par ex. copyleft)
- **Charge de maintenance :** l'auto-hébergement exige des compétences internes et du temps

### Exemples {/*#examples*/}

- Firefox
- Linux
- React
- VSCode

## Logiciel propriétaire {/*#proprietary-software*/}

### Avantages {/*#advantages-1*/}

- **Support professionnel :** support dédié de l'éditeur avec des SLA
- **Finition et UX :** investissement généralement plus important dans l'expérience utilisateur et la documentation
- **Mises à jour et maintenance fiables :** Des mises à jour et correctifs régulièrement testés sont fournis par l'éditeur, sans qu'une expertise interne soit nécessaire pour les installer.
- **Intégration :** Offre souvent une bonne compatibilité avec d'autres logiciels du même fabricant

### Inconvénients {/*#disadvantages-1*/}

- **Coût :** les frais de licence peuvent être importants, surtout à grande échelle
- **Dépendance vis-à-vis de l'éditeur (vendor lock-in) :** dépendance à la feuille de route et à la politique tarifaire de l'éditeur
- **Absence de transparence :** impossible d'auditer le code source en matière de sécurité ou de qualité
- **Restrictions :** possibilités limitées de personnalisation ou d'extension au-delà de ce que l'éditeur autorise

### Exemples {/*#examples-1*/}

- Microsoft Office
- Windows, iOS, MacOS
- Discord
- Google Chrome

## Comparaison {/*#comparison*/}

|                           | Open source              | Propriétaire             |
| ------------------------- | ------------------------ | ------------------------ |
| Code source               | Public                   | Privé                    |
| Coût                      | Généralement gratuit     | Frais de licence         |
| Support                   | Communauté / payant      | Fourni par l'éditeur     |
| Personnalisation          | Élevée                   | Faible                   |
| Dépendance vis-à-vis de l'éditeur | Faible           | Élevée                   |
| Transparence de la sécurité | Élevée                 | Faible                   |
