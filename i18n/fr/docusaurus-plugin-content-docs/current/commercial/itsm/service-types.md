# Types de services informatiques

## Aperçu {/*#overview*/}

Les services informatiques peuvent être classés selon leur mode de fourniture et selon la partie qui les gère. Cette entrée présente les principales définitions du terme « service » selon les référentiels, les types courants de services informatiques, le cycle de vie IMAC/R/D et la terminologie essentielle de l'ITSM.

## Définitions du service {/*#service-definitions*/}

| Source | Définition                                                                                                                                                                       |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BSI    | « Un service est la composition d'objets et de processus destinée à accomplir une tâche. »                                                                                       |
| FitSM  | « Un service est un moyen de fournir de la valeur aux clients en soutenant leurs objectifs. »                                                                                    |
| ITIL 4 | « Un service est un moyen de permettre la co-création de valeur en facilitant les résultats que les clients souhaitent atteindre, sans que le client ait à gérer des coûts et des risques spécifiques. » |

**La qualité convainc, le service décide.**

## Aperçu des types de services informatiques {/*#it-service-types-overview*/}

| Type de service                                     | Description                                                                                                                                                    |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vente informatique / commerce informatique          | Acquisition de systèmes et de composants informatiques, y compris l'installation et le raccordement au réseau                                                  |
| Service informatique                                | Tout service rendu possible par l'informatique et pour l'informatique                                                                                          |
| Support Break/Fix / Field Service / service sur site | Services informatiques réalisés à la demande chez le client, facturés selon la main-d'œuvre et les pièces. Optimisés par le Field Service Management (FSM)     |
| On-Site Management                                  | Fourniture de services informatiques dans les locaux du client                                                                                                 |
| Swap Service                                        | Un appareil de remplacement identique est mis à la disposition de l'utilisateur                                                                                |
| Service DIY                                         | Le client réalise lui-même le service (avec l'autorisation du fabricant, par ex. la garantie reste valable)                                                    |
| Service cloud                                       | Tous les services proposés par les fournisseurs de cloud                                                                                                       |
| Live Chat                                           | Via un widget ou une application, le client est mis en relation en direct avec un collaborateur du fournisseur du service web                                  |
| Chatbot                                             | Système basé sur l'IA intégré aux sites web, aux applications et aux réseaux sociaux pour communiquer automatiquement avec les utilisateurs ; les chatbots hybrides proposent aussi un chat en direct |
| Managed Services                                    | Services informatiques récurrents d'un Managed Services Provider (MSP) ; l'étendue et la qualité sont convenues au préalable dans un SLA, par ex. surveillance proactive et maintenance à distance |
| Service sous garantie                               | Service gratuit au titre de la garantie légale ou commerciale                                                                                                  |
| Goodwill                                            | Service gratuit offert volontairement par le prestataire                                                                                                       |
| Service de helpdesk                                 | Services fournis par un helpdesk en ligne                                                                                                                      |
| Service de maintenance                              | Service prévu dans le cadre de contrats de maintenance                                                                                                         |
| Service de réparation                               | Services de réparation                                                                                                                                         |
| Externalisation informatique / IT Sourcing          | Acquisition externe de services informatiques ; des prestataires informatiques spécialisés traitent efficacement les tâches difficiles à résoudre              |
| Initiation informatique                             | Initiation des clients et des collaborateurs aux systèmes informatiques                                                                                        |
| Formation informatique / instruction informatique   | Formation et enseignement des clients contre rémunération                                                                                                      |

## Cycle de vie IMAC/R/D {/*#imacrd-lifecycle*/}

Le cycle de vie **IMAC/R/D** décrit les phases d'un équipement informatique, du déploiement à la mise au rebut :

| Lettre | Phase                  | Description                                                                                                              |
| ------ | ---------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **I**  | Install                | Acquisition, préinstallation (staging) et déploiement opérationnel sur le site final                                     |
| **M**  | Move                   | Déplacement d'équipements, par ex. lors de déménagements de bureaux ou de réorganisations internes                       |
| **A**  | Add                    | Ajouts matériels ou logiciels, par ex. ajout de RAM ou installation de nouveaux programmes                               |
| **C**  | Change                 | Modifications de configuration ou adaptations des droits d'utilisateur et des politiques                                 |
| **R**  | Remove / Rollback      | Désinstallation d'équipements et retour à l'inventaire informatique                                                      |
| **D**  | Dispose                | Effacement sécurisé des données (data erasure), remise en vente ultérieure (remarketing) ou élimination respectueuse de l'environnement |

## Termes essentiels de l'ITSM {/*#key-itsm-terms*/}

| Terme                                                                      | Description                                                                                                                                         |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Service Desk**                                                           | Point de service pour les utilisateurs ; aussi appelé Helpdesk                                                                                      |
| **ITSM**                                                                   | IT Service Management : ensemble des activités menées par un prestataire de services informatiques pour planifier, fournir, exploiter et piloter les services informatiques |
| **Portefeuille de services**                                               | Ensemble de tous les services informatiques proposés ; comprend le catalogue de services, les directives et les responsabilités                     |
| **[SLA](./sla.md)**                                                        | Service Level Agreement : accord contractuel sur les niveaux de service entre le prestataire et le client                                           |
| **OLA**                                                                    | Operational Level Agreement : accord interne entre équipes ou services informatiques                                                                |
| **KPI**                                                                    | Key Performance Indicator : indicateurs alignés sur les objectifs métier critiques, par ex. la disponibilité du service ou le nombre d'interruptions de service |
| **SOA**                                                                    | Service-Oriented Architecture : les processus métier et les systèmes sont modularisés et reliés par des services informatiques réutilisables         |
| **[IaaS](../../cloud/service-models.md#infrastructure-as-a-service-iaas)** | Infrastructure as a Service : plateforme cloud fournissant l'infrastructure comme base d'une application                                            |
| **Disponibilité du service 24/7**                                          | Le service est disponible à tout moment                                                                                                             |
| **Disponibilité du service 12/5**                                          | Le service est disponible pendant les heures de bureau habituelles                                                                                  |
