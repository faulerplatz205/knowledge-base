# 图像存储大小

## 像素与色深 {/* #pixels-and-colour-depth */}

光栅图像由像素网格构成。**分辨率**即像素数量，可表示为宽 x 高（例如 `1920 x 1080`），或以**百万像素**（megapixel）为单位表示总数（1 MP = 1,000,000 像素）。

**色深**表示每个像素用多少位来存储其颜色。当位数为 `n` 时，一个像素可以取 `2ⁿ` 种不同的颜色。

| 色深 | 颜色数    | 名称                                                       |
| ------------ | ---------- | ---------------------------------------------------------- |
| 1 位        | 2          | 单色（黑白）                               |
| 8 位        | 256        | 灰度或索引色                                |
| 16 位       | 65,536     | 高彩色（High Color）                                                 |
| 24 位       | 16,777,216 | 真彩色（True Color），红、绿、蓝各 8 位            |
| 32 位       | 16,777,216 | 真彩色加 8 位 Alpha 通道（透明度）        |

---

## 公式 {/* #formula */}

```text
Storage size in bits  = number of pixels x colour depth
Storage size in bytes = number of pixels x colour depth ÷ 8
```

结果为未经压缩的原始图像数据的大小。JPEG 或 PNG 等格式会压缩这些数据，且每个文件还包含文件头和元数据。实际文件的大小与计算值不同。

---

## 示例 {/* #example */}

一张 5000 万像素、色深为 24 位的照片：

```text
Pixels:        50 MP x 10⁶ = 50,000,000 pixels
Bits:          50,000,000 x 24 bit = 1,200,000,000 bit
Bytes:         1,200,000,000 bit ÷ 8 = 150,000,000 B
Decimal:       150,000,000 B ÷ 10⁶ = 150 MB
Binary:        150,000,000 B ÷ 2²⁰ ≈ 143.05 MiB
```

当分辨率以宽 x 高给出时，先计算像素数：

```text
Pixels:        1920 x 1080 = 2,073,600 pixels
Bytes:         2,073,600 x 24 bit ÷ 8 = 6,220,800 B
Decimal:       6,220,800 B ÷ 10⁶ ≈ 6.22 MB
Binary:        6,220,800 B ÷ 2²⁰ ≈ 5.93 MiB
```

---

## 常见错误 {/* #common-mistakes */}

1. **漏除以 8：** 像素数与色深的乘积是比特数。未除以 8 时，结果会大八倍，例如得到 1,200 MB 而不是 150 MB。
2. **按 1,024² 计算百万像素：** 百万像素中的前缀 mega 始终为十进制。50 MP 为 50,000,000 像素，而不是 52,428,800。
3. **混用 MB 和 MiB：** 150,000,000 B 为 150 MB，但仅约 143.05 MiB。目标单位决定除数：MB 为 10⁶，MiB 为 2²⁰（参见[位、字节与单位换算](./bit-byte-conversions.md)）。
4. **将颜色数当作色深：** 真彩色有 16,777,216 种颜色，但每个像素存储 24 位。公式使用的是位数，而不是颜色数。
