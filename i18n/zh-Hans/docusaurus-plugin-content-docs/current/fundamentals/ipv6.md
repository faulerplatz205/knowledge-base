# IPv6（互联网协议第 6 版）

## 概述 {/*#overview*/}

IPv6 是 IPv4 的后继协议，为解决 32 位 IPv4 地址空间耗尽的问题而引入。IPv6 地址长 **128 位**，可提供 2¹²⁸（约 3.4 x 10³⁸）个地址。

地址写作 **8 组、每组 16 位**（常称为 *hextet* 或*组*），每组用 4 个十六进制数字表示，并以冒号分隔（`:`）。

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
```

- 8 组 x 16 位 = 128 位
- 十六进制数字不区分大小写（`ff00` 等同于 `FF00`），但推荐的规范形式为小写

## 地址结构 {/*#address-structure*/}

典型的 IPv6 单播地址分为两个各 64 位的部分：

| 部分               | 长度  | 用途                                                  |
| ------------------ | ------- | -------------------------------------------------------- |
| **网络前缀** | 64 位 | 标识网络（路由前缀 + 子网 ID）。     |
| **接口 ID**   | 64 位 | 标识该网络内的单个接口。 |

前缀长度以 CIDR 表示法书写，例如 `2001:db8:abcd:1234::/64`。`/64` 是单个子网的标准大小。

## 缩短（压缩） {/*#shortening-compression*/}

有两条规则可使 IPv6 地址写得更紧凑，两者可以组合使用。

### 规则 1：去除前导零 {/*#rule-1-remove-leading-zeros*/}

每组中的前导零可以省略。每组至少保留一位数字。

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
2001:db8:0:0:0:ff00:42:8329
```

### 规则 2：折叠一段连续的零组（`::`） {/*#rule-2-collapse-one-run-of-zero-groups-*/}

一段连续的、由一个或多个全零组构成的序列可以用双冒号 `::` 替换。

```text
2001:db8:0:0:0:ff00:42:8329
2001:db8::ff00:42:8329
```

**重要：** `::` 在一个地址中**只能出现一次**，否则长度将产生歧义。若存在两段同样长的零序列，应压缩最左侧的那一段。

```text
fe80:0:0:0:1:0:0:1   =>   fe80::1:0:0:1   (correct)
fe80:0:0:0:1:0:0:1   =>   fe80::1::1      (invalid, two "::")
```

## 展开 {/*#expanding*/}

展开是压缩的逆过程，用于还原完整的 128 位形式。这在比较地址或手动计算子网时很有用。

1. **还原 `::`** – 统计现有的组数，然后插入足够多的 `0` 组，使总数达到 8 组。
2. **补全每一组** – 添加前导零，直到每组都有 4 个十六进制数字。

```text
2001:db8::ff00:42:8329

Step 1 (restore zero groups, 5 groups present => insert 3):
2001:db8:0:0:0:ff00:42:8329

Step 2 (pad to 4 digits each):
2001:0db8:0000:0000:0000:ff00:0042:8329
```

## 地址类型 {/*#address-types*/}

IPv6 没有广播，其作用由多播取代。

| 类型          | 含义                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------- |
| **单播（Unicast）**   | 一对一。标识单个接口；数据包只会被送达该接口。 |
| **多播（Multicast）** | 一对多。送达所有加入该多播组的接口。                   |
| **任播（Anycast）**   | 一对最近。由多个接口共享；送达拓扑上最近的那一个。  |

## 作用域 {/*#scopes*/}

*作用域*定义地址在网络中有效且可路由的范围。最相关的两种单播作用域为：

- **链路本地（Link-Local）** – 仅在直接相连的链路（一个网段）上有效。不会被路由。每个 IPv6 接口都会自动配置。
- **全局（Global）** – 全球唯一，可在互联网上路由，类似于公共 IPv4 地址。

多播地址带有明确的作用域字段（例如接口本地、链路本地、站点本地、全局）。

### 链路本地地址的区域索引 {/*#zone-index-for-link-local*/}

由于链路本地地址（`fe80::/10`）在多个接口之间并不唯一，必须使用附加 `%` 的区域索引来指定出站接口。

```text
ping fe80::1%eth0      # Linux (interface name)
ping fe80::1%12        # Windows (interface index)
```

## 重要地址 {/*#important-addresses*/}

| 地址 / 前缀 | 名称               | 说明                                                                           |
| ---------------- | ------------------ | ------------------------------------------------------------------------------------- |
| `::/128`         | 未指定地址        | 全零。在分配地址之前用作源地址（类似于 `0.0.0.0`）。    |
| `::1/128`        | 环回地址           | 本地主机，等同于 IPv4 的 `127.0.0.1`。                                       |
| `fe80::/10`      | 链路本地地址         | 自动配置，仅在本地链路上有效，不会被路由。                          |
| `fc00::/7`       | 唯一本地地址（ULA） | 供内部使用的私有地址，不在互联网上路由（类似于 RFC 1918）。 |
| `2000::/3`       | 全局单播地址     | 公共的、可在全球范围内路由的地址。                                                  |
| `ff00::/8`       | 多播地址          | 所有多播地址均以 `ff` 开头。                                              |
| `ff02::1`        | 所有节点（链路）   | 发往链路上所有节点的多播。                                                  |
| `ff02::2`        | 所有路由器（链路） | 发往链路上所有路由器的多播。                                                |
| `2001:db8::/32`  | 文档地址      | 保留用于示例和文档，绝不用于生产环境。                    |

## IPv6 与 IPv4 对比 {/*#ipv6-vs-ipv4*/}

| 属性       | IPv4                   | IPv6                         |
| -------------- | ---------------------- | ---------------------------- |
| 地址长度 | 32 位                | 128 位                     |
| 表示法       | 十进制，以点分隔 | 十六进制，以冒号分隔 |
| 广播      | 是                    | 否（由多播取代）   |
| 环回地址       | `127.0.0.1`            | `::1`                        |
| 自动配置    | DHCP / APIPA           | SLAAC + 链路本地地址           |
