# DHCP（动态主机配置协议）

DHCP 在本地网络内自动为客户端分配 IP 地址、子网掩码和其他配置参数。这样就无需手动配置每台主机。DHCP 使用 UDP 端口 `67`（服务器）和 `68`（客户端）。

## DORA 过程 {/*#the-dora-process*/}

客户端分四步获取其配置，简记为 **DORA**：

1. **Discover（发现）**：客户端向本地网络广播 `DHCP Discover`，以查找服务器。
2. **Offer（提供）**：DHCP 服务器用包含可用地址和配置参数的 `DHCP Offer` 作出应答。
3. **Request（请求）**：客户端用 `DHCP Request` 请求所提供的地址。
4. **Acknowledge（确认）**：如果该地址仍然可用，服务器用 `DHCP Ack` 予以确认。

## 关键概念 {/*#key-concepts*/}

- **租约：**地址在有限时间内分发（即租约）。这可防止地址永远绑定于某个客户端，并使其可以被重复使用。
- **作用域：**服务器可以分发的 IP 地址范围（包括子网掩码）。
- **选项：**随地址一起分发的附加参数，例如默认网关、DNS 服务器、子网掩码。
- **保留：**与特定 MAC 地址永久绑定的固定 IP 地址，使客户端始终获得同一地址。

## 中继代理 {/*#relay-agent*/}

由于路由器不转发广播，DHCP 服务器通常只为其自身子网提供服务。**DHCP 中继代理**将另一子网的 DHCP 请求（以单播方式）转发给 DHCP 服务器，使一台服务器可以为多个子网提供服务。

## 故障转移 {/*#failover*/}

为实现高可用性，两台 DHCP 服务器可以共享相同的作用域并复制其租约信息。有两种模式：

- **负载均衡：**两台服务器同时分发地址（默认比例 50/50，可调整）。
- **热备用：**主服务器分发所有地址；只有当主服务器失效时，辅助服务器才会接管。

故障转移最多支持两台服务器，且仅适用于 IPv4 作用域。

## DHCPv6 与 SLAAC {/*#dhcpv6-vs-slaac*/}

对于 IPv6，地址配置并不严格要求 DHCP：

- **SLAAC**（无状态地址自动配置）：主机根据路由器通告的全局前缀（路由器通告）自行构建地址。不涉及中央服务器。
- **DHCPv6**（有状态）：DHCPv6 服务器集中分配并跟踪完整配置，与 IPv4 类似。路由器仍会发送带有 `managed` 标志的路由器通告，使主机知道应使用 DHCPv6。

## 常用命令（客户端） {/*#useful-commands-client*/}

| 命令             | 用途                                                         |
| ------------------- | --------------------------------------------------------------- |
| `ipconfig /all`     | 显示完整的 IP 配置（适配器、MAC、IP、DNS、网关） |
| `ipconfig /release` | 释放当前地址（租约）                             |
| `ipconfig /renew`   | 向 DHCP 服务器请求新的租约                        |
