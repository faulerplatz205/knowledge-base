# Raspberry Pi 概述

## 什么是 Raspberry Pi {/*#what-is-a-raspberry-pi*/}

Raspberry Pi 是一种小型单板计算机。除了常见的接口（USB、HDMI、网络）之外，它还带有一排 **GPIO 引脚**，可直接连接电子元件，因此是硬件项目的热门平台。

## GPIO 引脚 {/*#gpio-pins*/}

**GPIO** 是 *General-Purpose Input/Output*（通用输入/输出）的缩写。排针结合了多种引脚：

- **电源引脚：** 固定的 **3.3 V** 和 **5 V** 输出，用于为元件供电。
- **接地引脚（GND）：** 电流的公共参考/回流路径。
- **I/O 引脚：** 可自由编程的引脚，可被读取（**输入**）或设置（**输出**）。

GPIO 的 I/O 引脚是纯**数字**的：它只识别 **HIGH**（3.3 V）和 **LOW**（0 V）。它无法直接测量模拟电压，因此模拟传感器需要在中间加入[模数转换器（ADC）](./analog-digital-converter.mdx)。反过来，类似模拟的输出可通过[脉宽调制（PWM）](./pulse-width-modulation.md)来近似实现。

## 传感器与执行器 {/*#sensors-vs-actuators*/}

元件分为两种相反的角色：

- **传感器**是将环境中的物理量（温度、湿度、压力、加速度等）转换为**电信号**的元件。
- **执行器**是传感器的对应物，作用恰好相反：它将**电信号**转换为运动、压力、声音或光等物理量。

| 角色     | 方向                        | 示例                             |
| -------- | -------------------------------- | ------------------------------------ |
| 传感器   | 环境 => 电信号 | 温度传感器、光传感器     |
| 执行器 | 电信号 => 环境 | 电机、灯/LED、扬声器、蜂鸣器 |

## 面包板 {/*#the-breadboard*/}

**面包板**无需焊接即可连接元件，导线和元件引脚只需插入其孔中。属于同一内部导电条的孔在电气上相连：

- 沿边缘的两条长**电源轨**（标记为 `+` 和 `-`）贯穿整块板。它们通常由一个 3.3 V / 5 V 引脚和一个 GND 引脚各供电一次，使电源和地在各处都可用。
- 内部的**接线条**将每个短列的孔连接在一起，并由板中间的缝隙隔开。

插入同一连通条的元件共享电气连接，电路即由此搭建。

## 连接元件 {/*#connecting-components*/}

大多数元件都有几个定义明确的连接。最常见的三个是**电源（VCC / `+`）**、**地（GND / `-`）**和**信号**线。

| 元件          | 角色     | 连接                  | 补充说明                             |
| ------------------ | -------- | ---------------------------- | ----------------------------------------------- |
| LED / 灯         | 执行器 | 阳极（`+`）、阴极（`-`）   | 较长的引脚是 `+`，较短的引脚是 `-`           |
| 温度传感器 | 传感器   | VCC（`+`）、GND（`-`）、信号 | 信号将测量值传送到 GPIO 引脚 |
| 蜂鸣器             | 执行器 | `+`（信号）、`-`（GND）      | 信号用于开关或驱动发声         |

### 常见引脚标签 {/*#common-pin-labels*/}

传感器模块和扩展板很少把各个连接完整写出，而是在每个引脚旁印上简短的标准化缩写：

- **VDD / VDC / VCC（`+`）：** 正电源电压（电源输入）。`VDD` 和 `VCC` 源于芯片设计，`VDC` 仅表示“直流伏特”；实际上这三者都标示电源引脚（例如 3.3 V 或 5 V）。
- **GND / VSS（`-`）：** 地，电流的公共参考和回流路径。
- **SDA：** **I2C** 总线的**数据**线，传感器通过它与 Pi 交换数值。
- **SCL：** **I2C** 总线的**时钟**线，使双方保持同步。

**I2C** 是一种两线总线（SDA + SCL），允许多个数字传感器共用同样的两个 GPIO 引脚，每个传感器单独寻址。I2C 传感器不需要 [ADC](./analog-digital-converter.mdx)，向数字值的转换已在模块内部完成。

### LED / 灯 {/*#led--lamp*/}

LED 有两个具有固定极性的引脚：

- **阳极（`+`）：** **较长**的引脚，连接到 GPIO / 正极一侧。
- **阴极（`-`）：** **较短**的引脚（也以边缘的平口标示），连接到 GND。

LED 必须始终通过**串联电阻**驱动以限制电流，否则 LED 会通过过大的电流而烧毁。

### 温度传感器 {/*#temperature-sensor*/}

典型的传感器模块有三个引脚：

- **VCC（`+`）：** 电源，例如 3.3 V。
- **GND（`-`）：** 地。
- **信号：** 传送测量值的输出。

若信号为**模拟**信号（与温度成正比的电压），则无法直接接入 GPIO 引脚，需要先经过 [ADC](./analog-digital-converter.mdx)。

### 蜂鸣器 {/*#buzzer*/}

蜂鸣器只有两个连接，即 `+`（信号）和 `-`（GND），分为两种类型：

- **有源蜂鸣器：** 内含振荡器，只需 HIGH / LOW 信号即可开关声音。它只能发出单一的固定音调。
- **无源蜂鸣器：** 没有振荡器，可以发出不同的音调，但需要变化的信号。音调高低由 [PWM](./pulse-width-modulation.md) 信号的频率决定。
