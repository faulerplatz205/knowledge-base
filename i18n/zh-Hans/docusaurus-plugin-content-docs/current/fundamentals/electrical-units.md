# 电气单位：功率、电压、电流与能量

## 三个核心单位 {/*#the-three-core-units*/}

| 符号 | 物理量 | 单位       |
| ------ | -------- | ---------- |
| P      | 功率    | 瓦特（W）   |
| U      | 电压  | 伏特（V）   |
| I      | 电流  | 安培（A） |

## 功率三角形 {/*#the-power-triangle*/}

三个量之间的关系由公式 **P = U x I** 给出。遮住待求的量，即可得到相应的公式：

```text
      P
    -----
    U | I
```

- **P = U x I**（功率 = 电压 x 电流）
- **U = P / I**（电压 = 功率 / 电流）
- **I = P / U**（电流 = 功率 / 电压）

## 欧姆定律 {/*#ohms-law*/}

欧姆定律引入电阻 **R**（单位为欧姆，Ω），并将其与电压和电流联系起来。

此处同样适用三角形方法：

```text
      U
    -----
    R | I
```

- **U = R x I**（电压 = 电阻 x 电流）
- **R = U / I**（电阻 = 电压 / 电流）
- **I = U / R**（电流 = 电压 / 电阻）

## 组合公式 {/*#combined-formulas*/}

将功率公式与欧姆定律结合，可得到另外几种计算功率的方式：

- **P = U² / R**
- **P = I² x R**

## 示例 {/*#examples*/}

**示例 1：** 某设备在 230 V 下运行，电流为 2 A。其功耗（P）是多少？

```text
P = U x I = 230 V x 2 A = 460 W
```

**示例 2：** 一只 100 W 的灯泡在 230 V 下工作。其电流（I）是多少？

```text
I = P / U = 100 W / 230 V ≈ 0.43 A
```

**示例 3：** 一个 50 Ω 的电阻通过 3 A 的电流。其两端的电压降是多少？

```text
U = R x I = 50 Ω x 3 A = 150 V
```

## 电功（能量） {/*#electrical-work-energy*/}

电功 **W**（常称为能量，有时写作 **E**）是设备在一段时间内消耗或产生的能量。其 SI 单位为**焦耳（J）**，但在日常用电中更常以**瓦时**（Wh）或**千瓦时**（kWh）表示。

基本公式为：

- **W = P x t**（电功 = 功率 x 时间）

将 **P** 替换为 **U x I** 后，可直接由 **U**、**I** 和 **t** 计算 **W**，无需先计算 **P**：

- **W = U x I x t**

### 常用能量单位 {/*#common-units-of-energy*/}

| 单位          | 符号 | 等于                 |
| ------------- | ------ | ---------------------- |
| 焦耳         | J      | 1 W x 1 s              |
| 瓦时     | Wh     | 3,600 J                |
| 千瓦时 | kWh    | 1,000 Wh = 3,600,000 J |

:::info
符号 **W** 既用于单位“瓦特”（功率单位），也用于物理量“电功”。通常可由上下文判断其含义。部分资料以 **E** 表示“电功”，以避免混淆。
:::

### 示例 {/*#examples-1*/}

**示例 1：** 一只 60 W 的灯泡运行 5 小时。其消耗的能量是多少？

```text
W = P x t = 60 W x 5 h = 300 Wh = 0.3 kWh
```

**示例 2：** 某设备在 230 V 下通过 2 A 电流，持续 30 分钟。其消耗的能量是多少？

```text
W = U x I x t = 230 V x 2 A x 0.5 h = 230 Wh
```

**示例 3：** 电费账单显示用电 250 kWh，单价为每千瓦时 0.30 欧元。总费用是多少？

```text
Cost = 250 kWh x €0.30/kWh = €75.00
```
