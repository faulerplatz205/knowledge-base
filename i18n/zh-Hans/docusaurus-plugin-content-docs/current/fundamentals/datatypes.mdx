# 数据类型

## 概述 {/* #overview */}

数据类型为每个变量、参数和返回值定义三件事：

- **取值范围：**哪些值有效，例如布尔值的 `true` 和 `false`
- **内存占用：**为一个值保留多少字节
- **操作：**可以对该值做什么，例如 `+` 对数字表示加法，而对字符串表示连接

| 类别      | 包含                             | 示例                             |
| ------------- | --------------------------------- | ------------------------------------ |
| **基本** | 恰好一个不可分割的值     | `int`、`double`、`boolean`、`char`   |
| **复合** | 一个名称下的多个值     | 数组、元组、记录、对象、字符串 |
| **抽象**  | 一份契约，而非具体布局 | 接口、泛型类型参数    |

:::info
下文的类型名称和大小遵循常见的 C/Java/C# 家族。其他语言有所不同：Python 的整数具有任意精度，JavaScript 只有一种以 64 位浮点数为基础的 `number` 类型，Go 则按宽度命名其类型（`int32`、`uint64`）。
:::

## 基本数据类型 {/* #primitive-data-types */}

### 整数类型 {/* #integer-types */}

整数存储不带小数部分的整数值。取值范围直接由位数 `n` 决定：

```text
signed:    -2^(n-1)  to  2^(n-1) - 1
unsigned:         0  to  2^n - 1
```

| 位数 | 常见名称 | 有符号范围                                            | 无符号范围                  |
| ---- | ------------ | ------------------------------------------------------- | ------------------------------- |
| 8    | `byte`       | -128 至 127                                             | 0 至 255                        |
| 16   | `short`      | -32,768 至 32,767                                       | 0 至 65,535                     |
| 32   | `int`        | -2,147,483,648 至 2,147,483,647                         | 0 至 4,294,967,295              |
| 64   | `long`       | -9,223,372,036,854,775,808 至 9,223,372,036,854,775,807 | 0 至 18,446,744,073,709,551,615 |

**补充说明：**

- 有符号整数的一位用于编码符号，因此有符号范围大约只有无符号范围的一半。
- 负数一侧比正数一侧多延伸一步，因为零占用了非负值中的一个位置。

### 浮点类型 {/* #floating-point-types */}

浮点类型按照 IEEE 754 以符号、尾数和指数的形式存储带小数部分的数字。

| 位数 | 常见名称      | 有效十进制位数 | 大致量级 |
| ---- | ----------------- | -------------------------- | --------------------- |
| 32   | `float`、`single` | 约 7 位                    | 最大约 3.4 x 10^38     |
| 64   | `double`          | 约 15 至 16 位             | 最大约 1.8 x 10^308    |

由于尾数是二进制的，`0.1` 之类的十进制小数无法被精确表示：

```text
0.1 + 0.2 = 0.30000000000000004
```

**由此得出的重要注意事项：**

- 浮点值从不使用 `==` 比较，而是与一个很小的容差比较
- 货币金额不存储为 `float` 或 `double`，而是存储在[定点类型](#fixed-point-types)中，或存储为以分为单位的整数

### 定点类型 {/* #fixed-point-types */}

定点类型存储固定数量的小数位。其内部值是按 10 的幂缩放的整数，因此 `12.34` 以标度 2 保存为 `1234`。于是十进制小数得以被精确表示，这是浮点类型做不到的。

**示例：**

`DECIMAL(10, 2)` 表示共 10 位数字，其中 2 位在小数点之后，小数点之前还剩 8 位。

这种精确性的代价是运算速度比 `double` 慢得多，且占用更多内存。因此定点类型用于必须精确的场合，首先是货币金额、税率和发票总额，而不用于测量值或图形。

### 布尔 {/* #boolean */}

布尔值恰好持有 `true` 和 `false` 两个真值之一，是每个比较和逻辑运算（`&&`、`||`、`!`）的结果类型。虽然一位就已足够，但通常至少保留一个字节，因为内存是按字节寻址的。

### 字符 {/* #character */}

字符类型持有单个字符，以字符编码的数值码点形式存储。

| 编码 | 每个字符的大小   | 范围                                    |
| -------- | -------------------- | ---------------------------------------- |
| ASCII    | 1 字节（使用 7 位） | 128 个字符，不含变音字母               |
| UTF-8    | 1 至 4 字节         | 完整 Unicode，兼容 ASCII           |
| UTF-16   | 2 或 4 字节         | 完整 Unicode，Java 和 C# 使用 `char` |

**趣闻：**由于字符以数字形式存储，可以对其进行算术运算和比较：`'A' + 1` 得到 `'B'`，而 `'a' < 'b'` 为 `true`。

## 复合数据类型 {/* #composite-data-types */}

### 字符串 {/* #string */}

字符串是字符序列。两个设计决策区分了不同的实现：

- **长度：**固定（在应用代码中少见）或可变
- **可变性：**在 Java、C# 和 Python 中不可变，在 C++ 和 Rust 中可变

字符串不可变时，每次修改都会创建新对象。因此在循环中通过反复连接来构建字符串，会在每一趟复制整个文本，应改用构建器类型（`StringBuilder`、`StringBuffer`）。

### 数组 {/* #array */}

数组在一个名称下存储固定数量的**相同类型**元素，通过从零开始的索引访问。

```text
scores = [17, 42, 8, 23]

scores[0] = 17
scores[3] = 23
```

特点：

- 大小在创建时固定，因此扩容需要新建数组并复制
- 按索引访问耗时恒定，因为地址按 `start + index x elementSize` 计算
- 多维数组（`matrix[row][column]`）可用于建模表格和网格

### 元组 {/* #tuple */}

元组按固定顺序将固定数量的**可能类型各异**的值组合在一起。元素通过位置而非名称来寻址。

```text
point    = (3, 7)
httpCall = ("GET", "/users", 200)
```

元组适合从函数返回多个值，而无需声明专门的类型。一旦位置需要解释，记录是更好的选择。

### 记录、结构体和对象 {/* #record-struct-and-object */}

记录（也称结构体，或类的对象）将不同类型的值归入**具名**字段。

```text
Customer {
    id:      int
    name:    string
    active:  boolean
    revenue: decimal
}
```

与元组不同，每个字段都带有名称，这使每个值的含义一目了然，并且可以扩展类型而不破坏现有位置。

### 枚举 {/* #enumeration */}

枚举定义一组固定的、具名的允许值。

```text
enum OrderState { NEW, PAID, SHIPPED, CANCELLED }
```

与魔数或松散的字符串常量相比的优势在于：编译器会拒绝集合之外的任何值，且所有有效状态都记录在同一处。

### 集合 {/* #collections */}

## 类型转换 {/* #type-conversion */}

将值从一种类型转换为另一种类型，要么是**隐式**的（由编译器自动执行），要么是**显式**的（在源代码中通过强制转换或转换函数请求）。

| 方向     | 含义                            | 示例         | 风险                 |
| ------------- | ---------------------------------- | --------------- | -------------------- |
| **拓宽**  | 目标范围包含源范围 | `int` => `long` | 无，无损       |
| **收窄** | 目标范围更小            | `long` => `int` | 溢出、截断 |

```text
implicit widening:   long total = 42;          // int fits into long
explicit narrowing:  int  count = (int) 42L;   // cast required
truncation:          int  n     = (int) 3.99;  // yields 3, not 4
```

字符串与数字之间的转换不是强制转换，而是**解析**或**格式化**，因为内存表示完全改变。解析取决于输入，因此可能失败，这就是它会返回错误或抛出异常的原因。

## 常见陷阱 {/* #common-pitfalls */}

- **整数溢出：**在大多数语言中，给最大值加 1 会回绕到最小值，而不是引发错误
- **整数除法：**只要两个操作数都是整数，`7 / 2` 得到 `3`，而不是 `3.5`
- **浮点数比较：**`0.1 + 0.2 == 0.3` 的求值结果为 `false`
- **用浮点数表示金额：**舍入误差会在大量运算中累积
- **收窄时的截断：**将浮点值强制转换为整数会截去小数部分，而不是四舍五入
- **默认使用过大的类型：**在 `byte` 足够的地方使用 `long` 会在大型数组和记录中浪费内存

## 选择数据类型 {/* #choosing-a-data-type */}

1. **取值范围：**可能合理出现的最大值和最小值，包括预期的增长
2. **精度：**是否需要小数部分，以及它必须精确（货币）还是可以近似（测量值）
3. **内存和性能：**对大型数组、嵌入式系统和网络传输很重要，对单个变量可以忽略
4. **语义：**是否可以通过类型本身排除无效值，例如用枚举代替字符串，或用布尔值代替 `0` 和 `1`，从而使错误的值在编译时就失败
