# IT 安全目标

## 概述 {/*#overview*/}

IT 安全建立在四个核心目标之上，它们定义了安全的系统必须保证什么。

## 机密性 {/*#confidentiality*/}

信息仅对获得授权的各方可访问。

- 数据必须受到保护，避免未经授权的访问或泄露
- 通过加密、访问控制和最小知悉原则实现
- **示例**：只有预定的收件人才能读取加密邮件

## 完整性 {/*#integrity*/}

信息准确且未被篡改。

- 未经授权，数据不得被修改、损坏或删除，无论是有意还是无意
- 通过哈希函数、数字签名和校验和实现
- **示例**：哈希值与公布值一致的已下载文件未被更改

## 可用性 {/*#availability*/}

系统和数据在获授权用户需要时可被访问。

- 服务必须保持运行并及时响应；停机或拒绝访问属于安全故障
- 通过冗余、备份、DDoS 防护和容错基础设施实现
- **示例**：受 DDoS 攻击防护的 Web 服务在攻击期间仍可访问

## 真实性 {/*#authenticity*/}

通信伙伴的身份或数据的来源可以被验证。

- 确保各方确为其所声称的身份，且数据来自可信来源
- 通过数字证书、签名和身份验证协议（例如 TLS、MFA）实现
- **示例**：TLS 证书证明某网站由所述组织运营

## 总结 {/*#summary*/}

| 目标            | 问题                                 | 解决方案                  |
| --------------- | ---------------------------------------- | -------------------------- |
| 机密性 | 谁可以访问？                     | 加密、访问控制 |
| 完整性       | 是否被篡改？             | 哈希、数字签名 |
| 可用性    | 需要时是否可访问？          | 冗余、备份        |
| 真实性    | 对方是否确为其所声称的身份/内容？ | 证书、MFA          |
