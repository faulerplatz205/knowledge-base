# OSI 模型

## 概述 {/*#overview*/}

OSI（Open Systems Interconnection，开放系统互连）模型是一个概念框架，用于规范不同网络系统之间的通信方式。它将通信划分为 **7 层**，每层都有特定的作用。该模型不依赖于任何厂商，可作为理解协议如何交互的参考。

## 七个层次 {/*#the-7-layers*/}

| #   | 名称         | 主要职责                      |
| --- | ------------ | --------------------------------------- |
| 7   | 应用层  | 面向用户的协议和服务      |
| 6   | 表示层 | 数据格式化、编码、加密   |
| 5   | 会话层      | 应用程序之间的会话管理 |
| 4   | 传输层    | 进程之间的端到端传输   |
| 3   | 网络层      | 逻辑寻址和路由          |
| 2   | 数据链路层    | 本地网络内的帧传输   |
| 1   | 物理层     | 通过介质传输原始比特      |

## 各层详解 {/*#layer-details*/}

### 第 1 层：物理层 {/*#layer-1--physical*/}

通过物理介质（线缆、无线电、光纤）传输原始比特。定义电压电平、引脚布局和比特时序。没有寻址的概念。

**示例：** 以太网线缆、Wi-Fi 无线电信号、光纤、集线器、中继器

### 第 2 层：数据链路层 {/*#layer-2--data-link*/}

将比特打包为**帧**，并使用 **MAC 地址**处理单个网段内的传输。还通过 CRC 检测传输错误。

**子层：** LLC（Logical Link Control，逻辑链路控制）和 MAC（Media Access Control，介质访问控制）

**示例：** 以太网、Wi-Fi（802.11）、ARP、交换机

### 第 3 层：网络层 {/*#layer-3--network*/}

处理**逻辑寻址**（IP）以及数据包跨多个网络的路由。确定从源到目的地的最佳路径。

**示例：** IP（IPv4、IPv6）、ICMP、路由器

### 第 4 层：传输层 {/*#layer-4--transport*/}

提供进程之间的**端到端通信**。负责分段、重组、流量控制和错误恢复。

- **TCP**：面向连接、可靠、有序传输
- **UDP**：无连接、更快、不保证送达

**示例：** TCP、UDP、端口号

### 第 5 层：会话层 {/*#layer-5--session*/}

建立、管理和终止应用程序之间的**会话**（逻辑连接）。支持同步和检查点，以便进行长时间的数据传输。

**示例：** NetBIOS、RPC、会话令牌

### 第 6 层：表示层 {/*#layer-6--presentation*/}

在应用程序格式与网络格式之间转换数据。负责编码、序列化、压缩和加密。

**示例：** TLS/SSL（加密）、JSON、XML、JPEG、MPEG

### 第 7 层：应用层 {/*#layer-7--application*/}

最接近用户的一层。直接为应用程序提供网络服务。它指的不是应用程序本身，而是它们所使用的协议。

**示例：** HTTP、HTTPS、FTP、SMTP、DNS、SSH
