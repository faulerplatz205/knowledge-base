# DNS（域名系统）

DNS 将 DNS 名称解析为 IP 地址，反之亦然。DNS 名称由两部分组成：标识单台主机的**主机名**，以及标识共享命名空间中一组主机的**域名**。两者以点分隔。

## 层级结构与 FQDN {/*#hierarchy-and-fqdn*/}

DNS 是一个层级系统，从根向下构建：

- **根：**层级的顶端（写作 `.`）
- **顶级域（TLD）：**例如 `com`、`net`、`de`、`org`
- **二级域：**例如 `heise.de` 中的 `heise`
- **子域/主机：**二级域之下的更多层级，例如 `www`

当指定了直至根的所有部分时，结果即为 **FQDN**（Fully Qualified Domain Name，完全限定域名），它在网络中必须唯一，例如 `www.heise.de`。

## 区域 {/*#zones*/}

每台 DNS 服务器负责命名空间中一个划定的部分，称为**区域**（例如 `heise.de`）。管理区域文件的服务器对该区域拥有**权威**。

- **主要区域：**读写访问；区域的权威副本。
- **辅助区域：**主要区域的只读副本（用于冗余或负载分担）。它可以应答查询，但无法更新区域文件。

区域数据通过**区域传送**（没有域控制器的两台 DNS 服务器之间）或**区域复制**（域控制器上与 Active Directory 集成的区域）在服务器之间交换。

按方向划分：

- **正向查找区域：**将域名解析为 IP 地址。
- **反向查找区域：**将 IP 地址解析为域名。

## 记录类型 {/*#record-types*/}

| 记录    | 用途                                   |
| --------- | ----------------------------------------- |
| **A**     | 域名到 IPv4 地址               |
| **AAAA**  | 域名到 IPv6 地址               |
| **CNAME** | 指向另一主机记录的别名     |
| **SRV**   | 将服务解析为 IP 地址       |
| **PTR**   | 反向查找：IP 地址到域名 |

## 递归查询与迭代查询 {/*#recursive-vs-iterative-queries*/}

- **递归查询：**客户端将其发送给自己的名称服务器，并期望得到最终答案（IP 地址）。如果服务器持有该区域，则返回**权威应答**。
- **迭代查询：**如果服务器自己无法应答，则沿层级向其他 DNS 服务器查询。每台服务器可能只会指向下一个负责的服务器，而不是给出最终答案，直至到达权威服务器。
- **缓存：**每台参与的服务器都会将结果存入其 **DNS 缓存**。缓存的应答以**非权威应答**返回。

## 解析示例（`www.example.com`） {/*#example-resolution-wwwexamplecom*/}

1. 客户端向其配置的 DNS 服务器发送**递归**查询。
2. 该服务器不具权威且没有缓存条目，因此向**根**名称服务器发送**迭代**查询。
3. 根服务器回复 `com.` TLD 名称服务器的地址。
4. DNS 服务器查询 `com.` 名称服务器。
5. `com.` 服务器回复 `example.com.` 名称服务器的地址。
6. DNS 服务器查询 `example.com.` 名称服务器。
7. 该服务器对该区域具有权威，回复该 FQDN 的 IP 地址。
8. DNS 服务器将 IP 地址返回给客户端（并将其缓存）。

## HOSTS 文件 {/*#hosts-file*/}

对于非常小的网络，可以使用静态 `HOSTS` 文件（`C:\Windows\System32\Drivers\etc\HOSTS`）代替 DNS 来将主机名映射到 IP 地址。由于 Active Directory 需要 DNS，这种替代方式如今很少使用。

## 常用命令（客户端） {/*#useful-commands-client*/}

| 命令                | 用途                   |
| ---------------------- | ------------------------- |
| `ipconfig /displaydns` | 显示本地 DNS 缓存  |
| `ipconfig /flushdns`   | 清除本地 DNS 缓存 |

## Windows 域的命名规则 {/*#naming-rules-for-windows-domains*/}

- 对于内部网络，使用正式互联网域的子域（例如 `media.ct.de` 而不是 `media.ct.local`）。
- 名称保持简短（域最多 64 个字符）。
