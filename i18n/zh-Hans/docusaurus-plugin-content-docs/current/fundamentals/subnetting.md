# 子网划分（IPv4）

## 子网划分基础 {/*#subnetting-basics*/}

子网划分将一个大型网络拆分为更小、更易管理的子网络（子网）。这可以提升性能、条理性和安全性。

| 术语             | 符号/简称 | 定义                                                   | 示例                |
| ---------------- | ---------- | ------------------------------------------------------------ | ---------------------- |
| **IP 地址**   | IP         | 设备在网络上的唯一地址。                   | `192.168.1.10`         |
| **子网掩码**  | Netmask    | 区分网络部分与主机部分。               | `255.255.255.0`        |
| **CIDR**         | 斜线表示法 | 掩码的简短格式（“1”位的个数）。                | `/24`                  |
| **网络 ID**   | Net ID     | “街道名称”。子网的第一个地址。          | `192.168.1.0`          |
| **广播地址**    | Bcast      | 呼叫*所有*设备。最后一个地址。                     | `192.168.1.255`        |
| **主机**         | Host       | 子网内的设备（PC、路由器）。                     | `.1` 至 `.254`         |
| **网络位** | Net-Bits   | IP 地址中标识网络的位。              | `/24` => 前 24 位 |
| **主机位**    | Host-Bits  | IP 地址中标识网络内主机的位。 | `24` => 后 8 位    |

**规则：** IPv4 地址由 **32 位**组成，分为 4 个八位组（每个 8 位）。  
**格式：** `x.x.x.x`（十进制）或 `11000000.10101000.00000001.00001010`（二进制）

---

## 理解子网掩码与 CIDR {/*#understanding-subnet-masks--cidr*/}

子网掩码告诉计算机 IP 的哪一部分是**网络**（街道），哪一部分是**主机**（门牌号）。

### CIDR 表示法（无类别域间路由，Classless Inter-Domain Routing） {/*#cidr-notation-classless-inter-domain-routing*/}

CIDR（例如 `/24`）只是从左到右统计掩码中**有效位**的个数。

| CIDR | 十进制子网掩码 | 二进制子网掩码（前几个八位组） | 每个子网的主机数* |
| ---- | ------------------- | --------------------------------- | ----------------- |
| /8   | 255.0.0.0           | `11111111.00000000...`            | 16,777,214        |
| /16  | 255.255.0.0         | `11111111.11111111...`            | 65,534            |
| /24  | 255.255.255.0       | `11111111...11111111.0`           | 254               |
| /25  | 255.255.255.128     | `11111111...1.10000000`           | 126               |
| /26  | 255.255.255.192     | `11111111...1.11000000`           | 62                |
| /30  | 255.255.255.252     | `11111111...1.11111100`           | 2                 |

**注意：** 地址总数减 2（1 个用于网络 ID，1 个用于广播地址）。

## 计算方法 {/*#calculation-methods*/}

### 1. 计算子网大小（主机数量） {/*#1-calculating-subnet-size-number-of-hosts*/}

一个子网包含多少个**IP 地址总数**（跨所有八位组）

```text
Formula (Total Addresses): 2^(Host-Bits) = Total Addresses
Formula (Usable Hosts): 2^(Host-Bits) - 2 = Usable Hosts

Host-Bits = 32 - (CIDR)
```

#### 示例：/24 网络 {/*#example-24-network*/}

1. **主机位：** 32 - 24 = 8 位
2. **计算：** 2⁸ = 256
3. **可用：** 256 - 2 = **254 台主机**

#### 示例：/26 网络 {/*#example-26-network*/}

1. **主机位：** 32 - 26 = 6 位
2. **计算：** 2⁶ = 64
3. **可用：** 64 - 2 = **62 台主机**

---

### 2. 求“魔数”（关键八位组中的块大小） {/*#2-finding-the-magic-number-block-size-in-the-interesting-octet*/}

魔数表示进行子网划分的八位组内的**步长**。

**重要：** 魔数仅适用于“关键八位组”（即子网掩码既不为 0 也不为 255 的八位组）。

```text
Method 1 (Binary Place):
Look at the last bit set to '1' in the subnetmask. Its value is the Magic Number.

Method 2 (Subtraction):
256 - (Last non-zero octet of the mask) = Magic Number
```

#### 哪个八位组是“关键”八位组？ {/*#which-octet-is-interesting*/}

- `/24 - /32`：**第 4 个八位组**变化
- `/16 - /23`：**第 3 个八位组**变化
- `/8 - /15`：**第 2 个八位组**变化

#### 方法 [1](#1-calculating-subnet-size-number-of-hosts) 与 [2](#2-finding-the-magic-number-block-size-in-the-interesting-octet) 之间的关系 {/*#relationship-between-methods-1--2*/}

- **对于 `/24+`（第 4 个八位组的子网划分）：** 魔数 = 2^(主机位) ✔
- **对于 `/23-`（更靠前的八位组的子网划分）：** 二者不同：
  - **计算子网大小：** 地址总数跨越多个八位组
  - **求“魔数”：** 魔数只是一个八位组内的步长

#### 示例：/26 掩码 => 255.255.255.192，第 4 个八位组的子网划分 {/*#example-26-mask--255255255192---4th-octet-subnetting*/}

- **关键八位组：** 192
- **计算：** 256 - 192 = **64**
- **结果：** 网络以 64 为步长递增（0、64、128、192）。

#### 示例：`/18` 掩码 => 255.255.192.0，第 3 个八位组的子网划分 {/*#example-18-mask--2552551920---3rd-octet-subnetting*/}

**总大小：**

- 主机位：32 - 18 = 14
- 地址总数：2^14 = **16,384**

**魔数（第 3 个八位组中的步长）：**

- 掩码：`255.255.192.0`
- 关键八位组：第 3 个（192）
- 魔数：256 - 192 = **64**
- 含义：第 3 个八位组以 64 递增（0、64、128、192）

**二者的联系：**

- 64 是第 3 个八位组中的步长
- 每一步包含 256 个地址（完整的第 4 个八位组）
- 总计：64 × 256 = 16,384 ✔

---

### 3. 计算子网数量 {/*#3-calculating-number-of-subnets*/}

划分子网时，会从主机部分“借用”位来创建更多网络。

```text
Formula: 2^(Borrowed Bits) = Number of Subnets

Borrowed Bits = New CIDR - Original CIDR
```

#### 示例：从 /24 到 /26 {/*#example-from-24-to-26*/}

**场景：** 现有 `192.168.1.0/24`，需要将其拆分为 `/26` 个子网。

1. **原始网络：** `/24`（共 256 个地址）
2. **新的子网大小：** `/26`
3. **借用的位：** 26 - 24 = **2 位**
4. **子网数量：** 2² = **4 个子网**

**结果：** 得到 4 个子网，每个有 64 个地址（62 台可用主机）。

| 子网编号 | 网络 ID    | 第一台主机    | 最后一台主机     | 广播地址     |
| -------- | ------------- | ------------- | ------------- | ------------- |
| 1        | 192.168.1.0   | 192.168.1.1   | 192.168.1.62  | 192.168.1.63  |
| 2        | 192.168.1.64  | 192.168.1.65  | 192.168.1.126 | 192.168.1.127 |
| 3        | 192.168.1.128 | 192.168.1.129 | 192.168.1.190 | 192.168.1.191 |
| 4        | 192.168.1.192 | 192.168.1.193 | 192.168.1.254 | 192.168.1.255 |

#### 示例：从 /16 到 /24 {/*#example-from-16-to-24*/}

**场景：** ISP 分配了 `10.0.0.0/16`，需要 `/24` 个网络供各部门使用。

1. **原始：** `/16`
2. **新：** `/24`
3. **借用的位：** 24 - 16 = **8 位**
4. **子网数量：** 2⁸ = **256 个子网**

**结果：** 可以创建 256 个部门网络（10.0.0.0/24、10.0.1.0/24、...、10.0.255.0/24）。

## 分步计算示例 {/*#step-by-step-example-calculation*/}

**任务：** 分析 IP `192.168.10.150`，掩码为 `255.255.255.192`（/26）。

### 步骤 1：求魔数（块大小） {/*#step-1-find-the-magic-number-block-size*/}

- 掩码为 `/26`。变化发生在第 4 个八位组。
- 第 4 个八位组中的掩码：`192`
- 魔数：`256 - 192 = 64`

### 步骤 2：确定子网范围 {/*#step-2-determine-subnet-ranges*/}

以 64 递增，直至超过该 IP 地址（`150`）。

- 子网 1：`0 - 63`
- 子网 2：`64 - 127`
- 子网 3：`128 - 191`（150 落在此范围内）
- 子网 4：`192 - 255`

### 步骤 3：计算地址 {/*#step-3-calculate-addresses*/}

IP `192.168.10.150` 属于 `.128` 子网。

| 类型           | 计算          | 结果             |
| -------------- | -------------------- | ------------------ |
| **网络 ID** | 块的起始   | **192.168.10.128** |
| **第一台主机** | 网络 ID + 1       | **192.168.10.129** |
| **最后一台主机**  | 广播地址 - 1        | **192.168.10.190** |
| **广播地址**  | 下一个块（192）- 1 | **192.168.10.191** |

## 常见陷阱 {/*#common-pitfalls*/}

- **忘记网络 ID/广播地址：** 始终减去 2 以得到*可用*主机数。
- **步进错误：** 子网范围是包含端点的。因此第一个子网止于 `start + block size − 1`。第一个子网正确之后，后续子网的结尾既可通过在前一个子网结尾上加上块大小来计算，也可使用各子网的网络地址应用同样的 `start + block size − 1` 公式来计算。
- **偶数/奇数：** 网络 ID 通常为偶数；广播地址通常为奇数。
- **八位组错误：** `/18` 子网在*第 3 个*八位组而不是第 4 个八位组中变化。
- `/8 - /15`：第 2 个八位组变化
- `/16 - /23`：第 3 个八位组变化
- `/24 - /32`：第 4 个八位组变化
