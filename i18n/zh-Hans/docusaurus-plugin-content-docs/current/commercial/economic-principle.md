# 经济原则

资金、时间、材料和劳动力等资源是稀缺的。因此，**经济原则**（也称*合理性原则*）要求**投入**（所用的手段）与**产出**（所取得的结果）之间的比率尽可能有利。

## 形式 {/*#forms*/}

| 形式     | 固定项 | 规则                                       |
| -------- | ------ | ------------------------------------------ |
| 最大原则 | 投入   | 以给定的投入取得尽可能大的产出。           |
| 最小原则 | 产出   | 以尽可能少的投入取得给定的产出。           |
| 最优原则 | 均不固定 | 选择投入与产出，使二者的比率尽可能有利。 |

## 示例 {/*#examples*/}

- **最大原则：** IT 部门有 20,000 EUR 的笔记本电脑预算，并用它购买尽可能多的符合要求规格的设备。
- **最小原则：** IT 部门需要 15 台给定规格的笔记本电脑，通过[报价比较](./offer-comparison.md)确定总价最低的供应商，并在该处购买。
- **最优原则：** 企业计划建设网店，既没有固定预算，也没有固定的功能范围，并选择成本与收益之比最佳的预算与功能组合。
