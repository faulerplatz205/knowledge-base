# 报价比较

## 概述 {/*#overview*/}

报价比较用于采购中评估两份或多份供应商报价，以确定最优方案。该过程既包括**定量**（可衡量、基于成本）比较，也包括**定性**（基于标准）比较。

## 定量比较 {/*#quantitative-comparison*/}

定量比较侧重于可衡量的财务因素：

- **采购价格 / 单价**：产品或服务的基础成本
- **运输与处理费用**：交付和处理产生的额外成本
- **折扣**：适用于标价，通常基于订单量或业务关系
- **现金折扣（Skonto）**：在规定期限内提前付款所获得的第二项折扣
- **付款条件**：影响总成本的到期日和条件

## 定性比较 {/*#qualitative-comparison*/}

定性比较评估较难量化但同样重要的非财务标准：

- **质量**：产品或服务的质量、认证以及标准合规性
- **可靠性**：供应商的可信赖程度和按时交付的历史记录
- **支持**：售后服务、保修条件和响应能力
- **可持续性**：环保标准、本地采购和道德实践
- **业务关系**：现有合作关系、信任和长期潜力

## 评分方法 {/*#scoring-method*/}

当需要把定性与定量因素合并为单一决策时，可使用**加权评分模型**：

1. 定义所有相关标准，并为每项标准分配权重（权重之和须为 100%）
2. 就每项标准为每个供应商打分（例如采用 1-10 分制，或 3 分制，其中 3 = 好，2 = 一般，1 = 差）
3. 将每个分数乘以其权重，得到加权得分
4. 按供应商汇总加权得分
5. 总分最高的供应商代表整体最优报价

这种方法使主观标准更透明，并便于在不同供应商之间进行比较。

**注意：** 评分模型没有唯一的标准化方法。评分尺度和计算方式都存在不同变体：

- **评分尺度**：常见尺度包括 1-10、1-5 或 3 分制（3 = 好，2 = 一般，1 = 差）
- **计算方式**：权重可以用整数（例如 `40 x 8 = 320`）或小数（例如 `0.40 x 8 = 3.20`）。两种方式得出相同的排名，只是总分不同

### 示例 {/*#example*/}

假设要为一些新员工采购一批新笔记本电脑。采用 1–10 分制，并以整数形式应用权重（例如 `40 x 8 = 320`）来找出最佳供应商。

- **供应商 1**：价格便宜，但质量一般
- **供应商 2**：价格昂贵且交货缓慢，但质量一流
- **供应商 3**：均衡，交货快

| 标准 | 权重 | 供应商 1 | 供应商 2 | 供应商 3 |
| ------------------------------------------------------ | --------- | ------------ | ------------ | ------------ |
| 价格（[定量](#quantitative-comparison)） | 40% | 8 => **320** | 6 => **240** | 7 => **280** |
| 质量（[定性](#qualitative-comparison)） | 40% | 6 => **240** | 9 => **360** | 7 => **280** |
| 交货时间（[定性](#qualitative-comparison)） | 20% | 7 => **140** | 5 => **100** | 9 => **180** |
| 总和 | 100% | **700** | **700** | **740** |

**结果**：在本示例中，供应商 3 的总分最高，因此是推荐的选择。
