# AIDA 模型

**AIDA 模型**描述了成功的广告引导潜在客户从初次接触到购买所经历的四个连续阶段。该模型可追溯至美国广告先驱 Elmo Lewis（1898 年），既用于设计广告，也用于评估广告。广告常常针对客户尚未意识到的[潜在需求](./needs-and-demand.md#types-of-needs)。

## 阶段 {/*#stages*/}

| 阶段           | 目标                                         | 典型手段                                           |
| -------------- | -------------------------------------------- | -------------------------------------------------- |
| **注意**（Attention） | 广告在众多竞争刺激中被注意到。          | 醒目的图像、色彩或音乐，不寻常的标题，知名面孔     |
| **兴趣**（Interest）  | 客户想进一步了解产品。                  | 功能与益处的信息，产品所解决的问题                 |
| **欲望**（Desire）    | 客户想要拥有该产品。                    | 情感诉求，与当前状况的对比，评价，稀缺性           |
| **行动**（Action）    | 客户执行预期的行动，通常是购买。        | 行动号召，"立即购买"按钮，限时折扣，简便的下单流程 |

预期的行动不一定是购买。订阅新闻通讯、试驾或索取报价同样可以是广告的目标。

## 示例 {/*#example*/}

一家智能手机制造商在社交媒体上宣传新机型。

| 阶段 | 实施                                                         |
| ---- | ------------------------------------------------------------ |
| 注意 | 一段配有动听音乐的吸睛视频在滑动信息流时脱颖而出。           |
| 兴趣 | 视频展示新款相机和令人印象深刻的夜景照片。                   |
| 欲望 | 与旧手机拍摄的照片相比，观看者心想"我想要这个"。             |
| 行动 | 带有 48 小时有效折扣的"立即购买"按钮直接通向订单。           |

## 扩展 {/*#extensions*/}

- **AIDAS：** 增加*满意*（Satisfaction）。满意的客户会再次购买并推荐产品，因此购买后的满意度也是广告目标的一部分。
- **AIDCA：** 在欲望与行动之间增加*信念*（Conviction）。客户通过测试结果或保证等论据确信购买是正确的决定。

## 局限 {/*#limitations*/}

- 真实的购买决策并非线性。冲动购买会跳过某些阶段，而昂贵商品的购买涉及调研与比较，这是该模型未涵盖的。
- 该模型将客户视为被动者。如今客户常常自行搜索信息，例如通过评价、比价平台和社交媒体。

## 常见错误 {/*#common-mistakes*/}

1. **混淆兴趣与欲望：** 兴趣是想进一步了解产品的愿望，欲望是想拥有产品的愿望。阅读技术数据的客户有兴趣，但不一定想购买。
