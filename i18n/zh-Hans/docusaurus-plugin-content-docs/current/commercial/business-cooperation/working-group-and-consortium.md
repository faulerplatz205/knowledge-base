# 工作组与联合体

**工作组**或**联合体**是法律上和经济上独立的企业为完成某个特定项目而结成的临时联合体，这类项目通常对单一企业而言过大或风险过高。

## 定义 {/*#definition*/}

- 与项目或任务相关的合作，项目完成时即告结束
- 常见于建筑以及大型基础设施或服务项目
- 典型的法律形式：民法上的合伙
- **区别**：联合体是较松散的形式，各成员独立提供各自的服务

## 工作组与联合体 {/*#working-group-vs-consortium*/}

尽管两者常被互换使用，但它们在内部整合程度上有所不同：

| 方面     | 工作组（ARGE）           | 联合体                                |
| -------- | ------------------------ | ------------------------------------- |
| 整合程度 | 高：资源、资金和人员汇集 | 低：各成员独立完成各自份额            |
| 内部组织 | 共同管理、共同核算       | 各成员分别管理和核算                  |
| 责任     | 连带责任                 | 通常仅限于各成员自己的部分            |
| 典型领域 | 建筑和基础设施           | 银行业（银团贷款、IPO）、大型服务项目 |

简言之：工作组在内部汇集资源并共同工作，而联合体对外共同亮相，但各成员独立处理自己的部分。

## 对独立性的影响 {/*#effect-on-independence*/}

- 成员在**法律上和经济上保持独立**
- 各自保留自己的法律形式和核心业务
- 利润和亏损在合作伙伴之间分配
- 如果工作组以自己的名义行事，可作为合伙企业纳税

## 动机 {/*#motives*/}

- 承担任何单一企业都无法独自完成的项目
- 分担成本和风险
- 整合专有技术、资源和产能
- 增强竞争力

## 优点与缺点 {/*#advantages-and-disadvantages*/}

| 优点                 | 缺点                         |
| -------------------- | ---------------------------- |
| 工作、成本和风险共担 | 可能出现协调问题             |
| 大型项目变得可行     | 合作伙伴的利益各不相同       |
| 利用合作伙伴的专有技术 | 需承担合作伙伴过失的责任风险 |

## 对竞争的影响 {/*#effects-on-competition*/}

- 优势整合（专有技术、资本、资源）
- 对消费者可能的好处：质量更好、价格更低、交付更快
- **风险**：市场力量过大可能挤压小企业，并滑向类似卡特尔的局面

## 与合资企业的比较 {/*#comparison-with-joint-venture*/}

两种形式都涉及独立企业之间的合作，但在范围、期限和结构上有所不同：

| 方面         | 工作组 / 联合体            | 合资企业                             |
| ------------ | -------------------------- | ------------------------------------ |
| 期限         | 与项目绑定，项目结束时解散 | 通常长期或持续                       |
| 新的法律实体 | 没有，通常是民法上的合伙   | 通常有（例如共同设立的 GmbH）        |
| 范围         | 单一、明确界定的项目       | 更广泛的战略目标（进入市场、产品线） |
| 资源         | 各成员各自独立出资         | 共同管理并汇集                       |
| 利润分配     | 按协议在合作伙伴之间分配   | 在设立合同中明确约定                 |

简言之：工作组或联合体是仅限于一个项目的临时联盟，项目结束后各合作伙伴各奔前程；而合资企业是更紧密、通常长期存在的伙伴关系，共享资源，并且常常设立新公司。

## 示例 {/*#examples*/}

- **A7 高速公路扩建**（德国）：EUROVIA、ROHDE 和 STUTZ 组成的工作组，Bockenem 与 Northeim-Nord 之间的六车道扩建，2023 年结束
- **Stuttgart 21**：大型铁路基础设施项目，参与方包括 Züblin、HOCHTIEF、Deutsche Bahn 等，汇集了隧道、深基础和结构方面的专业知识
