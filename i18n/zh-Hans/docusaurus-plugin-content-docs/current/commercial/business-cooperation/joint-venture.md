# 合资企业

**合资企业**（Joint Venture）是至少两家独立企业之间的合作，通常通过共同设立新公司或在某个项目上进行合同合作来实现。合作企业在其他方面仍保持独立。

## 类型 {/*#types*/}

- **本地、区域、全国性**：来自同一国家或地区的企业联手（例如为某个本地项目）
- **国际性**：来自不同国家的企业组建合资公司以进入外国市场（在汽车行业非常常见）

## 动机 {/*#motives*/}

- 进入新市场并接触新客户（例如外国市场）
- 分担成本、风险和利润
- 整合专有技术和资源（技术、研究）
- 遵守法律要求（例如中国曾要求外国企业只能通过合资企业进行生产）

## 对独立性的影响 {/*#effect-on-independence*/}

- **法律上**：合作伙伴保持独立；通常会为该合资项目设立新的法律实体
- **经济上**：合作伙伴在其他业务领域保持独立，但在合资项目中紧密合作，共同承担责任、利润和亏损

## 优点与缺点 {/*#advantages-and-disadvantages*/}

| 优点                 | 缺点               |
| -------------------- | ------------------ |
| 分担成本和风险       | 合作伙伴之间的冲突 |
| 进入新市场并获得客户 | 利润需分享         |
| 整合专有技术和资源   | 依赖合作伙伴       |
| 竞争地位更强         | 决策较慢           |

## 对竞争和经济的影响 {/*#effects-on-competition-and-economy*/}

- **其他企业**：企业联手后竞争对手减少，但其他企业也可能受到激励而开展合作
- **消费者**：出现新产品和新技术，有时价格更低，但品牌多样性减少
- **经济**：推动创新、增长和外国投资，但存在市场集中的风险

## 与工作组和联合体的比较 {/*#comparison-with-working-group-and-consortium*/}

两种形式都涉及独立企业围绕特定目标的合作，但在范围和结构上有所不同：

| 方面         | 合资企业                             | 工作组 / 联合体            |
| ------------ | ------------------------------------ | -------------------------- |
| 期限         | 通常长期或持续                       | 与项目绑定，项目结束时解散 |
| 新的法律实体 | 通常有（例如共同设立的 GmbH）        | 没有，通常是民法上的合伙   |
| 范围         | 更广泛的战略目标（进入市场、产品线） | 单一、明确界定的项目       |
| 资源         | 共同管理并汇集                       | 各成员各自独立出资         |
| 利润分配     | 在设立合同中明确约定                 | 按协议在合作伙伴之间分配   |

简言之：合资企业是更紧密、通常长期存在的伙伴关系，共享资源，并且常常设立新公司；而工作组或联合体是仅限于一个项目的临时联盟，项目结束后各合作伙伴各奔前程。

## 与利益共同体的比较 {/*#comparison-with-interest-group*/}

两种形式都涉及独立企业之间的合作，但在结构和目的上有所不同：

| 方面          | 合资企业                            | 利益共同体                             |
| ------------- | ----------------------------------- | -------------------------------------- |
| 法律形式      | 通常是新成立的法律实体（例如 GmbH） | 没有自己的法律形式，通常是民法上的合伙 |
| 合同严格程度  | 经正式规范，权利和义务明确界定      | 非正式，无需固定形式                   |
| 目的          | 范围明确的特定项目或目标            | 广泛、持续的共同利益（游说、成本分摊） |
| 利润/亏损分担 | 合作伙伴之间明确约定                | 不一定约定                             |
| 典型期限      | 通常与项目绑定或有时间限制          | 无固定期限                             |

简言之：合资企业是为实现特定目标而设立的更紧密的合同伙伴关系，通常通过新成立的公司进行；而利益共同体是为追求共同目标而作出的较松散、通常非正式的安排。

## 示例（汽车行业，中国） {/*#examples-automotive-china*/}

| 合资企业          | 详情                                |
| ----------------- | ----------------------------------- |
| Volkswagen & SAIC | 在中国生产 VW 汽车（自 1984 年起）  |
| BMW & Brilliance  | 50:50 的合资企业，生产 BMW 车型     |
| Daimler & BAIC    | 在中国生产 Mercedes（Beijing Benz） |
| Sony & Ericsson   | Sony Ericsson 手机                  |
