# 企业集团与控股公司

**企业集团**是在统一领导下的法律上独立企业的联合体。**控股公司**是其中一种特殊形式，母公司持有子公司的股权并提供战略指导。

## 结构 {/*#structure*/}

- **企业集团**：层级式（母公司 / 子公司）；母公司控制子公司
- **控股公司类型**：
  - **纯粹控股公司**：仅管理股权
  - **经营性控股公司**：同时经营自己的业务

## 企业集团的形式 {/*#forms-of-corporate-groups*/}

### 从属型集团 {/*#subordination-group*/}

- 由母公司作出战略决策
- 子公司在**法律上独立**，但在**经济上依附**
- 示例：**Volkswagen AG**，旗下有 Audi、Porsche、Skoda

### 平等型集团 {/*#coordination-group*/}

- 没有占支配地位的母公司
- 企业之间相互持股或共享共同领导层
- 权力更为均衡，在实践中较为少见

## 对独立性的影响 {/*#effect-on-independence*/}

- **法律上**：子公司仍是独立的法律主体
- **经济上**：受集团中央指导

## 优点与缺点 {/*#advantages-and-disadvantages*/}

| 优点                 | 缺点                       |
| -------------------- | -------------------------- |
| 资金实力与市场力量   | 丧失企业独立性             |
| 共同战略             | 滥用权力的风险             |
| 利用协同效应         | 管理复杂                   |
| 分散风险             | 竞争减弱                   |
| 更易获得资本         | 集团与子公司利益之间的冲突 |

## 示例 {/*#examples*/}

- **Oetker 集团**：多元化经营（食品、航运、酒店）
- **Procter & Gamble**：国际消费品（Pampers、Gillette、Ariel）
- **Nestlé**：全球最大的食品集团（KitKat、Nescafé、Maggi）
- **Volkswagen AG**：拥有 Audi、Porsche、Skoda
