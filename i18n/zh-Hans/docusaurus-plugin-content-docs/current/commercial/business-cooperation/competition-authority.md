# 竞争主管机构

**竞争主管机构**是指国家机关监督并执行竞争法以防止限制竞争、滥用市场力量和形成垄断的全部措施。在德国，这主要由 **Bundeskartellamt** 负责。

## 三大支柱 {/*#three-pillars*/}

### 卡特尔查处 {/*#cartel-prosecution*/}

Bundeskartellamt 查明并追究企业之间的价格操纵、市场瓜分及其他秘密协议。

| 优点               | 缺点           |
| ------------------ | -------------- |
| 防范价格操纵       | 难以收集证据   |
| 促进公平市场       | 各国存在差异   |

### 合并控制 {/*#merger-control*/}

| 优点                     | 缺点             |
| ------------------------ | ---------------- |
| 防止大型合并形成垄断     | 干预经营自由     |
| 保障竞争持续存在         | 各国存在差异     |

### 滥用监督 {/*#abuse-supervision*/}

| 优点                         | 缺点             |
| ---------------------------- | ---------------- |
| 防范大型企业滥用权力         | 评估复杂         |
|                              | 存在过度监管风险 |

## 滥用市场力量的类型 {/*#types-of-abuse-of-market-power*/}

市场支配企业可以通过两种主要方式滥用其地位：

- **剥削性滥用**：支配企业索取不合理的高价或强加不公平的条件，以剥削客户或供应商。
- **排他性滥用**：支配企业阻碍竞争对手，例如拒绝其使用必要的基础设施。典型的例子是电信公司阻止对手接入其网络，以获取不正当的竞争优势。

## 影响 {/*#effects*/}

- 创造**公平的市场条件**，任何企业都不能获得非法优势
- 提高市场的**透明度与信任**
- 企业必须凭业绩竞争
- **威慑作用**：罚款最高可达**年营业额的 10%**
- 消费者：价格更低、选择更多、质量更好

## 近期案例 {/*#recent-examples*/}

**获批的合并：**

- Lufthansa 与 ITA Airways（2024 年 7 月）
- Microsoft 与 Activision Blizzard（2023 年底完成，2024 年实施）

**被否决的合并：**

- Amazon 与 iRobot（2024 年 1 月）
- Adobe 与 Figma（2023 年底）

**其他行动：**

- **Google**（2025 年）：被迫取消对 Google Maps Platform 的限制
- **Amazon**（2026 年 2 月）：Bundeskartellamt 禁止了某些价格控制机制，并没收了 5900 万欧元的利润
