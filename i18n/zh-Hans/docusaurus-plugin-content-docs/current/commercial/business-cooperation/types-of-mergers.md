# 合并的类型

企业合并时，**合并的方向**决定其类型。三种主要类型是横向、纵向和斜向合并。

## 横向合并 {/*#horizontal-merger*/}

**横向合并**将处于**同一行业**价值链**同一环节**的企业合并，通常是直接竞争对手。

**目标**：扩大市场份额、消除竞争并实现规模经济。

**示例**：两家汽车制造商合并，或两家零售银行合并。

## 纵向合并 {/*#vertical-merger*/}

**纵向合并**将处于同一价值链**不同环节**的企业合并，即供应商与客户。

有两个方向：

- **前向整合**：企业收购更接近最终客户的业务（例如制造商收购零售连锁店）
- **后向整合**：企业收购更接近原材料的业务（例如制造商收购零部件供应商）

**目标**：保障供应链、减少对外部合作伙伴的依赖，并通过消除中间商来降低成本。

**示例**：汽车制造商收购钢铁供应商（后向），或生产商收购自己的分销网络（前向）。

## 斜向合并 {/*#diagonal-merger*/}

**斜向合并**（也称**混合合并**）将来自**完全无关行业**、没有直接供应链关系的企业合并。

**目标**：实现业务多元化、在不同市场之间分散风险，并开辟新的收入来源。

**示例**：制造企业收购金融服务公司，或媒体公司收购物流服务商。

## 比较 {/*#comparison*/}

| 类型 | 涉及的企业             | 主要目标           |
| ---- | ---------------------- | ------------------ |
| 横向 | 同一行业，同一环节     | 市场份额、规模     |
| 纵向 | 同一行业，不同供应环节 | 供应保障、降低成本 |
| 斜向 | 不同行业               | 多元化             |
