# 合并与托拉斯

**合并**（Merger）是将两家或多家企业合并为一个实体。所有资产、权利、义务和合同转移给新公司（或收购方公司），且至少有一家原有企业在法律上不复存在。

## 合并的两种形式 {/*#two-forms-of-merger*/}

- **吸收合并**：一家公司吸收另一家公司
- **新设合并**：多家公司合并为一个全新的实体

## 对独立性的影响 {/*#effect-on-independence*/}

- 参与合并的企业**同时失去法律上和经济上的独立性**
- 它们被完全并入新公司或收购方公司

## 动机 {/*#motives*/}

- 节约成本并提高效率
- 扩大市场份额
- 整合专有技术
- 增强财务实力
- 进入新市场

## 优点与缺点 {/*#advantages-and-disadvantages*/}

| 优点           | 缺点                       |
| -------------- | -------------------------- |
| 更强的市场地位 | 丧失独立性                 |
| 节约成本       | 整合问题                   |
| 整合专有技术   | 成本高（法律、重组）       |
| 更强的财务实力 | 可能裁员                   |
| 进入新市场     | 预期的协同效应可能无法实现 |

## 对环境的影响 {/*#effects-on-environment*/}

| 受影响方 | 可能的影响                                             |
| -------- | ------------------------------------------------------ |
| 其他企业 | 竞争加剧、被挤出市场、对小企业构成压力                 |
| 消费者   | 价格可能上涨、选择减少，有时因效率提升而获得更好的产品 |
| 整体经济 | 生产率提高，但市场力量集中并存在垄断风险               |

## 托拉斯，合并的结果 {/*#trust-the-result-of-a-merger*/}

合并是**过程**，而**托拉斯**（Trust）是**结果**：多家企业在统一管理下完全合并并放弃独立性，因此在经济上如同一家公司那样行事。

## 与相似形式的区别 {/*#distinction-from-similar-forms*/}

- **卡特尔**：企业保持独立，仅协调行为
- **企业集团**：企业在法律上保持独立，但受共同控制
- **托拉斯**：企业完全合并并失去独立性

## 示例 {/*#examples*/}

- **Daimler-Benz 与 Chrysler**（1998 年），合并为 DaimlerChrysler
- **Disney 与 Pixar**（2006 年），Disney 完全收购了 Pixar
