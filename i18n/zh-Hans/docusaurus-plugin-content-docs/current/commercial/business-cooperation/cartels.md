# 卡特尔

**卡特尔**（Cartel）是本应相互竞争的企业之间达成的协议，这些企业转而相互协调，以限制或消除竞争。其目标是通过减少竞争获得更高利润。

## 德国竞争法下的类别 {/*#categories-under-german-competition-law*/}

### 一般禁止的卡特尔 {/*#generally-prohibited-cartels*/}

- **价格卡特尔**：企业就价格或招标中的报价达成一致
- **地域卡特尔**：划分市场以避免竞争
- **计算卡特尔**：确定统一的定价方案
- **配额卡特尔**：约定固定的产量

示例：**糖业卡特尔**，对价格、销售区域和配额作出约定。

### 需申报的卡特尔 {/*#notification-required-cartels*/}

- **条件卡特尔**：统一的条款和付款规则
- **折扣卡特尔**：对所有客户给予相同折扣
- **专业化卡特尔**：每家企业专注于特定产品
- **标准化卡特尔**：统一的产品标准或类型

### 需批准的卡特尔 {/*#approval-required-cartels*/}

- **结构性危机卡特尔**：危机时期共同削减产量
- **辛迪加**：由共同的销售办事处为所有成员处理订单和付款

示例：**E.ON / Innogy 合并**必须向 Bundeskartellamt 申报，因为合并后在能源领域的市场份额将十分可观。

## 对独立性的影响 {/*#effect-on-independence*/}

- **法律上**：企业形式上仍保持独立，但其行动自由受到卡特尔协议的限制
- **经济上**：企业失去对价格、数量和销售政策的独立控制

## 形成卡特尔的动机 {/*#motives-for-cartel-formation*/}

- 通过减少竞争实现利润最大化
- 价格稳定
- 降低成本
- 市场势力

## 优点与缺点 {/*#advantages-and-disadvantages*/}

| 优点                 | 缺点                 |
| -------------------- | -------------------- |
| 竞争减少带来更高利润 | 违规将被处以高额罚款 |
| 协调行为降低风险     | 依赖其他卡特尔成员   |

## 对他方的影响 {/*#effects-on-others*/}

- **其他企业**：新进入者更难进入市场
- **消费者**：价格更高，选择更少
- **经济**：对自由市场失去信任
