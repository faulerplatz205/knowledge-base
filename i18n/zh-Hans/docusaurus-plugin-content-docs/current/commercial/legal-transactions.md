# 法律行为

德国《民法典》（BGB）下的**法律行为**（德语：*Rechtsgeschäft*）至少由一项意思表示构成，并旨在产生法律效果，例如设立、变更或终止法律关系。商业中最常见的法律行为是[买卖合同](./purchase-contract.md)。

## 意思表示 {/*#declaration-of-intent*/}

**意思表示**（*Willenserklärung*）表达的是指向某一法律效果的意愿，可以通过不同方式作出。

- **明示：** 以口头、书面或电子方式作出，例如在网店下订单。
- **推断行为：** 可从中推知其意愿的行为，例如把商品放上收银传送带、上出租车或在拍卖会上举手。

必须到达相对人的意思表示（如解除通知）在到达相对人时生效（BGB 第 130 条）。相对人是否阅读则无关紧要。信件投入信箱后，只要在通常情况下可期待信箱被清空，即视为已到达。

## 法律行为的类型 {/*#types-of-legal-transactions*/}

| 类型 | 意思表示 | 示例 |
| --------------------------------- | -------------------------------- | ------------------------------------------------------- |
| 单方行为，须到达相对人 | 一项，向另一人作出 | 解除通知、撤销、退出合同 |
| 单方行为，无须到达相对人 | 一项，无需相对人即可生效 | 遗嘱、公开悬赏广告 |
| 约束一方的合同 | 两项相一致的意思表示 | 赠与、保证 |
| 约束双方的合同 | 两项相一致的意思表示 | 买卖合同、租赁合同、劳动合同 |

**合同**始终至少需要两项内容一致的意思表示，即要约和承诺。合同被称为单务还是双务，指的是它所产生的义务，而不是意思表示的数量。赠与是一种合同，因为受赠人必须接受，但只有赠与人负有义务。

## 行为能力 {/*#capacity-to-contract*/}

**权利能力**（*Rechtsfähigkeit*）是享有权利和承担义务的能力，始于出生（BGB 第 1 条）。**行为能力**（*Geschäftsfähigkeit*）是作出具有法律效力的意思表示的能力，主要取决于年龄。患有持续性精神障碍而排除自由意志的人，无论年龄多大，均无行为能力（BGB 第 104 条第 2 项）。

| 年龄 | 行为能力 | 后果 |
| ------- | ---------------------- | -------------------------------------------------------------------------------------------- |
| 7 岁以下 | 无（BGB 第 104 条第 1 项） | 意思表示无效（BGB 第 105 条）。由法定代理人代表儿童行事。 |
| 7 至 17 岁 | 限制行为能力（BGB 第 106 条） | 合同须经法定代理人同意，通常为父母（BGB 第 107 条）。 |
| 18 岁起 | 完全 | 意思表示不受限制地生效。 |

未成年人未经事先同意订立的合同处于**效力待定**状态（BGB 第 108 条）。法定代理人追认时合同生效，拒绝追认时合同终局无效。未成年人可以单独行事的例外情形如下：

- **纯获法律上利益：** 不附带义务的赠与，例如赠送金钱（BGB 第 107 条）。
- **零花钱条款：** 以为此目的或为自由支配而交给未成年人的资金完全履行的合同（BGB 第 110 条）。
- **经许可的雇佣：** 与父母已许可的雇佣关系有关的法律行为（BGB 第 113 条）。

## 无效与可撤销的法律行为 {/*#void-and-voidable-legal-transactions*/}

**无效**（*nichtig*）的法律行为自始无效，无需任何人采取行动。

| 原因 | 示例 |
| ------------------------------------------------ | -------------------------------------------------------------------------- |
| 无行为能力（BGB 第 105 条） | 一名六岁儿童购买游戏机。 |
| 虚假行为（BGB 第 117 条） | 为避税而在合同中记载较低的价格。 |
| 戏谑行为（BGB 第 118 条） | 明显出于玩笑说出“我以 1 欧元把我的车卖给你”。 |
| 欠缺法定形式（BGB 第 125 条） | 出售土地而未经公证认证。 |
| 违反法定禁止规定（BGB 第 134 条） | 一份非法用工合同。 |
| 违背善良风俗、暴利（BGB 第 138 条） | 利用他人困境，以远高于市场水平的利率发放贷款。 |

**可撤销**（*anfechtbar*）的法律行为在一方撤销之前有效。撤销后，该行为自始无效（BGB 第 142 条）。

| 原因 | 示例 | 期限 |
| ------------------------------------------------------- | ------------------------------------------------------------------- | ----------------------------------- |
| 内容错误（BGB 第 119 条第 1 款） | 买方订购一“罗”（gross）钢笔，却以为是 100 支。 | 发现后不得无故拖延 |
| 表示错误（BGB 第 119 条第 1 款） | 报价中的笔误将 10,000 欧元写成了 1,000 欧元。 | 发现后不得无故拖延 |
| 对交易上重要特性的错误（BGB 第 119 条第 2 款） | 一幅画被当作原作购入，结果却是复制品。 | 发现后不得无故拖延 |
| 传达错误（BGB 第 120 条） | 传话人转达了错误的数量。 | 发现后不得无故拖延 |
| 欺诈（BGB 第 123 条） | 明知发生过事故，仍将二手车作为无事故车出售。 | 发现后一年 |
| 非法胁迫（BGB 第 123 条） | 在暴力威胁下签订合同。 | 胁迫结束后一年 |

因错误而撤销的一方，须赔偿对方因信赖该意思表示而遭受的损害（BGB 第 122 条）。

## 常见错误 {/*#common-mistakes*/}

1. **只把书面合同视为有约束力：** 合同通常无需任何特定形式即可订立，包括口头或通过推断行为。只有在法律或当事人之间的约定规定了特定形式时才需要该形式，例如出售土地须经公证认证（BGB 第 311b 条），或终止劳动关系须采用书面形式（BGB 第 623 条）。
2. **把沉默视为承诺：** 沉默不会产生合同。一个例外是商事确认函：在商人之间，对其沉默视为同意其内容。消费者收到未订购的商品，既无需付款，也无需退还（BGB 第 241a 条）。
3. **把无效与可撤销等同：** 无效的行为从不生效。可撤销的行为在被撤销之前有效，未经撤销则一直有效。
4. **因动机错误而撤销：** 对交易原因的错误不构成撤销事由。购买股票并预期其价格上涨的买方，在价格下跌时不能撤销该购买。对方无法识别的计算错误亦同。
5. **将零花钱条款适用于分期付款购买：** BGB 第 110 条要求合同以未成年人的资金完全履行。分期付款购买在最后一期付清之前一直处于效力待定状态，除非父母事先同意或事后追认。
