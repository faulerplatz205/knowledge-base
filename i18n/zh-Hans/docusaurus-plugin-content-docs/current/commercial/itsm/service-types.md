# IT 服务类型

## 概述 {/*#overview*/}

IT 服务可以按交付方式和管理方进行分类。本文涵盖各框架中“服务”的主要定义、常见的 IT 服务类型、IMAC/R/D 生命周期以及 ITSM 关键术语。

## 服务的定义 {/*#service-definitions*/}

| 来源 | 定义 |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BSI | “服务是为完成某项任务而对对象和流程所做的组合。” |
| FitSM | “服务是通过支持客户目标而向客户交付价值的一种方式。” |
| ITIL 4 | “服务是通过促成客户希望实现的成果来促进价值共创的一种方式，而客户无需自行管理特定的成本和风险。” |

**质量令人信服，服务决定成败。**

## IT 服务类型概览 {/*#it-service-types-overview*/}

| 服务类型 | 说明 |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IT 销售 / IT 贸易 | 采购 IT 系统和组件，包括安装和网络连接 |
| IT 服务 | 由 IT 实现并面向 IT 的任何服务 |
| Break/Fix 支持 / 现场服务 / 上门服务 | 按需在客户现场提供的 IT 服务；按人工和零件计费。通过现场服务管理（FSM）进行优化 |
| 驻场管理 | 在客户场所提供 IT 服务 |
| 更换服务（Swap Service） | 向用户提供一台相同的替换设备 |
| DIY 服务 | 由客户自行完成服务（需经制造商许可，例如保修仍然有效） |
| 云服务 | 云服务提供商提供的所有服务 |
| 在线聊天（Live Chat） | 通过小组件/应用，客户被实时连接到网络服务提供商的工作人员 |
| 聊天机器人（Chatbot） | 集成到网站、应用和社交媒体中的 AI 驱动系统，与用户自动沟通；混合型聊天机器人还提供在线聊天 |
| 托管服务（Managed Services） | 由托管服务提供商（MSP）提供的周期性 IT 服务；范围和质量事先在 SLA 中约定，例如主动监控和远程维护 |
| 保修服务 | 基于保修或担保索赔的免费服务 |
| 善意服务（Goodwill） | 承包方自愿提供的免费服务 |
| 帮助台服务 | 通过在线帮助台提供的服务 |
| 维护服务 | 维护合同范围内的服务 |
| 维修服务 | 维修类服务 |
| IT 外包 / IT 采购外包（IT Sourcing） | 对外采购 IT 服务；专业的 IT 服务提供商高效处理难以解决的任务 |
| IT 入门培训 | 向客户和员工介绍 IT 系统 |
| IT 培训 / IT 指导 | 向客户提供收费的培训与教育 |

## IMAC/R/D 生命周期 {/*#imacrd-lifecycle*/}

**IMAC/R/D** 生命周期描述 IT 设备从部署到处置的各个阶段：

| 字母 | 阶段 | 说明 |
| ------ | ----------------- | ----------------------------------------------------------------------------------------------------------- |
| **I** | 安装（Install） | 采购、预安装（staging）以及在最终地点的运行部署 |
| **M** | 迁移（Move） | 设备的搬迁，例如办公室搬迁或内部重组期间 |
| **A** | 添加（Add） | 硬件/软件的添加，例如增加内存或安装新程序 |
| **C** | 变更（Change） | 配置变更或对用户权限和策略的调整 |
| **R** | 移除 / 回退（Remove / Rollback） | 卸载设备并退回 IT 库存 |
| **D** | 处置（Dispose） | 安全删除数据（数据擦除），随后进行再营销（转售）或符合环保要求的处置 |

## ITSM 关键术语 {/*#key-itsm-terms*/}

| 术语 | 说明 |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **服务台（Service Desk）** | 面向用户的服务点；也称为帮助台 |
| **ITSM** | IT 服务管理：IT 服务提供商为规划、提供、运营和控制 IT 服务而开展的全部活动的总和 |
| **服务组合（Service Portfolio）** | 所提供全部 IT 服务的集合；包括服务目录、指导方针和职责 |
| **[SLA](./sla.md)** | 服务级别协议：服务提供方与客户之间关于服务级别的合同约定 |
| **OLA** | 运营级别协议：IT 团队/部门之间的内部协议 |
| **KPI** | 关键绩效指标：与关键业务目标相一致的度量指标，例如服务可用性或服务中断次数 |
| **SOA** | 面向服务的架构：业务流程和系统被模块化，并通过可复用的 IT 服务相互关联 |
| **[IaaS](../../cloud/service-models.md#infrastructure-as-a-service-iaas)** | 基础设施即服务：提供基础设施作为应用程序基础的云平台 |
| **服务可用性 24/7** | 服务全天候可用 |
| **服务可用性 12/5** | 服务在正常工作时间内可用 |
