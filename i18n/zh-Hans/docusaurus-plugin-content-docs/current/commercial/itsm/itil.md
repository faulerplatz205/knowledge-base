# ITIL

## 概述 {/*#overview*/}

**ITIL** 是 **Information Technology Infrastructure Library**（信息技术基础架构库）的缩写。它是一个基于成熟最佳实践的 IT 服务管理框架（即参考模型与方法），帮助组织以经济高效、以客户为导向并注重质量的方式开展工作。

ITIL 为 IT 服务组织定义了基本的**流程**、**角色**和**术语**，并为服务相关的所有参与方提供了共同的沟通基础。

## ITIL 的目标 {/*#goals-of-itil*/}

- 以客户为导向
- 成本控制与降低
- 质量有保证的服务交付
- IT 服务与业务流程的整合
- 有效且高效的 IT 服务
- 服务的持续改进

## ITIL 服务生命周期 {/*#itil-service-lifecycle*/}

ITIL 服务生命周期由五个阶段和一个持续改进的外层循环组成：

### 服务战略 {/*#service-strategy*/}

根据客户需求和市场评估，确定 IT 组织提供哪些服务以及需要发展哪些能力。

### 服务设计 {/*#service-design*/}

确定具体的服务需求，开发满足这些需求的解决方案，设计新服务，并修改或改进现有服务。

### 服务转换 {/*#service-transition*/}

构建并上线新的或经修改的 IT 服务。确保员工尽早接受培训，所需材料（如手册）按时编制，并能在目标日期前交付服务。

### 服务运营 {/*#service-operations*/}

确保 IT 服务得到有效且高效的交付。包括[满足用户请求](./service-requests.md)、[制定问题解决方案](./problem-management.md)以及在生产运行中执行运营任务。

### 持续服务改进（CSI） {/*#continual-service-improvement-csi*/}

围绕所有阶段的持续改进循环。ITIL 流程不断经受调整与改进。
