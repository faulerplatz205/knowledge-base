# 服务级别协议（SLA）

## 概述 {/*#overview*/}

**SLA（Service Level Agreement，服务级别协议）** 是 IT 服务提供商与客户之间的合同，规定所提供 IT 服务的范围、质量和条件。

## 典型的 SLA 结构 {/*#typical-sla-structure*/}

### 1. 描述 / 范围 {/*#1-description--scope*/}

规定涵盖哪些 IT 问题、如何处理以及使用哪些支持渠道（电话、电子邮件）。同时说明所涵盖的硬件和系统。

### 2. [优先级](./priorities.md) {/*#2-priorities*/}

三个或更多优先级等级，响应时间各不相同。示例：

| 优先级 | 响应时间 |
| ---------- | ---------------------------------- |
| 优先级 1 | 1 个工作小时，加急附加费 |
| 优先级 2 | 5 个工作小时，标准优先级 |
| 优先级 3 | 1 个工作日 |

**响应时间：** 从故障报告到[帮助台](./service-requests.md)起，至相应支持级别开始着手解决问题之间的时间。

### 3. 服务时间 {/*#3-service-times*/}

| 日期 | 时间 |
| --------------------------- | -------------------- |
| 周一至周五 | 07:00–20:00 |
| 周六 | 09:00–18:00 |
| 周日及公共假日 | 不提供服务 |
| 延长时段 | 可应要求提供 |

### 4. 语言 {/*#4-languages*/}

支持服务所提供的语言（例如德语、英语）。

### 5. 质量指标：来电受理 {/*#5-quality-metrics-call-acceptance*/}

| 指标 | 目标 |
| -------------------------- | -------------------------------------- |
| 已接听来电 | 所有来电的 95 %，丢失率 < 5 % |
| 20 秒内接听 | 75 % |
| 40 秒内接听 | 90 % |
| 通过语音信箱处理 | 最多 10 % |

### 6. 质量指标：问题解决 {/*#6-quality-metrics-problem-resolution*/}

| 指标 | 目标 |
| ------------------------------------------ | -------------------------- |
| 来电平均处理时间 | 最多 30 分钟 |
| 若未在以下时间内答复，则提供中间报告 | 4 小时 |
| 故障平均处理时间 | 最多 2 小时 |
| 最长处理时间 | 3 天 |
| 最低解决率 | 2 个工作日内达到 70 % |

### 7. 质量指标：客户满意度 {/*#7-quality-metric-customer-satisfaction*/}

通过在线调查和回访电话（对 10 % 的来电者进行回电和评价）进行衡量。

### 8. 报告 {/*#8-reporting*/}

每月复核；每季度进行统计评估。

### 9. 有效期与期限 {/*#9-validity-and-duration*/}

说明 SLA 的期限以及何时重新协商（例如“有效期至 20xx 年 8 月 1 日”）。

### 10. 签署方 {/*#10-signatories*/}

服务提供方和客户各自签署协议。

## 服务级别管理（SLM） {/*#service-level-management-slm*/}

**SLM** 确保与客户签订 SLA，并确保服务的设计能够满足约定的服务级别。

**任务：**

- 收集服务需求
- 检查约定的服务级别是否得到满足
- 在服务级别报告中提供信息

## 角色 {/*#roles*/}

### 服务级别经理 {/*#service-level-manager*/}

服务级别管理的流程负责人。

职责：

- 协商 SLA
- 确保 SLA 得到满足
- 确保所有 ITSM 流程、OLA 和第三方合同都支持约定的服务级别目标
- 监控服务级别并提供报告

### 服务负责人（Serviceverantwortlicher） {/*#service-owner-serviceverantwortlicher*/}

负责在约定的 SLA 范围内交付基础设施服务。

职责：

- 在约定 OLA 时，作为服务级别经理的协商对象
- 通常是带领一支技术专家团队或内部支持部门的经理

## OLA（运营级别协议） {/*#ola-operational-level-agreement*/}

**OLA** 是 IT 团队或部门之间关于运营层面服务交付的内部协议。OLA 有助于履行对外的 SLA。
