# 报价计算

## 概述 {/*#overview*/}

报价计算以采购价格加上所有相关成本、加价和税费为基础，确定产品的销售价格。它遵循贸易和零售中使用的标准化分步方案。

## 计算方案 {/*#calculation-scheme*/}

### 采购侧 {/*#purchase-side*/}

| 运算 | 项目 | 说明 |
| --------- | ---------------------- | ----------------------------- |
| | 标价采购价 | 供应商的目录价格 |
| − | 供应商折扣 | 标价的百分比减免 |
| = | 净采购价 | |
| − | 供应商现金折扣 | 提前付款的百分比减免 |
| = | 现金采购价 | |
| + | 采购费用 | 运费、关税 |
| = | **成本价** | 商品的实际成本 |

### 销售侧 {/*#sales-side*/}

| 运算 | 项目 | 说明 |
| --------- | ---------------------------- | -------------------------------------------------- |
| | 成本价 | 承接自上表 |
| + | 管理费用加成 | 运营成本、租金、人员等 |
| = | 保本价 | |
| + | 利润加成 | 期望的利润率 |
| = | 现金销售价 | |
| + | 客户现金折扣 | 加回：允许客户享受提前付款折扣 |
| = | 净销售价 | |
| + | 客户折扣 | 加回：允许客户获得折扣 |
| = | 不含税标价销售价 | |
| + | 增值税 | 例如德国为 19% |
| = | **含税标价销售价** | 面向客户的最终价格 |

## 注意事项 {/*#notes*/}

- 现金折扣（Skonto）与折扣（Rabatt）在销售侧被**加回**，因为它们代表客户可能提出的扣减，销售价格必须覆盖这些扣减
- 管理费用加成通常以成本价的百分比表示，依据公司实际的运营成本确定
- 计算既可以正向进行（从采购价格到销售价格），也可以反向进行（从目标销售价格推导所需的采购价格）
