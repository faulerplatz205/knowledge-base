# 需求说明书/功能说明书

## 概述 {/*#overview*/}

在项目管理中，**需求说明书**和**功能说明书**是两份关键文档，分别定义系统应当做什么以及将如何实现。

- **需求说明书**由客户编写，描述**需要什么**
- **功能说明书**由承包方编写，描述需求将**如何**被满足

## 需求说明书 {/*#requirement-specification*/}

包含客户对承包方提出的需求，以及对所需系统的大致构想。

- 项目目标描述
- 现状描述
- 与安全相关的需求
- 功能性需求（系统应当做什么？）
- 非功能性需求（例如性能、安全性、可用性、易用性）
- 时间框架
- 预算

## 功能说明书 {/*#functional-specification*/}

由需求说明书衍生而来。它是承包方的回应，描述需求将如何被实现。

- 技术方案（架构、技术）
  - 系统组件的详细描述
  - 接口定义
  - 数据模型
- 测试标准和验收条件
- 项目进度计划和里程碑
- 成本估算
