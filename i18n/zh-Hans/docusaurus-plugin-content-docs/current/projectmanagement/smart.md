# SMART 模型

## 概述 {/*#overview*/}

SMART 模型用于敏捷开发中，精确地定义目标、用户故事或冲刺目标，从而弥合战略愿景与最终运营落地之间的差距。

## 准则 {/*#criteria*/}

### S - 具体（Specific） {/*#s---specific*/}

目标必须被清晰、精确地定义。模糊或宽泛表述的目标会留下过多解读空间，使团队难以知道究竟需要实现什么。

### M - 可衡量（Measurable） {/*#m---measurable*/}

目标的进展和完成情况必须可以衡量。具体的指标或验收标准使团队能够客观地判断目标是否已经达成。

### A - 有吸引力（Attractive） {/*#a---attractive*/}

目标应当对负责实现它的人具有激励性和相关性。如果团队看不到目标的价值，投入度和参与度就会受到影响。

### R - 现实（Realistic） {/*#r---realistic*/}

目标必须能够凭借可用的资源、技能和时间实现。不切实际的目标会打击团队的积极性，使项目从一开始就注定失败。

### T - 有时限（Time-bound） {/*#t---time-bound*/}

每个目标都需要明确的截止日期或时间框架。没有明确的终点，目标往往会被无限期推迟，并失去紧迫性。

## 总结 {/*#summary*/}

| 字母 | 准则                          | 关键问题                       |
| ---- | ----------------------------- | ------------------------------ |
| S    | [具体](#s---specific)         | 目标是否被清晰、精确地定义？   |
| M    | [可衡量](#m---measurable)     | 能否衡量进展和完成情况？       |
| A    | [有吸引力](#a---attractive)   | 目标对团队是否具有激励性？     |
| R    | [现实](#r---realistic)        | 凭借可用资源能否实现该目标？   |
| T    | [有时限](#t---time-bound)     | 目标是否有明确的截止日期？     |
