# 网络图

## 概述 {/*#overview*/}

:::info
存在多种网络计划方法，例如 CPM（关键路径法）、PERT 和 MPM。本文介绍 CPM。
:::

网络图是一种有向图，将任务建模为节点，以箭头表示依赖关系。它能够实现精确的进度安排并识别瓶颈。

## 节点结构 {/*#node-structure*/}

网络图中的每个节点包含以下字段：

```text
┌──────────────────────────┐
│         Task Name        │
├─────────────┬────────────┤
│ EAT         │ EET        │
├─────────────┼────────────┤
│ Total Float │ Free Float │
├─────────────┼────────────┤
│ LAT         │ LET        │
├─────────────┴────────────┤
|          Duration        |
└──────────────────────────┘
```

- **EAT**（最早开始时间）：任务最早可以开始的时间
- **EET**（最早结束时间）：任务最早可以结束的时间
- **LAT**（最晚开始时间）：在不延误项目的前提下，任务最晚可以开始的时间
- **LET**（最晚结束时间）：任务最晚可以结束的时间
- **自由时差**：`min(EAT of all successors) − EET`；任务可以推迟多久而不延误其任何紧后任务
- **总时差**：`LAT − EAT`；任务可以推迟的时间量，而不延误项目结束日期

## 时差类型 {/*#buffer-types*/}

**自由时差**描述*局部*灵活性：任务可以延后多久而不延误其任何紧后任务。它只向前看网络中的一步。

**总时差**描述*全局*灵活性：任务可以延后多久而不影响项目整体结束日期，不考虑中间的影响。

两者始终满足 `Free Float ≤ Total Float`。当 `Total Float > Free Float` 时，超过自由时差的延误会使链条中靠前的某个后继任务提前受到影响，但该后继任务自身拥有足够的总时差来吸收这一影响，而不会推迟项目结束。关键路径上的任务，两个值均为零。

## 计算网络图 {/*#calculating-the-plan*/}

**正向计算**：从左到右计算 EAT 和 EET：

- EET = EAT + 工期
- 如果一个任务有多个前置任务 => EAT = 所有前置任务 EET 的最大值

**反向计算**：从右到左计算 LAT 和 LET：

- LAT = LET − 工期
- 如果一个任务有多个后继任务 => LET = 所有后继任务 LAT 的最小值

## 关键路径 {/*#critical-path*/}

关键路径是从项目开始到结束的最长依赖任务序列。关键路径上的任务**总时差为零**，这意味着任何延误都会直接推迟项目整体结束日期。

## 优点 {/*#advantages*/}

- 明确地对任务依赖关系建模
- 识别关键路径和进度瓶颈
- 可精确计算最早和最晚的开始/结束时间
- 更适合复杂且依赖关系繁多的项目

## 缺点 {/*#disadvantages*/}

- 与[甘特图](./gantt.md)相比，构建和阅读更为复杂
- 对非技术背景的相关方不够直观
- 需要准确的工期估算才有意义

## 示例 {/*#example*/}

**项目：** 网站上线

| ID | 任务     | 工期 | 前置任务 |
|----|----------|------|----------|
| A  | 需求分析 | 2 天 | —        |
| B  | UI 设计  | 3 天 | A        |
| C  | 后端开发 | 5 天 | A        |
| D  | 前端开发 | 4 天 | B        |
| E  | 集成     | 2 天 | C, D     |
| F  | 测试     | 3 天 | E        |
| G  | 部署     | 1 天 | F        |

**网络结构：**

```text
    ┌──► B ──► D ───┐
A ──┤               ├──► E ──► F ──► G
    └──► C ─────────┘
```

**计算得出的节点值：**

```text
┌──────────────────────┐      ┌──────────────────────┐      ┌──────────────────────┐
│  A: Requirements     │      │  B: UI Design        │      │  C: Backend Dev      │
├──────────┬───────────┤      ├──────────┬───────────┤      ├──────────┬───────────┤
│  EAT: 0  │  EET: 2   │      │  EAT: 2  │  EET: 5   │      │  EAT: 2  │  EET: 7   │
├──────────┼───────────┤      ├──────────┼───────────┤      ├──────────┼───────────┤
│  TF:  0  │  FF:  0   │      │  TF:  0  │  FF:  0   │      │  TF:  2  │  FF:  2   │
├──────────┼───────────┤      ├──────────┼───────────┤      ├──────────┼───────────┤
│  LAT: 0  │  LET: 2   │      │  LAT: 2  │  LET: 5   │      │  LAT: 4  │  LET: 9   │
├──────────┴───────────┤      ├──────────┴───────────┤      ├──────────┴───────────┤
│        Dur: 2        │      │        Dur: 3        │      │        Dur: 5        │
└──────────────────────┘      └──────────────────────┘      └──────────────────────┘

┌──────────────────────┐      ┌──────────────────────┐      ┌──────────────────────┐
│  D: Frontend Dev     │      │  E: Integration      │      │  F: Testing          │
├──────────┬───────────┤      ├──────────┬───────────┤      ├──────────┬───────────┤
│  EAT: 5  │  EET: 9   │      │  EAT: 9  │  EET: 11  │      │  EAT: 11 │  EET: 14  │
├──────────┼───────────┤      ├──────────┼───────────┤      ├──────────┼───────────┤
│  TF:  0  │  FF:  0   │      │  TF:  0  │  FF:  0   │      │  TF:  0  │  FF:  0   │
├──────────┼───────────┤      ├──────────┼───────────┤      ├──────────┼───────────┤
│  LAT: 5  │  LET: 9   │      │  LAT: 9  │  LET: 11  │      │  LAT: 11 │  LET: 14  │
├──────────┴───────────┤      ├──────────┴───────────┤      ├──────────┴───────────┤
│        Dur: 4        │      │        Dur: 2        │      │        Dur: 3        │
└──────────────────────┘      └──────────────────────┘      └──────────────────────┘

┌──────────────────────┐
│  G: Deployment       │
├──────────┬───────────┤
│  EAT: 14 │  EET: 15  │
├──────────┼───────────┤
│  TF:  0  │  FF:  0   │
├──────────┼───────────┤
│  LAT: 14 │  LET: 15  │
├──────────┴───────────┤
│        Dur: 1        │
└──────────────────────┘
```

**关键路径：** A => B => D => E => F => G（共 15 天）

任务 C 的总时差为 2 天（此处也等于其自由时差），且不在关键路径上，因此后端开发最多可以晚开始 2 天，而不会延误任何后继任务或项目结束日期。
