# Linux 文件权限

两个 `ls` 选项涵盖了日常场景：列出详细信息（包括权限）和显示隐藏文件。

## 列出文件 {/* #listing-files */}

```bash
ls -l    # Long format: permissions, owner, size, date, name
ls -a    # Show all files, including hidden ones
```

名称以点开头的文件和目录（`.bashrc`、`.config`）为**隐藏**项，只有使用 `ls -a` 时才会显示。这两个选项通常组合为 `ls -la` 使用。

## 输出示例 {/* #example-output */}

每一行 `ls -l` 输出通过多列描述一个条目：

```bash
-rw-r--r-- 1 user staff 1024 Apr 25 10:00 notes.txt
drwxr-xr-x 2 user staff 4096 Apr 25 09:30 projects
```

| 列          | 示例           | 含义               |
| ----------- | -------------- | ------------------ |
| 权限        | `-rw-r--r--`   | 文件类型和权限     |
| 链接数      | `1`            | 硬链接的数量       |
| 所有者      | `user`         | 文件的所有者       |
| 组          | `staff`        | 文件所属的组       |
| 大小        | `1024`         | 以字节为单位的大小 |
| 日期和时间  | `Apr 25 10:00` | 最后修改时间       |
| 名称        | `notes.txt`    | 文件或目录名称     |

## 阅读权限表示法 {/* #reading-the-permission-notation */}

`ls -l` 的每一行以一个 10 个字符的字符串开头，例如 `-rwxr-xr-x`。它分为四个部分：

| 位置 | 示例    | 含义                                                       |
| ---- | ------- | ---------------------------------------------------------- |
| 1    | `-`     | 文件类型（`-` = 文件，`d` = 目录，`l` = 符号链接） |
| 2-4  | `rwx`   | **所有者**的权限                                           |
| 5-7  | `r-x`   | **组**的权限                                               |
| 8-10 | `r-x`   | **其他人**的权限                                           |

三组权限都使用相同的三个标志：

| 标志    | 含义 | 对文件的作用 | 对目录的作用        |
| ------- | ---- | ------------ | ------------------- |
| `r` | 读取 | 读取内容     | 列出条目            |
| `w` | 写入 | 修改内容     | 创建/删除条目       |
| `x` | 执行 | 作为程序运行 | 进入（`cd`）该目录 |

用 `-` 代替字母表示未授予该权限。因此 `-rwxr-xr-x` 表示：一个普通文件，所有者可以读/写/执行，组和其他人可以读取和执行，但不能写入。
